# 자원할당 그래프(Resource Allocation Graph)

---

## I. 교착상태를 그림으로 판정하는, 자원할당 그래프의 개요

### 가. 정의

- [[프로세스]]와 자원을 정점으로, 요청·할당 관계를 방향 간선으로 표현해 **[[교착상태]] 발생 여부를 판단하는 방향 그래프** (Holt, 1972)

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 구성 | 프로세스 정점(원), 자원 정점(사각형, 안의 점 = 인스턴스 수), 요청·할당 간선 |
| 사이클 없음 | 교착상태 아님 |
| 사이클 있음 (단일 인스턴스) | 교착상태 확정 |
| 사이클 있음 (다중 인스턴스) | 교착상태 가능성만 존재 → 은행가식 탐지 알고리즘으로 추가 확인 |

- P1 → R1 → P2 → R2 → P1의 사이클 형성, 모든 자원이 단일 인스턴스면 교착상태
- 그림의 R2처럼 인스턴스가 2개이고 하나가 비어 있다면 P2의 요청이 충족될 수 있어 교착이 아님 (다중 인스턴스에서 사이클은 필요조건일 뿐)

### 나. 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 정점 | 프로세스 (Pi) | 원으로 표시 |
| | 자원 (Rj) | 사각형으로 표시, 내부 점 하나가 인스턴스 하나 |
| 간선 | 요청 간선 (Pi → Rj) | 프로세스가 자원을 요청하고 대기 중, 사각형 테두리를 가리킴 |
| | 할당 간선 (Rj → Pi) | 특정 인스턴스(점)가 프로세스에 할당됨 |
| | 예약 간선 (Pi ⇢ Rj) | 회피 기법에서 앞으로 요청할 수 있음을 점선으로 표시 |
| 판정 | 사이클 탐지 | DFS로 사이클 검사, 정점 n개일 때 O(n²) |

## III. 비교 및 동향

### 가. 자원할당 그래프 vs 대기 그래프

| 비교 항목 | 자원할당 그래프 | 대기 그래프 (Wait-for Graph) |
| --- | --- | --- |
| 정점 | 프로세스 + 자원 | 프로세스만 |
| 간선 | 요청·할당 | Pi → Pj (Pi가 Pj의 자원을 기다림) |
| 적용 | 단일·다중 인스턴스 표현 | 단일 인스턴스 자원의 탐지 |
| 용도 | 상태 모델링, 회피(예약 간선) | 주기적 교착 탐지 (DBMS 락 관리자) |

### 나. 동향

- **DBMS 교착 탐지**: MySQL InnoDB, PostgreSQL 등은 락 대기 관계를 대기 그래프로 관리해 사이클 발견 시 희생 트랜잭션 롤백
- **분산 교착 탐지**: 노드별 대기 그래프를 합친 전역 그래프나 엣지 추적(Chandy-Misra-Haas) 방식, 실무에서는 락 타임아웃 병행
- **커널 락 검증**: Linux Lockdep이 락 획득 순서를 그래프로 기록해 잠재적 사이클을 개발 단계에서 경고
