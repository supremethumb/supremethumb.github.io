# 정보시스템 감리 점검 해설서

---

## I. 감리원 간 편차를 줄이는 기준서, 감리 점검 해설서의 개요

### 가. 정의

- 공공 정보화 사업 감리에서 **감리 시점·영역별 점검 항목과 점검 기준, 확인 방법, 증적 자료를 해설한 실무 기준서** (NIA 발간, 정보시스템 감리기준의 하위 실무 지침)

### 나. 필요성 및 특징

| 구분 | 내용 |
| --- | --- |
| 객관성 | 감리원의 주관적 경험에 따른 판단 편차 축소 |
| 일관성 | 동일 유형 사업에 동일한 점검 기준 적용 |
| 실무성 | 점검 항목마다 확인 방법과 요구 증적 자료 명시 |
| 현행화 | 클라우드·모바일·보안 규정 등 기술·제도 변화를 주기적으로 반영 |

---

## II. 점검 체계 및 구성요소

### 가. 점검 체계

```mermaid
flowchart LR
    LAW["전자정부법 · 정보시스템 감리기준"] --> FW["감리 프레임워크<br/>시점 × 영역 × 관점"]
    FW --> ITEM["점검 항목"]
    ITEM --> CRI["점검 기준"]
    CRI --> MTH["확인 방법"]
    MTH --> EVD["증적 자료"]
    EVD --> RPT["감리수행결과보고서<br/>(문제점 · 개선 권고)"]
```

- 감리 프레임워크에서 도출한 점검 항목마다 '기준 → 확인 방법 → 증적'을 제시해, 현장 감리 결과를 근거 있는 판단으로 연결

### 나. 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 감리 시점 | 요구정의 · 설계 · 종료 | 사업 단계별 점검 시점 |
| 감리 영역 | 사업관리 · 응용시스템 · 데이터베이스 · 시스템구조 및 보안 | 개발 사업의 4개 점검 영역 |
| 감리 관점 | 절차 · 산출물 등 | 수행 절차의 적정성과 산출물·시스템의 품질 관점 |
| 상세 구성 | 점검 항목 · 기준 | 감리원이 확인할 체크포인트와 판단 척도 |
| | 확인 방법 · 증적 | 산출물 대조, 인터뷰, 시험 등 검증 방식과 요구 문서 |
| 특화 점검 | [[클라우드 감리]] | 클라우드 전환 시 자원 탄력성, 데이터 이관, [[CSAP]] 인증 확인 |
| | 모바일 · 웹 | 모바일 전자정부 표준, 웹 접근성, 호환성 점검 |
| | 보안약점 | 행안부 SW 개발보안 가이드의 구현단계 보안약점([[SAST\|정적 분석]] 결과) 조치 확인 |

## III. 비교 및 동향

### 가. 한계와 대응

| 한계 | 내용 | 대응 |
| --- | --- | --- |
| 문서 중심 점검 | 산출물 대조 위주로 동작하는 SW의 결함 도출 미흡 | 시험·도구 기반 점검 비중 확대 |
| 신기술 반영 지연 | [[MSA (Micro Service Architecture)\|MSA]]·오픈소스·AI 사업의 점검 기준 부족 | 분야별 가이드(빅데이터·AI 등)로 모듈형 보완 |
| 애자일 사업 부적합 | 단계 시점 고정형 감리와 반복 개발의 불일치 | 반복 주기에 맞춘 감리 시점 [[테일러링]] |

### 나. 동향

- 감리원 체크리스트를 RFP 특성에 맞춰 LLM으로 맞춤 추출하는 지능형 감리 지원 시도
- 보안약점·코드 품질 점검을 [[DevSecOps]] 파이프라인 결과로 대체·보완하는 자동화 감리
