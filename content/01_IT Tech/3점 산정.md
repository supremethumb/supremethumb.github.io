# 3점 산정 (Three-Point Estimating)

---

## I. 불확실성을 범위로 표현하는 추정, 3점 산정의 개요

### 가. 정의

- 활동 기간·원가를 **낙관치(O)·최빈치(M)·비관치(P)** 세 값으로 추정하고 확률분포 가정에 따라 **기대치와 불확실성**을 구하는 기법 (PERT에서 유래)

### 나. 필요성 및 특징

| 구분 | 내용 |
| --- | --- |
| 단일값 추정 한계 보완 | 한 개 값은 낙관 편향·위험을 숨김, 범위로 불확실성 표현 |
| 통계적 근거 | 기대치·표준편차로 일정 달성 확률 계산 |
| 위험 분석 입력 | [[몬테카를로 시뮬레이션]] 등 정량적 위험 분석의 입력 분포 제공 |
| 적용 대상 | 활동기간 산정, 원가 산정 모두 적용 |

---

## II. 산정 방식

### 가. 개념도

```mermaid
flowchart LR
    subgraph In ["추정치"]
        direction TB
        O["낙관치 O"]
        M["최빈치 M"]
        P["비관치 P"]
    end
    subgraph Dist ["분포 가정"]
        direction TB
        Beta["베타 분포 (PERT)<br/>E = (O + 4M + P) / 6"]
        Tri["삼각 분포<br/>E = (O + M + P) / 3"]
    end
    subgraph Out ["산출"]
        direction TB
        E["기대치 E"]
        SD["표준편차 σ ≈ (P - O) / 6"]
        PR["완료 확률"]
    end
    In --> Dist --> Out
```

- 활동별 기대치를 경로 단위로 합하고, 경로 분산은 활동 분산의 합(σ경로 = √Σσ²)으로 구해 정규분포 근사로 확률 계산

### 나. 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 입력 | 낙관치 (O) | 모든 조건이 유리할 때의 최소 기간·원가 |
| | 최빈치 (M) | 가장 일어날 가능성이 높은 값 |
| | 비관치 (P) | 불리한 조건에서의 최대 기간·원가 |
| 분포 | 베타 분포 (PERT) | 최빈치에 가중치 4, 현실적 중심 경향 반영 |
| | 삼각 분포 | 세 값을 동일 가중 평균, 비관치 영향이 상대적으로 큼 |
| 지표 | 표준편차 (σ) | PERT 근사식 (P−O)/6, 추정의 불확실성 크기 |
| | 분산 (σ²) | 주공정 활동 분산을 합산해 프로젝트 분산 산출 |
| 확률 | 신뢰 구간 | 정규분포 근사 시 E±1σ 약 68.3%, ±2σ 약 95.4%, ±3σ 약 99.7% |

- 계산 예: O=4, M=6, P=14일 → E = (4+24+14)/6 = 7일, σ = 10/6 ≈ 1.67일

## III. 비교 및 동향

### 가. 3점 vs 유사 vs 모수 산정

| 비교 항목 | 3점 산정 | 유사 산정 | 모수 산정 |
| --- | --- | --- | --- |
| 방식 | O·M·P 가중 평균 | 과거 유사 실적 기반 | 과거 데이터의 통계 관계 |
| 정확도 | 중~높음, 불확실성 범위 제공 | 낮음 (하향식) | 데이터·모델 품질에 따라 높음 |
| 노력 | 활동마다 3개 값 필요 | 적음 | 모델 구축 필요 |
| 적용 시기 | [[WBS]] 상세화 이후 | 초기, 정보 부족 시 | 신뢰할 데이터 확보 시 |

### 나. 동향

- **몬테카를로 결합**: 3점 추정치를 삼각·베타 분포로 입력해 P50·P80 일정과 원가 산출
- **애자일 적용**: 불확실성이 큰 에픽·스파이크 추정에 범위 추정을 병행
