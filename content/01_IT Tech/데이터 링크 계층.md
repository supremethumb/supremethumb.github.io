# 데이터 링크 계층 (Data Link Layer)

---

## I. 인접 노드 간 신뢰성 있는 전송, 데이터 링크 계층의 개요

### 가. 데이터 링크 계층의 정의

- 물리적인 링크(Link)를 통해 연결된 두 노드 간에 **[[신뢰성]](Reliability)** 있는 정보 전송을 보장하기 위해 **오류 제어, 흐름 제어, 회선 제어**를 수행하는 OSI 2계층,.
- 상위 계층(Network Layer)의 패킷을 **프레임(Frame)** 단위로 캡슐화하여 물리 계층으로 전달하는 역할을 수행함.
### 나. 핵심 키워드

- **Node-to-Node**, **Frame**, **[[MAC]] 주소(48bit)**, **LLC/MAC Sub-layer**, **오류 제어([[CRC]]/ARQ)**, **흐름 제어(Sliding Window)**, **[[CSMA CD|CSMA/CD]]**, **L2 [[스위치 (Layer 3 Switch)|스위치]]**.

- **도식화 포인트:** 데이터 링크 계층이 단일 계층이 아니라, **S/W적인 기능을 담당하는 LLC**와 **H/W적인 매체 접근을 담당하는 MAC**으로 나뉘어 있음을 시각화하여 기술적 깊이를 보여줌,.
### 나. 데이터 링크 계층의 핵심 기능 및 기술 요소 (소스 43, 101 기반)

| 구분 | 기능 | 상세 설명 및 기술 |
| --- | --- | --- |
| **전송**<br>**제어** | **오류 제어** | - 전송 중 발생한 오류 검출 및 정정 (신뢰성 확보).<br>- **FEC:** 해밍 코드 / **[[BEC (Backward Error Correction)|BEC]]:** CRC(검출), ARQ(재전송),. |
|  | **흐름 제어** | - 송수신 측의 속도 차이를 조절하여 버퍼 오버플로우 방지.<br>- **Sliding Window**, Stop-and-Wait,. |
| **접근**<br>**제어** | **회선 제어** | - 링크의 설정, 유지, 해제 및 데이터 전송 순서 제어.<br>- **ENQ/ACK** (1:1), **Polling** (Select/Poll 모드). |
|  | **매체 접근** | - 다수의 장비가 통신 매체를 공유할 때 충돌 방지.<br>- 유선: **CSMA/CD** (IEEE 802.3), 무선: **[[CSMA CA|CSMA/CA]]** (IEEE 802.11). |
| **주소** | **[[물리 주소]]** | - 인접 장비 식별을 위한 고유의 **MAC Address** (48bit) 사용. |

## III. 데이터 링크 계층 프레임 구조 및 주요 장비

### 가. 이더넷(Ethernet) 프레임 구조

- **Preamble(동기화)** + **Dest/Source MAC(주소)** + **Type/Len** + **Data(Payload)** + **FCS(CRC, 오류검출)**.
- 데이터의 무결성을 위해 끝부분(Trailer)에 **FCS(Frame Check Sequence)** 필드를 두어 오류를 검사함.
### 나. 주요 장비 및 프로토콜

- **장비:** **L2 스위치**, **브리지(Bridge)** (MAC 주소 기반 스위칭 수행),.
- **[[프로토콜]]:** **Ethernet**, **HDLC**(비트 중심), **PPP**(점대점), **[[ARP]]**(IP→MAC 변환),.
