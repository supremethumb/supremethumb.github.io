# 데이터 링크 계층 (Data Link Layer, OSI 2계층)

---

## I. 인접 노드 간 신뢰성 있는 프레임 전송, 데이터 링크 계층의 개요

### 가. 정의

- OSI 7계층 중 2계층으로, 물리 링크로 연결된 **인접 노드 간에 프레임(Frame)을 오류 없이 전달**하기 위해 프레이밍·오류 제어·흐름 제어·매체 접근 제어를 수행하는 계층

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 전달 범위 | Node-to-Node (같은 링크·LAN 구간) |
| 물리 주소 | 48비트 MAC 주소로 송수신 노드 식별 ([[물리 주소]]) |
| 2개 부계층 | 상위 계층 인터페이스인 LLC(IEEE 802.2), 매체 접근을 담당하는 MAC(802.3, 802.11) |
| 투명성 | [[네트워크 계층]]에 신뢰성 있는 링크를 제공 |

---

- LLC는 상위 프로토콜 식별(다중화)·흐름·오류 제어 같은 소프트웨어적 기능을, MAC은 매체 접근과 주소 지정 같은 하드웨어적 기능을 담당

### 나. 프레임 캡슐화

```mermaid
flowchart LR
    P["L3 패킷"] --> H["MAC 헤더<br/>(목적지 · 출발지 MAC, Type)"]
    H --> D["Payload<br/>(L3 패킷)"]
    D --> T["FCS 트레일러<br/>(CRC-32)"]
    T --> B["L1 비트 스트림"]
```

- 이더넷 프레임: Preamble(동기화) + 목적지·출발지 MAC + Type/Length + Data(46~1500바이트) + FCS

### 다. 핵심 기능

| 구분 | 기능 | 설명 |
| --- | --- | --- |
| 프레이밍 | Framing | 비트열을 프레임 단위로 묶고 헤더·트레일러 부가 (문자·비트 스터핑) |
| 오류 제어 | 검출 | 패리티, 체크섬, [[CRC]] (FCS 필드) |
| | 정정 | [[FEC(Forward Error Correction) BEC(Backward Error Correction)\|FEC]](해밍 코드) 또는 ARQ 재전송 (Stop-and-Wait, Go-Back-N, Selective Repeat) |
| 흐름 제어 | 속도 조절 | Stop-and-Wait, Sliding Window로 수신 버퍼 오버플로 방지 |
| 회선 제어 | 링크 관리 | ENQ/ACK(점대점), Polling/Selecting(멀티포인트) |
| 매체 접근 | 다중 접속 | 유선 [[CSMA CD\|CSMA/CD]](802.3), 무선 [[CSMA CA\|CSMA/CA]](802.11) |
| 장비 | L2 [[스위치]] · 브리지 | MAC 주소 테이블(CAM) 기반 포워딩으로 충돌 도메인 분할 |
| 프로토콜 | Ethernet, Wi-Fi, PPP, HDLC | 유선 LAN, 무선 LAN, 점대점, 비트 지향 동기식 |

## III. 비교 및 동향

### 가. 데이터 링크 계층 vs 네트워크 계층

| 비교 항목 | 데이터 링크 (L2) | 네트워크 (L3) |
| --- | --- | --- |
| 전달 범위 | 인접 노드 간 (같은 LAN) | 호스트 간 (서로 다른 네트워크) |
| 주소 | MAC 주소 (48비트, 장치 고정) | IP 주소 (논리, 할당 가변) |
| 전송 단위 | 프레임 | 패킷 |
| 핵심 동작 | 스위칭 (MAC 테이블) | 라우팅 (라우팅 테이블) |
| 장비 | L2 스위치, 브리지, NIC | [[라우터]], L3 스위치 |

### 나. 동향

- **가상 스위치**: 하이퍼바이저 내부의 Open vSwitch가 VM·컨테이너 간 L2 스위칭 수행
- **오버레이 네트워크**: VLAN 4,094개 한계를 넘기 위해 L2 프레임을 L3 IP 망 위로 터널링하는 VXLAN(24비트 VNI)·GENEVE가 데이터센터 표준
- **TSN (Time-Sensitive Networking)**: 이더넷에 시간 동기·스케줄링을 더해 산업 제어·차량 네트워크의 확정적 지연 보장
