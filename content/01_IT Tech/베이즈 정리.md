### 가. 정의

- 조건부 확률과 전확률 정리로부터 유도되며, **사전 확률 $P(A)$와 우도 $P(B \mid A)$로 사후 확률 $P(A \mid B)$를 구하는 확률 정리**

$$P(A \mid B) = \frac{P(B \mid A)\,P(A)}{P(B)}, \quad P(B) = \sum_i P(B \mid A_i)P(A_i)$$

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 역확률 | 원인→결과 확률 $P(B \mid A)$로 결과→원인 확률 $P(A \mid B)$를 계산 |
| 확률 갱신 | 사후 확률을 다음 관측의 사전 확률로 사용해 순차 갱신 |
| 기저율 반영 | 사전 확률(기저율)을 무시하면 판단이 왜곡됨 (예: 유병률 낮은 질병의 양성 판정) |

### 나. 구성요소 및 응용

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 구성요소 | 사전 확률 $P(A)$ | 관측 전 가설이 참일 확률 |
| | 우도 $P(B \mid A)$ | 가설 A가 참일 때 데이터 B가 관측될 확률 |
| | 증거 $P(B)$ | 데이터 B의 전체 발생 확률, 전확률 정리로 계산하는 정규화 상수 |
| | 사후 확률 $P(A \mid B)$ | 데이터 반영 후 갱신된 가설의 확률 |
| AI/ML 응용 | 나이브 베이즈 분류기 | 특징 간 조건부 독립을 가정한 분류 모델 |
| | 베이지안 네트워크 | 변수 간 조건부 의존 관계를 DAG로 표현 |
| | 베이지안 최적화 | 목적 함수를 대리 모델로 확률 추정해 하이퍼파라미터 탐색 |
| | 베이지안 신경망 | 가중치를 확률 분포로 다뤄 예측 불확실성 정량화 |

## III. 비교 및 동향

### 가. 확률 개념 비교

| 비교 항목 | 조건부 확률 | 전확률 정리 | 베이즈 정리 |
| --- | --- | --- | --- |
| 식 | $P(A \mid B) = P(A \cap B)/P(B)$ | $P(B) = \sum_i P(B \mid A_i)P(A_i)$ | $P(A \mid B) = P(B \mid A)P(A)/P(B)$ |
| 역할 | B가 주어졌을 때 A의 확률 | 분할된 원인별로 결과 확률 합산 | 결과로 원인 확률 역추론 |
| 예 | 비 오는 날 지각 확률 | 전체 불량률 | 불량품이 A공장 제품일 확률 |

### 나. 동향

- **불확실성 정량화**: [[베이지안 딥러닝]]·MC Dropout으로 의료·자율주행 AI의 예측 신뢰도 산출
- **자동 튜닝**: 베이지안 최적화가 [[AutoML (Automated Machine Learning)|AutoML]]·하이퍼파라미터 탐색 도구(Optuna, Ax 등)의 핵심 기법으로 사용
- **확률적 프로그래밍**: PyMC, Stan 등으로 사후분포 추론(MCMC·변분 추론)을 자동화 ([[베이즈 추론]])
