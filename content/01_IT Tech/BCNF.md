# BCNF (Boyce-Codd Normal Form)

---

## I. 모든 결정자는 후보키, BCNF의 개요

### 가. 정의

- 릴레이션의 **모든 비자명 함수 종속 X → Y에서 결정자 X가 슈퍼키(후보키 포함)인 정규형** (강한 3NF, 3.5NF)

### 나. 등장 배경 및 특징

| 구분 | 내용 |
| --- | --- |
| 3NF의 한계 | 후보키가 여럿이고 서로 겹치거나, 키가 아닌 속성이 키 일부를 결정하면 이상현상 잔존 |
| 조건 | 모든 결정자가 후보키 |
| 분해 | 위반 종속 X → Y를 (X, Y)와 나머지로 무손실 분해 |
| 한계 | 종속성 보존이 항상 가능하지는 않음 |

---

## II. 분해 구조 및 요소

### 가. BCNF 분해 예

```mermaid
flowchart LR
    R["수강(학번, 과목, 교수)<br/>(학번, 과목) → 교수<br/>교수 → 과목"] -->|"교수는 결정자지만 후보키 아님"| D{"BCNF 분해"}
    D --> R1["수강(학번, 교수)"]
    D --> R2["담당(교수, 과목)"]
```

- 교수 → 과목에서 교수가 후보키가 아니므로 (교수, 과목)을 분리, 단 (학번, 과목) → 교수 종속은 한 릴레이션에서 검사할 수 없게 됨 (종속성 미보존)

### 나. 핵심 요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 개념 | 결정자 (Determinant) | X → Y에서 Y를 결정하는 X |
| | 후보키 | 유일성·최소성을 만족하는 속성 집합 ([[릴레이션 키]]) |
| 판정 | 속성 폐포 X⁺ | X⁺가 전체 속성을 포함하면 X는 슈퍼키 ([[암스트롱 공리]]) |
| 분해 원칙 | 무손실 분해 | 자연 조인으로 원래 릴레이션 복원 |
| | 종속성 보존 | BCNF 분해는 보장하지 못할 수 있음 |
| 위반 원인 | 키가 아닌 결정자 | 비주요 속성이 주요 속성을 결정하는 경우 |

---

## III. 비교 및 동향

### 가. 3NF vs BCNF

| 비교 항목 | 3NF | BCNF |
| --- | --- | --- |
| 조건 | X → A에서 X가 슈퍼키이거나 A가 주요 속성 | X → A에서 X가 반드시 슈퍼키 |
| 결정자 | 후보키가 아닌 결정자 허용 (A가 주요 속성일 때) | 모든 결정자가 후보키 |
| 이상현상 | 겹치는 복합 후보키에서 잔존 가능 | 함수 종속에 의한 이상현상 제거 (다치 종속은 4NF) |
| 종속성 보존 | 보존하는 무손실 분해가 항상 존재 | 보존하지 못할 수 있음 |
| 실무 | 일반적 설계 목표 | 복합 후보키가 겹치는 경우 검토 |

### 나. 동향

- **3NF·BCNF 선택**: 종속성 보존이 중요하면 3NF에서 멈추고 제약은 트리거·애플리케이션으로 보완
- **분산·NoSQL 환경**: 조인 비용 때문에 의도적 반정규화를 병행 ([[데이터베이스 반정규화]])
