# IP (Internet Protocol)

---

## I. 주소를 붙여 목적지로 보내는, IP의 개요

### 가. 정의

- 패킷 교환망에서 **논리 주소로 송수신 호스트를 식별하고, 데이터그램을 홉 단위로 목적지까지 전달**하는 [[네트워크 계층]] 핵심 [[프로토콜]] (IPv4: RFC 791, IPv6: RFC 8200)

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 계층적 주소 | 네트워크 부분 + 호스트 부분으로 경로 집약 |
| 비연결형 | 사전 연결 없이 데이터그램마다 독립 전달 |
| 최선형 (Best-Effort) | 도착·순서·중복 없음을 보장하지 않음, 신뢰성은 [[TCP]] 담당 |
| 이기종 연결 | 다양한 L2 매체를 하나의 인터넷으로 통합 (Hourglass 구조의 허리) |
| 홉 단위 전달 | 라우터마다 목적지 주소로 다음 홉 결정 |

---

## II. 구조 및 구성요소

### 가. 홉 단위 전달

```mermaid
flowchart LR
    A["송신 호스트<br/>10.0.0.1"] -- "TTL 64" --> R1{"Router A"}
    R1 -- "TTL 63" --> R2{"Router B"}
    R2 -- "TTL 62" --> B["수신 호스트<br/>20.0.0.1"]
```

- 각 라우터는 목적지 주소를 라우팅 테이블에서 최장 접두사 일치로 조회해 다음 홉을 정하고 TTL을 1 감소

### 나. 핵심 기능

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 주소 지정 | 논리 주소 | [[IPv4]] 32비트, [[IPv6]] 128비트 |
| 경로 결정 | 라우팅 · 포워딩 | 목적지 주소 기반 다음 홉 선택 |
| 크기 조정 | [[단편화]] · 재조립 | MTU 초과 시 분할, 목적지에서 재조립 (IPv6는 송신 호스트만 분할) |
| 루프 방지 | TTL / Hop Limit | 홉마다 1 감소, 0이면 폐기 후 [[ICMP]] 통보 |
| 품질 | DSCP · ECN | [[DiffServ (Differentiated Services)\|DiffServ]] 등급 표시, 혼잡 통지 |
| 상위 식별 | Protocol / Next Header | TCP 6, UDP 17, ICMP 1 |
| 오류 검출 | Header Checksum | IPv4만 존재, IPv6는 제거(상·하위 계층에 위임) |

## III. 비교 및 동향

### 가. IPv4 vs IPv6

| 비교 항목 | IPv4 | IPv6 |
| --- | --- | --- |
| 주소 | 32비트 (약 43억 개), 점 10진 표기 | 128비트, 16진 콜론 표기 |
| 헤더 | 가변 20~60바이트 | 고정 40바이트 + 확장 헤더 |
| 단편화 | 송신 호스트·라우터 | 송신 호스트만 |
| 체크섬 | 있음 | 없음 |
| 주소 설정 | 수동, [[DHCP]] | SLAAC, DHCPv6 |
| IPsec | 선택 | 지원 권고 (초기 필수에서 RFC 6434로 권고로 완화) |

### 나. 동향

- **IPv6 확산**: 모바일망 중심으로 IPv6 트래픽 비중 증가, 듀얼 스택·IPv6 전용망 + NAT64 운영
- **SRv6**: IPv6 확장 헤더로 경로를 지정하는 네트워크 프로그래밍, 통신사 백본·5G 전송망 적용
- **암호화 보편화**: 망 계층보다 TLS·QUIC 등 상위 계층 암호화가 주류, IPsec은 VPN 중심
