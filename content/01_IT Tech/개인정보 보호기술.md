# 개인정보 보호기술 PET (Privacy Enhancing Technology)

---

## I. 프라이버시 보호와 데이터 활용을 가능하게 하는 PET의 개요

### 가. PET의 정의
- 데이터의 유용성과 활용 가치는 최대한 유지하면서 정보주체의 프라이버시 침해 위험을 수학적·기술적·구조적으로 최소화하는 프라이버시 강화 기술의 총칭.

### 나. PET의 등장 배경 및 주요 특징
| 구분 | 내용 |
| --- | --- |
| 제정 배경 | 빅데이터 결합 및 AI 모델 학습 시 데이터 활용 요구와 개인정보보호 규제(GDPR, 데이터 3법) 간 충돌 해소 |
| Data in Use 보호 | 데이터 저장(Rest) 및 전송(Transit) 구간을 넘어 연산·분석 중(In Use) 원본 데이터 노출 위험 원천 차단 |
| 5대 기술 영역 | 데이터 변환형(가명·익명화), 입력 암호화(동형암호, TEE), 처리 분산형(연합학습), 출력 보호형(차분 프라이버시), 검증 기반형(영지식 증명) |
| 칵테일 융합 전략 | 단일 기술의 연산 오버헤드와 정보 손실 한계를 극복하기 위해 다중 PET 기술을 상호보완적으로 복합 적용 |

### 나. PET 핵심 기술 유형별 상세

| 분류 | 요소기술(키워드) | 세부 설명 및 주요 특징 |
| --- | --- | --- |
| **데이터 변환형** | **가명처리 / [[비식별화]]** | 식별자 삭제, 범주화, 마스킹 등을 통해 추가 정보 없이는 개인을 식별할 수 없도록 변환 |
| **데이터 변환형** | **익명처리** | 시간·비용·기술을 고려해도 영구히 특정 개인을 재식별할 수 없도록 비가역적 처리 |
| **데이터 변환형** | **[[합성 데이터\|합성데이터]]** | 생성형 AI(GAN, VAE)를 활용해 원본 개인정보의 통계적 속성과 분포만 모사한 인공 데이터 생성 |
| **입력 암호화** | **[[동형 암호|동형암호(HE)]]** | 데이터를 복호화하지 않고 암호화된 상태 그대로 사칙연산 및 통계·AI 분석 수행 |
| **입력 암호화** | **TEE (신뢰실행환경)** | [[CPU]] 하드웨어 내부 격리 영역(Enclave)에서만 연산 중인 데이터를 복호화하여 처리 |
| **처리 분산형** | **연합학습 (Federated Learning)** | 원본 데이터를 중앙 서버로 모으지 않고 개별 기기(로컬)에서 학습 후 가중치 파라미터만 병합 |
| **처리 분산형** | **SMPC (안전 다자간 연산)** | 참여자 간 원본 데이터를 공개하지 않고 비밀 분산(Secret Sharing)을 통해 결합 연산 결과 도출 |
| **검증 기반형** | **[[영지식증명]] (ZKP)** | 증명자가 자신의 비밀 데이터 원본을 공개하지 않고도 그 명제가 참임을 검증자에게 암호학적으로 증명 |
| **출력 보호형** | **[[차분 프라이버시]] (DP)** | 통계적 질의 응답 결과에 의도적으로 정밀 계산된 노이즈를 주입하여 개별 데이터 유무 추론 차단 |

## III. 전통적 데이터 보호 vs 차세대 PET 비교 및 발전 전망

### 가. 전통적 데이터 보호 vs 차세대 PET 비교

| 비교 항목 | 전통적 데이터 보호 (Traditional) | 차세대 프라이버시 강화 기술 (PET) |
| --- | --- | --- |
| **보호 구간** | 저장(Data at Rest) 및 전송(Data in Transit) 중심 | 연산 및 분석 중인 데이터(Data in Use) 전면 보호 |
| **데이터 활용성** | 암호화 시 분석 불가(복호화 필수), 비식별화 시 유용성 저하 | 원본 비노출 상태에서도 고정밀 AI 학습 및 통계 연산 가능 |
| **보안 메커니즘** | 경계 방화벽, 접근 통제(ACL), 디스크/TLS 암호화 | 수학적 난제(동형암호), HW 격리(TEE), 분산 머신러닝 |
| **주요 적용 영역** | 정형 데이터베이스 관리, 기업 내부 인프라 보호 | 이종 산업 간 민감 데이터 결합, 연합학습, 의료·금융 AI |

### 나. PET 활용 동향 및 발전 전망
- **복합 칵테일(Multi-PET) 전략 가속화**: 단일 기술의 성능 및 보호 한계를 극복하기 위해 '연합학습 + 차분 프라이버시' 또는 '동형암호 + TEE'를 결합한 하이브리드 아키텍처 도입.
- **글로벌 규제 컴플라이언스 연계**: EU AI Act 및 데이터법(Data Act)에서 권고하는 프라이버시 보존 연산 가이드라인에 부합하도록 엔터프라이즈 AI 파이프라인 전 과정에 PET 내재화.
- **프라이버시 보존 머신러닝(PPML) 상용화**: 의료 기관 간 환자 정보 유출 없는 희귀 질환 공동 연구 및 금융 기관 간 이상금융거래(FDS) 모델 공동 개발을 위한 핵심 플랫폼으로 정착.
