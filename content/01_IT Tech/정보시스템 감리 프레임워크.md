# 정보시스템 감리 프레임워크 (Information System Audit Framework)

---

## I. 감리 점검의 표준 틀, 감리 프레임워크의 개요

### 가. 정의

- 감리의 객관성·일관성을 위해 점검 대상을 **감리 시점·감리 영역·감리 관점**의 교차 구조로 정리하고, 그 교차점에서 점검항목을 도출하는 표준 점검 체계

### 나. 등장 배경 및 특징

| 구분 | 내용 |
| --- | --- |
| 법적 근거 | 전자정부법(정보시스템 감리), 행정안전부 고시 정보시스템 감리기준 |
| 점검 편차 해소 | 감리원 개인 경험에 의존한 판단 차이 축소 |
| 누락 방지 | 시점×영역×관점 교차로 점검 사각지대 축소 |
| 테일러링 | 사업 유형(구축, 운영, 유지보수, 데이터베이스 구축 등)에 따라 영역·항목 조정 |

---

## II. 구조와 구성요소

### 가. 개념도

```mermaid
flowchart LR
    subgraph F ["감리 프레임워크"]
        direction TB
        subgraph T ["감리 시점"]
            P1["요구정의"] --- P2["설계"] --- P3["종료"]
        end
        subgraph D ["감리 영역 (구축 사업)"]
            D1["사업관리·품질보증"] --- D2["응용시스템"] --- D3["데이터베이스"] --- D4["시스템 구조·보안"]
        end
        subgraph V ["감리 관점"]
            V1["과업 이행"] --- V2["품질"] --- V3["준거성"]
        end
    end
    F -.->|"교차 조합"| CK["점검항목"]
    CK -->|"검증"| R["감리수행결과보고서<br/>(문제점, 개선 권고)"]
```

- 사업 진행 시점마다 영역별 감리원이 관점을 적용해 점검항목을 도출·검증하고 결과를 보고

### 나. 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 감리 시점 | 요구정의 | 요구사항 명확성, 제안서·계약 대비 과업 범위 확정 |
| | 설계 | 요구사항이 설계에 누락 없이 반영되었는지(추적성) |
| | 종료 | 구현·시험 결과, 운영 전환 준비 |
| 감리 영역 | 사업관리·품질보증 | 일정·위험·의사소통·[[형상 관리]], 품질보증 활동 |
| | 응용시스템 | 기능 구현, 화면·인터페이스, 테스트 |
| | [[데이터베이스]] | 데이터 모델, 정규화, 데이터 이관 정합성, 성능 |
| | 시스템 구조·보안 | H/W·N/W 아키텍처, 성능, [[시큐어코딩]], 접근통제 |
| 감리 관점 | 과업 이행 | 계약·요구사항의 이행 여부 |
| | 품질 | 기능성·성능·신뢰성 등 품질 특성 충족 |
| | 준거성 | 법·지침·표준 준수 |

## III. 비교 및 동향

### 가. 전통적 감리 vs 애자일·클라우드 사업 감리

| 비교 항목 | 전통적 (폭포수) | 애자일·클라우드 |
| --- | --- | --- |
| 점검 시점 | 요구정의·설계·종료 단계 | 반복 주기에 맞춘 수시 점검 |
| 점검 영역 | 응용, DB, 인프라 | [[MSA (Micro Service Architecture)\|MSA]], [[컨테이너]], API, 클라우드 보안 인증([[CSAP]]) |
| 점검 대상 | 산출물 문서 | 동작하는 SW, 소스코드, 파이프라인 |
| 결함 식별 | 단계 말 사후 식별 | CI/CD 내 조기 식별 |

### 나. 동향

- **신기술 특화 감리**: AI·빅데이터·클라우드 사업별 점검 항목 보완 ([[인공지능 감리]], [[빅데이터 감리]], [[클라우드 감리]])
- **도구 기반 감리**: [[SAST]]·[[DAST]]·성능 측정 결과를 감리 증적으로 활용해 정량 판단 강화
