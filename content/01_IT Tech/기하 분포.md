# 기하 분포 (Geometric Distribution)

---

## I. 첫 성공까지의 대기 횟수, 기하 분포의 개요

### 가. 정의

- 성공 확률 $p$인 [[베르누이 분포|베르누이 시행]]을 독립적으로 반복할 때 **처음 성공할 때까지의 시행 횟수**가 따르는 이산확률분포, $X \sim Geo(p)$

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 모수 | 성공 확률 $p$ 하나로 분포 결정 |
| 두 가지 정의 | 총 시행 횟수 $X \in \{1,2,\dots\}$ 또는 첫 성공 전 실패 횟수 $Y = X-1$ (아래는 총 시행 횟수 기준) |
| 무기억성 | $P(X > m+n \mid X > m) = P(X > n)$, 과거 실패가 이후 확률에 영향 없음 |
| 용도 | 사건이 일어날 때까지의 대기 횟수 모델링 |

- $k-1$번 연속 실패(각 $1-p$) 후 $k$번째에 성공($p$)하는 확률을 곱해 PMF를 얻음

### 나. 주요 통계량

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 모수 | 성공 확률 $p$ | 1회 시행에서 사건이 일어날 확률, 실패 확률 $q = 1-p$ |
| 확률 함수 | PMF | $P(X=k) = (1-p)^{k-1}p$, $k = 1, 2, \dots$ |
| | CDF | $P(X \le k) = 1-(1-p)^k$ |
| 통계량 | 기댓값 | $E(X) = 1/p$ (예: $p=0.1$이면 평균 10회) |
| | 분산 | $V(X) = (1-p)/p^2$ |

## III. 비교 및 동향

### 가. 관련 분포 비교

| 비교 항목 | 기하 분포 | 음이항 분포 | 지수 분포 |
| --- | --- | --- | --- |
| 확률변수 | 첫 성공까지 시행 횟수 | $r$번째 성공까지 시행 횟수 | 다음 사건까지 연속 시간 |
| 유형 | 이산 | 이산 | 연속 |
| 관계 | 음이항 분포의 $r=1$ 특수형 | 기하 분포 $r$개의 합 | 기하 분포의 연속형 대응 |
| 무기억성 | 있음 (이산 분포 중 유일) | 없음 ($r>1$) | 있음 (연속 분포 중 유일) |

### 나. 동향

- **품질·[[신뢰성]] 공학**: 첫 불량 발견, 첫 고장까지의 검사·작동 횟수 모델링으로 검사 주기·교체 시기 산정
- **마케팅·네트워크**: 첫 구매·클릭까지 필요한 접촉 수, 패킷 재전송(ARQ)에서 첫 성공까지의 전송 횟수 분석
