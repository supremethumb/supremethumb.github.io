# 인공지능 (AI) 도입 사업비 산정 절차

---

## I. SW 대가산정의 패러다임 전환, AI 도입 사업비 산정의 개요

### 가. 인공지능 도입 사업비 산정 절차의 정의
- 기존 기능점수(FP) 방식으로는 측정하기 어려운 AI 도입 사업에서, 서비스 이용료(구독/API)와 데이터 가공·모델 튜닝을 위한 커스터마이징 투입공수(M/M)를 결합하여 적정 예산 대가를 산출하는 체계적인 원가 산정 절차이다.

### 나. AI 도입 사업비 산정의 등장 배경 및 주요 특징

| 구분 | 주요 내용 |
| --- | --- |
| 기능점수(FP) 한계 극복 | 화면(UI)이나 단순 트랜잭션 수(CRUD)가 아닌 데이터 정제, 하이퍼파라미터 튜닝 등 AI 특유의 비기능적 공수 반영 |
| 클라우드 서비스 요금 반영 | 온프레미스 구축형 외에 클라우드 기반 API 호출료, 토큰 종량제, 구독형 SaaS 라이선스 비용 분리 산정 |
| 전문작업비 현실화 | KOSA(한국소프트웨어산업협회) SW 대가산정 가이드 내 AI 커스터마이징 전문작업비(M/M) 명문화 |
| 고가 GPU 인프라 분리 | 대규모 파운데이션 모델 훈련 및 서빙을 위한 GPU/NPU 클라우드 인프라 대관 비용을 순수 개발비와 분리 산정 |

## II. AI 도입 사업비 산정의 개념도 및 핵심 구성 요소

### 가. AI 도입 사업비 산정 프로세스

```mermaid
flowchart LR
    subgraph 1. 사전 준비 단계
        A["도입 대상 AI 식별<br/>(요구기능/목표 수준 파악)"]
    end
    
    subgraph 2. 비용 산정 단계
        direction TB
        B["서비스 이용료 산정<br/>(API / 구독료 / 라이선스)"]
        C["커스터마이징 작업비 산정<br/>(투입공수: 모델 튜닝, 연계)"]
        D["환경 구축비 산정<br/>(데이터 정제, GPU 인프라)"]
    end
    
    subgraph 3. 총 사업비 산정
        E["최종 사업비 확정<br/>(제경비 및 기술료 포함)"]
    end
    
    A --> B
    A --> C
    A --> D
    B & C & D --> E

```

* 인공지능 도입 대가는 단일 기능 규모(FP) 중심에서 벗어나, 서비스 이용료 + 커스터마이징(M/M) + 별도 환경구축비([[GPU]], 데이터)의 합산 구조로 산출됨

### 나. AI 도입 사업비 산정 체계의 핵심 요소

| 구분 | 요소기술(키워드) | 세부 설명 |
| --- | --- | --- |
| **사전 준비** | AI 수준 및 아키텍처 식별 | - 사업 목표에 부합하는 AI 기능 수준과 서비스 방식(On-Prem, Cloud API) 정의 |
| **요금 항목** | 서비스 이용료 (구독형) | - 클라우드 솔루션 이용에 따른 구독형 정액 요금 또는 API 호출량 기반 종량제 비용 |
| **요금 항목** | 환경 구축비 (인프라) | - 대규모 연산이 필수적인 AI 모델 학습 및 추론을 위한 고성능 GPU/[[NPU]] 컴퓨팅 사용료 |
| **전문 작업** | 데이터 준비 및 가공비 | - 원시 데이터 수집, 정제 및 라벨링([[Annotation]]) 등 데이터 품질 고도화에 투입되는 비용 |
| **전문 작업** | AI 모델 튜닝비 (커스터마이징) | - 도메인 특화 파인튜닝([[Fine-Tuning\|Fine-tuning]]), [[프롬프트 엔지니어링]], RAG 파이프라인 구축 비용 |
| **산정 방식** | 투입공수 (M/M) 산정 | - AI 아키텍트, 데이터 엔지니어 등 고숙련 인력의 직접 인건비를 투입공수 기반으로 산출 |
| **산정 방식** | 일반 기능점수(FP) 병행 | - AI 외의 업무 화면(UI), DB 연동 등 일반 어플리케이션 개발 영역은 2024년 상향된 FP 단가(605,784원) 적용 |
| **원가 보정** | 제경비 및 기술료 | - 투입 인력 기반 개발원가 산출 후 기업의 제경비 및 이윤(기술료)을 합산하여 최종 사업비 확정 |

## III. 일반 SW 대가산정(FP)과 AI 도입 대가산정 비교 및 향후 전망

### 가. 일반 SW 개발 대가산정 vs AI 도입 대가산정 비교

| 비교 항목 | 일반 SW 개발 대가 (기존) | AI 솔루션/서비스 도입 대가 (신규) |
| --- | --- | --- |
| **핵심 산정 기준** | 소프트웨어 기능 규모 (기능점수, FP) | 서비스 구독료 + 커스터마이징 전문작업 (투입공수) |
| **주요 원가 동인** | 데이터 입출력 수(TR) 및 내부 논리파일(ILF) | 모델 튜닝 시간, 고품질 데이터 구축량, API 호출량 |
| **인프라 비중** | 보조적 (일반 웹/WAS/DB 서버 환경) | 핵심적 (고가 GPU 가속기 등 기계 자원 비용 분리 산정) |
| **제도적 한계/특징** | 고정된 단가로 인해 복잡도 높은 AI 작업 미반영 | 데이터 준비, 아키텍처 구성 공수를 M/M 기반 명확화 및 현실화 보완 중 |

### 나. 최신 동향 및 향후 전망
- **KOSA 대가산정 가이드라인 고도화**: 한국소프트웨어산업협회가 '전문작업비'를 '커스터마이징 작업비용'으로 명칭을 현실화하고, 프롬프트 엔지니어링 및 RAG 파이프라인 구축 공수를 투입공수(M/M) 표준에 명문화.
- **공공부문 초거대 AI 사업비 산정 체계 정착**: 디지털서비스 전문계약제도 및 혁신제품 지정과 연계하여, 공공 클라우드 기반 AI API 사용료와 온프레미스 보안 환경 구축비를 분리 산정하는 예산 가이드라인 확산.
- **가치 기반(Value-based) 대가 모델로의 진화**: 단순 투입 인력(M/M) 중심 정산을 넘어, AI 모델의 업무 자동화율, 비용 절감 기여도 및 목표 KPI 달성 여부에 따라 성과급을 차등 지급하는 가치 기반 계약 체계 연구 가속화.
