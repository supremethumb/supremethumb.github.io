# 디지털 포렌식 (Digital Forensic)

---

## I. 디지털 증거의 법적 효력 확보, 디지털 포렌식의 개요

### 가. 정의

- PC·모바일·서버·클라우드 등의 디지털 데이터를 **적법한 절차로 수집·보존·분석하여 법정에서 증거능력을 인정받도록** 하는 과학적 조사 기법

### 나. 기본 원칙

| 구분 | 내용 |
| --- | --- |
| 정당성 | 영장 등 적법 절차로 수집한 증거만 인정 |
| 무결성 | 해시값으로 수집 이후 변경 없음을 입증 |
| 연계보관성 | 획득·이송·보관·분석·제출 전 과정의 이력 기록 (Chain of Custody) |
| 재현성 | 같은 절차로 분석하면 같은 결과 도출 |
| 신속성 | 휘발성 데이터는 소멸 전 신속 수집 |

---

## II. 수행 절차 및 핵심 기술

### 가. 수행 절차

```mermaid
flowchart LR
    subgraph CoC["연계보관성 · 무결성 유지"]
        direction LR
        A["사전 준비<br/>영장 · 장비"] --> B["증거 수집<br/>이미징 · 메모리 덤프"]
        B --> C["이송 · 보관<br/>봉인 · 해시 기록"]
        C --> D["조사 · 분석<br/>사본 분석"]
        D --> E["보고서 작성"]
    end
    E --> F{"법정 제출"}
```

- 원본은 봉인 보관하고 해시로 검증된 사본만 분석하며, 모든 취급 이력을 문서화

### 나. 핵심 기술

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 수집 | [[디스크 이미징]] | 저장매체 전체 섹터를 비트 단위 복제 |
| | 쓰기 방지기 | 수집 중 원본 변경 차단 |
| | 라이브 포렌식 | 메모리·네트워크 연결·프로세스 등 휘발성 데이터 수집 |
| 검증 | 해시값 | MD5·SHA-256으로 원본·사본 동일성 입증 |
| 분석 | 파일 카빙 | 파일시스템 정보 없이 헤더·푸터 시그니처로 파일 복원 |
| | 타임라인 분석 | MAC Time(수정·접근·변경/생성), 레지스트리, 로그로 행위 재구성 |
| | 슬랙·비할당 영역 분석 | 은닉·삭제 데이터 추출 |
| 분야 | 모바일·[[클라우드 포렌식\|클라우드]]·네트워크 포렌식 | 대상 환경별 수집·분석 기법 |

---

## III. 비교 및 동향

### 가. 안티 포렌식 vs 대응 기법

| 비교 항목 | [[안티 포렌식]] | 대응 기법 |
| --- | --- | --- |
| 데이터 파괴 | 와이핑, 디가우싱 | 볼륨 섀도 복사본·백업·클라우드 동기화본 확보 |
| 데이터 은닉 | 스테가노그래피, 슬랙 은닉 | 스테그분석, 슬랙 영역 분석 |
| 데이터 변조 | 타임스탬프 조작, [[암호화]] | 타임라인 교차 검증, 메모리 내 키 추출 |
| 흔적 제거 | 로그 삭제 | 원격 로그 서버·SIEM 로그 확보 |

### 나. 동향

- **클라우드 포렌식**: CSP의 스냅샷·API 기반 원격 증거 수집과 공동 책임 모델에 따른 협조 절차
- **AI 기반 트리아지**: 대용량 증거에서 관련 데이터 자동 선별, 딥페이크 탐지
- **포렌식 준비도**: [[전자증거개시제도|e-Discovery]] 대응을 위해 기업이 로그·증거 보존 체계를 사전 구축
