# 딥테크 (Deep Tech)

---

## I. 과학·공학 혁신으로 진입장벽을 만드는, 딥테크의 개요

### 가. 정의

- **과학적 발견이나 고도의 공학 혁신에 기반**해 모방이 어렵고, 기후·질병·에너지 등 근본적 문제 해결을 목표로 하는 기술과 그 기술 기반 기업 (S. Chaturvedi, 2014 용어 제시)

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 고위험·장기 | 연구 → 상용화까지 수년~10년 이상, 실패 위험 큼 |
| 대규모 자본 | 설비·실증 비용이 커 장기 투자(인내 자본) 필요 |
| 높은 진입장벽 | 특허·노하우·인재가 경쟁 우위의 원천 |
| 융합 | AI·바이오·소재·양자 등 학제 간 결합 |

## II. 딥테크의 사업화 경로 및 기술 분야

### 가. 사업화 경로

```mermaid
flowchart LR
    A["기초 연구<br/>대학·연구소"] -->|"기술 이전·창업"| B["기술 검증<br/>PoC, 시제품"]
    B -->|"죽음의 계곡"| C["실증·스케일업<br/>파일럿, 인증"]
    C --> D["상용화<br/>양산, 시장 창출"]
```

- 연구 성과를 창업·이전으로 사업화하되, 시제품 이후 실증·양산 단계까지 자금이 끊기는 '죽음의 계곡'을 넘는 것이 핵심 과제

### 나. 주요 기술 분야

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 디지털 | AI·반도체 | [[NPU]], [[뉴로모픽 칩]], 파운데이션 모델 |
| | 양자 기술 | 양자컴퓨팅·통신·센서 |
| 바이오 | 바이오·헬스 | 유전자 편집(CRISPR), mRNA, AI 신약 개발 |
| 에너지·환경 | 차세대 에너지 | 전고체 배터리, 소형모듈원전(SMR), 탄소 포집(CCUS) |
| 물리 시스템 | 모빌리티·로봇 | 자율주행, [[UAM]], 휴머노이드 |
| | 우주항공 | [[재사용]] 발사체, 저궤도 위성통신 |
| 신소재 | 첨단 소재 | 2차원 소재, 메타물질 |

## III. 섈로우테크 비교 및 동향

### 가. 섈로우테크 vs 딥테크

| 구분 | 섈로우테크 (Shallow Tech) | 딥테크 (Deep Tech) |
| --- | --- | --- |
| 혁신 대상 | 비즈니스 모델 (플랫폼, O2O) | 원천 기술 (과학·공학) |
| 주요 위험 | 시장 위험 (수요, 경쟁) | 기술 위험 (구현·양산 실패) |
| 투자 회수 | 상대적으로 짧음 | 장기, 대규모 설비 투자 |
| 경쟁 우위 | 네트워크 효과, 선점 | 특허·기술 노하우 |

### 나. 동향

- **정책 지원**: 국내 '초격차 스타트업 1000+'(2022~), 딥테크 팁스(2023~) 등 장기·대규모 R&D·투자 지원
- **실험실 창업 활성화**: 대학·출연연 기술 기반 창업과 대기업 실증 협력(오픈 이노베이션) 확대
- **AI의 연구 가속**: AlphaFold 등 AI가 소재·신약 탐색 기간을 단축하며 딥테크 R&D 방식 변화 ([[AI 기본법]] 등 제도 정비 병행)
