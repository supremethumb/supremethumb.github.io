# 가상메모리의 페이징과 세그멘테이션

---

## I. 고정 크기와 논리 단위, 페이징과 세그멘테이션의 개요

### 가. 정의

- **페이징(Paging)**: 가상 주소 공간을 **같은 크기의 페이지**로, 물리 메모리를 같은 크기의 프레임으로 나눠 비연속 할당하는 기법
- **[[세그멘테이션]](Segmentation)**: 프로그램을 코드·데이터·스택 등 **의미 있는 가변 크기 세그먼트**로 나눠 할당하는 기법

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 주소 변환 | [[MMU(Memory Management Unit)\|MMU]]가 매핑 테이블로 변환, TLB로 가속 |
| 페이징 | 외부 [[단편화]] 없음, 마지막 페이지에 내부 단편화 |
| 세그멘테이션 | 내부 단편화 없음, 가변 크기라 외부 단편화 발생 |
| [[가상 메모리]] 기반 | 필요한 부분만 적재(요구 페이징)해 물리 메모리보다 큰 프로그램 실행 |

- 페이징은 페이지와 프레임 크기가 같아 아무 빈 프레임에나 적재, 세그멘테이션은 크기가 제각각이라 맞는 빈 공간을 찾아 적재

### 나. 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 페이징 | 가상 주소 | 페이지 번호(p) + 오프셋(d) |
| | 페이지 테이블 (PMT) | p → 프레임 번호, 유효·보호·참조·변경 비트 |
| | PTBR | 페이지 테이블 시작 주소 레지스터 |
| | 다단계·역 페이지 테이블 | 큰 주소 공간의 테이블 크기 축소 |
| 세그멘테이션 | 가상 주소 | 세그먼트 번호(s) + 오프셋(d) |
| | 세그먼트 테이블 (SMT) | s → 시작 주소(Base)·길이(Limit)·보호 비트, d ≥ Limit이면 트랩 |
| 공통 | TLB | 최근 변환 결과 캐시 |
| | 페이지 폴트·세그먼트 폴트 | 미적재 또는 범위 위반 시 OS가 처리 |

## III. 비교 및 동향

### 가. 페이징 vs 세그멘테이션

| 비교 항목 | 페이징 | 세그멘테이션 |
| --- | --- | --- |
| 분할 기준 | 고정 크기 (예: 4KB) | 논리 단위, 가변 크기 |
| 주소 | 페이지 번호 + 오프셋 | 세그먼트 번호 + 오프셋 |
| 단편화 | 내부 단편화 | 외부 단편화 |
| 보호·공유 | 페이지 단위라 의미 단위 설정이 어려움 | 코드·데이터 단위로 보호·공유 용이 |
| 할당 | 빈 프레임 아무 곳 | 최초·최적 적합 등 배치 알고리즘 필요 |
| 사용자 관점 | 사용자에게 보이지 않음 | 프로그램 구조와 일치 |

### 나. 동향

- **페이지화된 세그멘테이션**: 세그먼트를 다시 페이지로 나눠 외부 단편화를 없애고 논리 단위 보호를 유지 (Multics, x86-32)
- **x86-64의 평탄화**: 64비트 모드에서는 세그먼트 Base를 대부분 0으로 고정하고 페이징 중심으로 보호, FS·GS만 스레드 지역 저장소에 활용
- **대형 페이지·5단계 페이징**: 2MB·1GB Huge Page로 TLB 효율을 높이고, LA57 5단계 페이징으로 57비트 가상 주소 지원
