# 연관성 분석 (Association Analysis)

---

## I. 함께 일어나는 패턴 찾기, 연관성 분석의 개요

### 가. 정의

- 트랜잭션 데이터에서 **함께 발생하는 항목 집합과 "A이면 B" 형태의 연관 규칙을 찾는 비지도 데이터 마이닝 기법** (장바구니 분석)

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 비지도 학습 | 정답 레이블 없이 동시 발생 패턴 탐색 |
| 해석 용이 | 규칙(A → B)이 직관적이라 바로 업무에 적용 |
| 평가 지표 | [[지지도]], 신뢰도, 향상도로 의미 있는 규칙만 선별 |
| 활용 | 교차 판매, 진열 최적화, 추천, 이상 패턴 탐지 |

---

## II. 분석 절차 및 구성요소

### 가. 연관 규칙 마이닝 절차

```mermaid
flowchart LR
    DB[("트랜잭션 DB")] --> F["1. 빈발 항목 집합 탐색<br/>(최소 지지도 이상)"]
    F --> R["2. 규칙 생성<br/>(최소 신뢰도 이상)"]
    R --> E["3. 규칙 평가<br/>(향상도 > 1 선별)"]
```

- 빈발 항목 집합 탐색이 계산의 대부분을 차지하며, Apriori·FP-Growth가 이 단계를 효율화

### 나. 지표와 알고리즘

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 평가 지표 | 지지도 (Support) | P(A∩B), 전체 거래 중 A·B를 함께 포함한 비율 |
| | 신뢰도 (Confidence) | P(B\|A) = P(A∩B) / P(A) |
| | 향상도 (Lift) | P(B\|A) / P(B), 1보다 크면 양의 연관, 1이면 독립 |
| 알고리즘 | [[Apriori 알고리즘\|Apriori]] | 빈발 집합의 부분집합도 빈발 → 후보 생성·가지치기, DB 반복 스캔 |
| | [[FP(Frequent Pattern) - Growth 알고리즘\|FP-Growth]] | FP-Tree로 압축, 후보 생성 없이 DB 2회 스캔 |
| | Eclat | 항목별 트랜잭션 ID 목록(수직 포맷) 교집합으로 계산 |
| | [[DHP(Direct Hashing & Pruning) 알고리즘\|DHP]] | 해시로 2-항목 후보를 줄이는 Apriori 개선 |
| 확장 | 순차 패턴 마이닝 | 시간 순서를 고려한 패턴 (GSP, PrefixSpan) |
| | 분산 처리 | Spark MLlib FPGrowth로 대규모 병렬 분석 |

---

## III. 비교 및 동향

### 가. Apriori vs FP-Growth

| 비교 항목 | Apriori | FP-Growth |
| --- | --- | --- |
| 원리 | 후보 생성 후 검증 | FP-Tree 기반 분할 정복 |
| DB 스캔 | 항목 집합 크기 단계마다 반복 | 2회 |
| 메모리 | 후보 집합이 커지면 부담 | 트리 압축으로 효율적 |
| 성능 | 대용량에서 느림 | 대용량에 유리 |

### 나. 동향

- **추천 시스템 결합**: 협업 필터링·임베딩 기반 추천과 함께 사용해 콜드 스타트 보완
- **그래프 기반 분석**: 그래프 DB에서 관계 경로를 탐색해 사기 탐지(FDS)·네트워크 분석에 활용
