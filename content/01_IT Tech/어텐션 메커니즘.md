# 어텐션 메커니즘 (Attention Mechanism)

---

## I. 중요한 정보에 집중하는 연산, 어텐션 메커니즘의 개요

### 가. 정의

- 출력을 만들 때 입력 전체를 똑같이 보지 않고, **현재 시점과 연관성이 높은 입력에 더 큰 가중치를 동적으로 부여**하여 문맥 벡터를 만드는 [[딥러닝]] 기법

### 나. 등장 배경 및 특징

| 구분 | 내용 |
| --- | --- |
| 정보 병목 해소 | [[seq2seq\|Seq2Seq]]의 고정 길이 컨텍스트 벡터에 모든 정보를 압축하던 한계 극복 |
| 장기 의존성 | [[RNN (Recurrent Neural Network)\|RNN]]·[[LSTM (Long Short-Term Memory)\|LSTM]]에서 문장이 길수록 앞 정보가 소실되는 문제 해결 |
| 병렬 처리 | 행렬 연산 기반으로 순차 처리 없이 병렬 계산 ([[트랜스포머]]의 핵심) |
| 해석 가능성 | 어텐션 가중치로 모델이 어디에 집중했는지 시각화 가능 |

---

## II. 동작 원리 및 핵심 요소

### 가. Scaled Dot-Product Attention

```mermaid
flowchart TD
    Q["Query (Q)<br/>찾고자 하는 기준"] --> M1
    K["Key (K)<br/>비교 대상의 특징"] --> M1
    M1["MatMul: Q·Kᵀ<br/>(유사도 점수)"] --> S["Scale: ÷ √dₖ"] --> Mask["Mask (선택)<br/>미래 토큰 차단"] --> SM["Softmax<br/>(가중치)"]
    SM --> M2
    V["Value (V)<br/>실제 정보"] --> M2["MatMul: 가중치 · V"] --> O["Attention 출력<br/>(가중합)"]
```

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V$$

- Q와 K의 내적으로 [[유사도]]를 구하고, $\sqrt{d_k}$로 나눠 Softmax 포화(기울기 소실)를 막은 뒤 V를 가중합

### 나. 핵심 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 입력 | Query · Key · Value | 기준(Q), 검색 대상의 특징(K), 실제 정보(V) |
| 연산 | Attention Score / Softmax | 유사도 점수를 합이 1인 가중치로 정규화 ([[소프트맥스 정규화]]) |
| 변형 | Self-Attention | Q·K·V가 같은 시퀀스에서 나와 문장 내부 관계 파악 ([[자기 집중]]) |
| | Cross-Attention | 디코더의 Q가 인코더의 K·V를 참조 |
| | Multi-Head Attention | 여러 헤드로 병렬 수행해 다양한 관점의 관계 학습 |
| | Masked Attention | 디코더 학습 시 미래 토큰을 −∞로 마스킹 |
| 추론 최적화 | KV Cache | 이전 토큰의 K·V를 저장해 생성 시 중복 연산 제거 |
| 범위 조절 | Local / Global Attention | 윈도우 내 토큰만 보거나 전체를 참조 |

## III. 비교 및 최신 동향

### 가. 기본 Seq2Seq vs 어텐션 기반 모델

| 비교 항목 | 기본 Seq2Seq | 어텐션 기반 (Transformer 등) |
| --- | --- | --- |
| 정보 압축 | 고정 크기 벡터 하나 | 시점마다 동적 문맥 벡터 |
| 장기 의존성 | 길수록 앞 정보 소실 | 거리와 무관하게 직접 참조 |
| 연산 | 순차 처리 | 병렬 처리 |
| 긴 문장 품질 | 급격히 하락 | 높게 유지 |

### 나. MHA vs MQA vs GQA

| 비교 항목 | MHA | MQA | GQA |
| --- | --- | --- | --- |
| 구조 | 헤드마다 별도 K·V | 모든 헤드가 K·V 1개 공유 | 헤드 그룹별로 K·V 공유 |
| KV Cache | 가장 큼 | 가장 작음 | 작음 |
| 추론 속도 | 느림 | 매우 빠름 | 빠름 |
| 정확도 | 가장 높음 | 다소 낮음 | MHA에 근접 |
| 예시 | 초기 Transformer, GPT-3 | PaLM | Llama 2/3, Mistral |

### 다. 동향

- **FlashAttention**: [[GPU]]의 SRAM–[[HBM]] 간 데이터 이동을 타일링으로 줄여 속도·메모리 개선, 사실상 표준
- **초장문 처리**: $O(n^2)$ 복잡도를 줄이는 Sparse·Ring·Linear Attention으로 수백만 토큰 컨텍스트 지원
- **대안 아키텍처**: Mamba(SSM), RWKV 등 어텐션 없이 선형 복잡도를 갖는 모델 연구
