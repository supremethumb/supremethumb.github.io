### 나. GoF 디자인 패턴의 3대 분류 및 핵심 요소

| 분류 | 핵심 패턴 | 설명 |
| :--- | :--- | :--- |
| **생성** | - [[Singleton (전역 인스턴스)|Singleton]]<br>- [[Factory Method (생성 위임)|Factory Method]]<br>- Builder | - 오직 1개의 [[인스턴스]]<br>- 서브클래스로 위임<br>- 생성과 표현 분리 |
| **구조** | - Adapter<br>- Facade<br>- Proxy | - 인터페이스 변환<br>- 단일 인터페이스 제공<br>- 객체의 대리자 역할 수행 |
| **행위** | - [[Observer (상태 변화 통지)|Observer]]<br>- [[Strategy (알고리즘 교체)|Strategy]]<br>- Command | - 의존 객체에 변화 송신<br>- 독립적 [[알고리즘]] 변경가능<br>- 의존성 분리, 실행취소 지원 |

* [[클라우드 네이티브]] 환경으로 지속적인 패턴 확장.
