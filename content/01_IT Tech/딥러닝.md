# 딥러닝 (Deep Learning)

---

## I. 데이터 특징의 자동 추출을 위한 기계학습, 딥러닝의 개요

### 가. 딥러닝의 정의
- 인간의 뇌 신경망을 모방한 다층 인공신경망(ANN)을 기반으로, 대규모 원시 데이터로부터 유의미한 특징 표현(Representation)을 스스로 추출하고 가중치를 학습하는 심층 기계학습 기술이다.

### 나. 딥러닝의 등장 배경 및 주요 특징

| 구분 | 주요 내용 |
| --- | --- |
| 수동 특징 추출 극복 | 기존 머신러닝의 도메인 전문가 수작업 특징 엔지니어링(Feature Engineering) 한계 완전 해소 |
| 빅데이터와 컴퓨팅 파워 | 인터넷·모바일로 축적된 대규모 데이터와 GPU/NPU 기반 대규모 병렬 행렬 연산 발전 결합 |
| 비선형 표현 학습 | 다층 은닉층과 비선형 활성화 함수를 통해 고차원 데이터의 복잡한 추상적 패턴 학습 가능 |
| 스케일링 법칙(Scaling) | 데이터 크기와 모델 파라미터가 커질수록 성능이 지수적으로 향상되는 스케일링 법칙 정립 |

---

## II. 딥러닝의 동작 원리 및 핵심 기술 요소

### 가. 딥러닝의 아키텍처 및 학습 동작 원리

```mermaid
flowchart LR
    subgraph Data["입력 (Input)"]
        X["입력 데이터 (X)"]
    end

    subgraph DNN["심층 신경망 (Deep Neural Network)"]
        direction LR
        L1(("입력층<br>Input Layer")) --> H1(("은닉층 1<br>Hidden Layer"))
        L1 --> H2(("은닉층 1<br>Hidden Layer"))
        H1 --> H3(("은닉층 N<br>Hidden Layer"))
        H2 --> H3(("은닉층 N<br>Hidden Layer"))
        H3 --> O1(("출력층<br>Output Layer"))
    end

    subgraph Optimize["최적화 (Optimization)"]
        direction TB
        Pred["예측값 (Y')"]
        Loss{"손실 함수<br>(Loss Function)"}
        True["정답 레이블 (Y)"]
    end

    X --> DNN
    DNN == "순전파 (Forward Propagation)" ==> Pred
    Pred --> Loss
    True --> Loss
    Loss -. "역전파 (Backpropagation)<br>가중치(W) 업데이트" .-> DNN

```

* 입력 데이터가 다층 신경망을 거쳐 예측값을 산출(순전파)하고, 정답과의 오차(Loss)를 최소화하는 방향으로 가중치와 편향을 갱신([[역전파]])하여 모델을 최적화함

### 나. 딥러닝의 핵심 기술 요소

| 구분 | 핵심 기술 | 설명 |
| --- | --- | --- |
| **네트워크 구조** | **[[CNN]]** (합성곱 신경망) | 이미지, 영상의 공간적 특징(Spatial Feature) 추출에 특화 |
| **네트워크 구조** | **[[RNN (Recurrent Neural Network)\|RNN]] / [[LSTM (Long Short-Term Memory)\|LSTM]]** | 순차 데이터(시계열, 자연어 등)의 시간적 흐름(Temporal) 처리 |
| **네트워크 구조** | **Transformer** | 어텐션(Self-Attention) 메커니즘 기반 대규모 병렬 처리 구조 |
| **학습 [[알고리즘]]** | **역전파** (Backpropagation) | 출력 오차를 출력층에서 은닉층으로 거슬러 전파하며 가중치 갱신 |
| **최적화 기법** | **[[경사하강법]]** (SGD, AdamW) | 손실 함수의 기울기(Gradient)를 계산하여 오차를 최소화하는 방향 탐색 |
| **활성화 함수** | **ReLU, GELU** | 신경망에 비선형성을 부여하여 복잡한 패턴 학습 가능 (기울기 소실 방지) |
| **과적합 방지** | **[[Dropout]]** | 학습 시 신경망의 노드를 무작위로 비활성화하여 과적합 방지 |
| **과적합 방지** | **Batch Normalization** | 미니배치 단위로 입력 분포를 정규화하여 학습 속도 및 안정성 향상 |

## III. 머신러닝과 딥러닝 비교 및 최신 동향

### 가. 머신러닝과 딥러닝의 핵심 비교

|**비교 항목**|**전통적 머신러닝 (Traditional ML)**|**딥러닝 (Deep Learning)**|
|---|---|---|
|**특징 추출 (Feature Extraction)**|**전문가 개입 (Hand-crafted)**<br>- 인간이 직접 특징을 정의 및 추출|**자동화 (Representation Learning)**<br>- 신경망이 데이터로부터 스스로 특징 학습|
|**데이터 의존도**|소규모/중규모 데이터에서도 성능 발휘|대규모 데이터 필수 (Scale Law 적용)|
|**하드웨어 요구사항**|일반 [[CPU]] 환경에서도 구동 가능|고성능 병렬 처리 GPU/[[NPU]] 필수|
|**해석 가능성 ([[XAI]])**|화이트박스([[의사결정나무]] 등) 해석 용이|블랙박스 모델로 결과 도출 과정 해석 어려움|
### 나. 딥러닝의 발전 전망 및 최신 동향
- **초거대 언어 모델(LLM) 및 AGI 진화**: 트랜스포머 아키텍처 기반의 수천억~조 단위 파라미터 사전 학습을 통해 인간 수준의 추론과 문제 해결을 수행하는 AGI로 진화
- **네이티브 멀티모달(Omni/Multimodal) 통합**: 텍스트, 음성, 비전, 비디오를 개별 모듈이 아닌 단일 통합 신경망에서 실시간으로 스트리밍 처리하는 옴니 모델 확산
- **온디바이스 경량화 및 실용화**: 양자화(AWQ/FP4), 가지치기, 지식 증류(Distillation)를 통해 스마트폰, PC, 자율주행 차량 NPU에서 저전력 로컬 구동 가능한 소형 딥러닝 모델 대중화
