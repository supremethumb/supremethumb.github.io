# 구독경제 (Subscription Economy)

---

## I. 판매에서 관계로, 구독경제의 개요

### 가. 정의

- 고객이 **정기적으로 요금을 내고 상품·서비스·콘텐츠를 계속 이용**하는 사업 모델로, 일회성 판매 대신 장기 고객 관계에서 반복 수익을 얻는 경제 (Zuora 창업자 T. Tzuo가 용어 대중화)

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 반복 수익 | 정기 결제로 예측 가능한 매출(MRR·ARR) 확보 |
| 관계 중심 | 신규 획득보다 유지(Retention)와 이탈(Churn) 관리가 핵심 |
| 데이터 축적 | 이용 데이터로 개인화·가격 정책 개선 |
| 소유 → 이용 | 고객은 초기 비용 부담 없이 최신 상품·서비스 이용 |

- 획득(Acquisition) → 유지(Retention) → 확장(Expansion, 업셀·교차판매)의 선순환을 CLV·CAC·이탈률 지표로 관리하며, 지속 가능 조건은 일반적으로 CLV > CAC

### 나. 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 유형 | 무제한 이용형 | 정액으로 무제한 접근 (OTT, 음원, SaaS) |
| | 정기 배송형 | 생필품·식품 등을 주기적으로 배송 |
| | 렌털·큐레이션형 | 고가 제품 렌털, 전문가 선별 상품 제공 |
| 지표 | CLV (고객 생애 가치) | 고객 1명이 이용 기간 동안 주는 이익 |
| | CAC (고객 획득 비용) | 마케팅·영업비 ÷ 신규 고객 수 |
| | 이탈률 (Churn) | 기간 내 해지 고객 비율 (자발적·비자발적) |
| 운영 | 구독 관리·빌링 | 요금제, 업·다운그레이드, 일시정지, 결제 실패 재시도 |
| | 개인화 | 이용 데이터 기반 추천·맞춤 오퍼로 이탈 방지 |

## III. 판매 모델 비교 및 동향

### 가. 전통적 판매 vs 구독

| 구분 | 전통적 판매 | 구독 |
| --- | --- | --- |
| 수익 | 판매 시점 일회성 | 정기 반복 수익 |
| 고객 관계 | 거래 후 단절 | 지속적 관계, 데이터 축적 |
| 핵심 지표 | 판매량, 마진 | MRR·ARR, CLV, 이탈률 |
| 위험 | 재고 | 이탈 증가, 구독 피로 |

### 나. 동향

- **유지 전략 강화**: 신규 획득 비용 상승으로 해지 대신 일시정지 제공, 번들 상품, 결제 실패 자동 재시도 등 이탈 방지에 집중
- **광고 결합 저가 요금제**: OTT 등이 광고 포함 요금제를 도입해 가격 민감 고객 유지
- **소비자 보호 규제**: 해지 방해·무단 갱신을 막는 규제 확대 (국내 전자상거래법 개정으로 다크패턴 규제 2025년 시행, 영국 DMCC법 구독 계약 규정 도입 예정)
