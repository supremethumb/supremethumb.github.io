# Z-검정 (Z-test, Z-statistic Hypothesis Testing)

---

## I. 정규분포 가정을 바탕으로 모평균의 유의성을 검정하는 통계적 가설검정 기법, Z-검정의 개요

### 가. Z-검정의 정의
- 모집단의 분산(모분산)을 알고 있거나 표본 크기가 충분히 클 때($n \ge 30$), 중심극한정리에 기반하여 정규분포를 따르는 Z-통계량을 산출하고 귀무가설의 기각 여부를 판정하는 모수적 가설검정 기법이다.

### 나. Z-검정의 등장 배경 및 주요 특징

| 구분 | 주요 내용 |
| --- | --- |
| 대표본 정규 근사 | 모집단 분포와 무관하게 표본 크기가 충분히 클 경우 표본평균의 분포가 정규분포에 수렴(중심극한정리) |
| 표준정규분포 기준 | 평균 0, 분산 1인 표준정규분포($Z \sim N(0, 1)$) 임계값과 Z-통계량을 직접 비교하여 판정 |
| t-검정 대비 차이점 | 모분산이 기지(Known)이거나 대표본일 때 적용하며, 소표본·미지 분산 환경에서는 t-검정을 적용 |
| 대규모 A/B 테스트 | 빅데이터 및 디지털 마케팅 환경에서 전환율 등 대규모 표본의 가설 검증 파이프라인에 널리 활용 |

---

## II. Z-검정의 검정 통계량 아키텍처 및 핵심 기술 요소

### 가. Z-검정의 가설 검증 및 통계량 산출 아키텍처

```mermaid
flowchart TB
    subgraph Data["모집단 및 표본 데이터"]
        POP["모집단 분포 (모평균 μ, 모분산 σ²)"] --> SAMP["표본 추출 (크기 n, 표본평균 x̄)"]
    end

    subgraph Z_Engine["Z-값(Statistic) 산출 엔진"]
        direction TB
        CALC["Z = (x̄ - μ) / (σ / √n)"]
    end

    subgraph Decision["유의수준 판정 영역"]
        CRIT["임계값 비교 (|Z| > Z_{α/2})"] --> |"귀무가설 기각"| REJ["유의한 차이 있음 (Reject H₀)"]
        CRIT --> |"기각 실패"| ACC["통계적 유의성 없음 (Fail to Reject H₀)"]
    end

    SAMP --> Z_Engine
    Z_Engine --> Decision

```

* 모집단에서 추출한 표본 평균($\bar{x}$)과 알려진 모표준편차($\sigma$)를 활용해 Z-통계량을 계산하고, 표준정규분포의 임계값과 비교하여 가설을 채택하거나 기각하는 구조

### 나. Z-검정의 핵심 구성 요소 및 기술 요소

| 분류 | 요소기술(키워드) | 세부 설명 |
| --- | --- | --- |
| 통계량 모델 | Z-통계량 (Z-Statistic) | 표본평균과 모평균의 차이를 표준오차로 나누어 표준화한 값 |
| 기본 가정 | 대표본 조건 (Large Sample) | 중심극한정리에 의해 표본 크기 $n \ge 30$ 이상일 때 정규성 근사 확보 |
| 분포 기준 | 표준정규분포 (Standard Normal) | 평균이 0이고 분산이 1인 [[정규분포]]($N(0, 1)$) 곡선 상의 확률 계산 |
| 가설 설정 | 양측 / 단측 검정 (Two/One-tailed) | 대립가설의 방향성(차이가 있다 vs 크다/작다)에 따른 임계 영역 설정 |
| 오류 제어 | 유의수준 ($\alpha$) 및 [[유의확률\|p-value]] | 제1종 오류의 허용 한계(예: 0.05)를 설정하여 검정 결과의 [[신뢰성]] 확보 |
| 비교 대조 | Z-검정 vs t-검정 | 모분산의 기지 여부 및 표본 크기에 따라 Z-분포 또는 t-분포 선택 적용 |
| 확장 응용 | 비율 검정 (Two-proportion Z-test) | 두 독립된 집단의 성공 비율(p1, p2) 간의 차이를 검정하는 이항 비율 모델 |
| 최신 트렌드 | A/B 테스팅 및 대규모 분석 | 웹 서비스 및 마케팅 성과 측정을 위한 대규모 실시간 Z-통계 검증 자동화 |

## III. Z-검정 vs t-검정 비교 및 최신 동향

### 가. Z-검정 vs t-검정 비교

| 비교 항목 | Z-검정 (Z-test) | [[t-검정 (t-test)]] |
| --- | --- | --- |
| **모분산 ($\sigma^2$) 조건** | 모집단의 분산/표준편차를 **알고 있는 경우** (Known) | 모집단의 분산/표준편차를 **모르는 경우** (Unknown) |
| **표본 크기 ($n$)** | 주로 대표본 ($n \ge 30$) 환경에 적용 (중심극한정리) | 소표본 ($n < 30$) 환경에서도 널리 활용 가능 |
| **사용하는 확률 분포** | 표준정규분포 ($Z \sim N(0, 1)$) | 자유도($\nu = n-1$)를 따르는 학생 t-분포 |
| **표본오차 추정** | 모표준편차 기반 ($\sigma / \sqrt{n}$) | 표본표준편차 기반 ($s / \sqrt{n}$) |

### 나. 한계 극복 및 최신 발전 동향
- **빅데이터 A/B 테스팅 표준화**: 사용자 수가 수만~수백만 건에 달하는 디지털 서비스 및 플랫폼 A/B 테스트에서 중심극한정리에 기반한 2-표본 비율 Z-검정(Two-proportion Z-test) 파이프라인 표준 채택
- **순차적 검정(Sequential Testing) 결합**: A/B 테스트 조기 종료에 따른 제1종 오류(False Positive) 팽창을 방지하기 위해 순차적 가설검정(SPRT) 및 베이지안 통계 기법과 결합하여 운영
- **AI/ML 모델 서빙 모니터링**: 서빙 중인 기계학습 모델의 데이터 드리프트(Data Drift) 및 컨셉 드리프트 발생 여부를 실시간 감지하기 위해 통계적 가설검정 기반 모니터링 자동화 확산
