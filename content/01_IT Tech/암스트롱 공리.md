# 암스트롱 공리 (Armstrong's Axioms)

---

## I. 함수 종속 추론 규칙, 암스트롱 공리의 개요

### 가. 정의

- 주어진 [[함수적 종속성]] 집합 F로부터 **논리적으로 함축되는 모든 함수 종속(F⁺)을 유도하는 추론 규칙** (W. W. Armstrong, 1974)

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 건전성 (Soundness) | 공리로 유도한 종속은 항상 성립 |
| 완전성 (Completeness) | 성립하는 모든 종속을 공리로 유도 가능 |
| 활용 | 후보키 탐색, 최소 커버 도출, 정규형 판정 |
| 구성 | 기본 규칙 3개(반사·첨가·이행) + 유도 규칙 3개(분해·합집합·의사이행) |

---

## II. 추론 규칙

### 가. 폐포 도출 흐름

```mermaid
flowchart LR
    F["함수 종속 집합 F<br/>예: X → Y, Y → Z"] --> R["암스트롱 공리 반복 적용"]
    R --> FP["폐포 F⁺<br/>예: X → Z 추가"]
    FP --> K["후보키 · 최소 커버 · 정규형 판정"]
```

- 속성 폐포 X⁺가 릴레이션의 모든 속성을 포함하면 X는 슈퍼키이며, 그중 최소인 것이 후보키

### 나. 규칙

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 기본 규칙 | 반사 (Reflexivity) | Y ⊆ X 이면 X → Y (자명한 종속) |
| | 첨가 (Augmentation) | X → Y 이면 XZ → YZ |
| | 이행 (Transitivity) | X → Y, Y → Z 이면 X → Z |
| 유도 규칙 | 분해 (Decomposition) | X → YZ 이면 X → Y, X → Z |
| | 합집합 (Union) | X → Y, X → Z 이면 X → YZ |
| | 의사이행 (Pseudo-transitivity) | X → Y, WY → Z 이면 WX → Z |

---

## III. 비교 및 동향

### 가. 설계 활용

| 비교 항목 | 수행 내용 | 효과 |
| --- | --- | --- |
| 속성 폐포 X⁺ | X가 결정하는 모든 속성 계산 | 특정 종속 성립 여부 판정 |
| 후보키 식별 | X⁺ = 전체 속성인 최소 X 탐색 | [[릴레이션 키\|후보키]] 도출 |
| 최소 커버 | 우변 단일화, 불필요한 좌변 속성·종속 제거 | 중복 없는 종속 집합으로 설계 단순화 |
| 정규화 분해 | 분해 후 F⁺ 유지 여부 확인 | 종속성 보존 검증 (무손실 조인은 별도 조건으로 검사) |

### 나. 동향

- **정규화 도구**: 모델링 도구·교육용 정규화기가 폐포·최소 커버 계산에 공리 사용
- **FD 자동 발견**: [[데이터 프로파일링]]에서 실제 데이터로 함수 종속을 찾고(TANE 등) 정규화 위반 탐지
- **NoSQL 환경**: 반정규화를 허용해도 데이터 의존 관계 분석에는 여전히 기본 원리로 사용
