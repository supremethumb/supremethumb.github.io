# 가상 메모리 관리 정책 (할당 · 배치 · 인출 · 교체)

---

## I. 한정된 메모리의 효율적 운영, 메모리 관리 정책의 개요

### 가. 정의

- 다중 프로그래밍 환경에서 [[가상 메모리]]를 효율적으로 운영하기 위해 **얼마나 줄지(할당)·어디에 둘지(배치)·언제 가져올지(인출)·무엇을 내보낼지(교체)** 를 결정하는 운영체제의 4대 정책 (할·배·인·교)

### 나. 필요성

| 구분 | 내용 |
| --- | --- |
| [[단편화]] 최소화 | 내부·외부 단편화를 줄여 적재 효율 향상 |
| 스래싱 방지 | 부적절한 정책은 페이지 부재가 폭증하는 [[스레싱]]으로 이어짐 |
| 처리량 극대화 | 워크로드에 맞게 정책을 조합해 [[처리량]] 향상 |

---

- OS가 프로세스에 프레임 수를 정하고(할당), 필요한 페이지를 언제 가져와(인출) 어디에 둘지(배치) 정하며, 공간이 부족하면 희생 페이지를 내보냄(교체)

### 나. 정책별 기법

| 정책 | 결정 사항 | 주요 기법 |
| --- | --- | --- |
| 할당 (Allocation) | 프로세스에 프레임을 **얼마나** 줄 것인가 | 고정 할당(균등·비례), 가변 할당(Working Set, PFF 기반) |
| 배치 (Placement) | 메모리 **어디에** 둘 것인가 | 연속 할당: First-fit, Best-fit, Worst-fit / 불연속: 페이징, [[세그멘테이션]] |
| 인출 (Fetch) | **언제** 가져올 것인가 | 요구 인출(Demand Paging), 예상 인출(Prepaging, [[지역성]] 기반) |
| 교체 (Replacement) | **무엇을** 내보낼 것인가 | [[FIFO]], [[OPT]], [[LRU]], [[LFU]], [[NUR]], Clock(SCR) / 전역·지역 교체 |

### 다. 성능 최적화 요소

| 요소 | 설명 |
| --- | --- |
| TLB | 주소 변환 결과를 캐시해 변환 지연 감소 |
| Working Set | 일정 시간 자주 참조하는 페이지 집합을 상주시켜 부재 감소 |
| PFF | 페이지 부재율 상·하한으로 프레임 수 동적 조절 |

## III. 비교 및 동향

### 가. 성능 저하 요인과 해결

| 요인 | 내용 | 해결 |
| --- | --- | --- |
| 스래싱 | CPU가 실행보다 페이지 교체에 시간을 더 씀 | Working Set, PFF, 다중 프로그래밍 정도 조절 |
| [[Belady's Anomaly]] | FIFO에서 프레임을 늘렸는데 부재가 증가 | LRU 등 스택 알고리즘 사용 |
| 단편화 | 연속 할당 시 외부 단편화 | 페이징, [[단편화\|압축·통합]] |

### 나. 동향

- **할당·교체의 계층화**: [[CXL]] 메모리 풀링과 DDR–CXL–NVMe 계층형 메모리에서 OS가 핫·콜드 페이지를 자동 이동
- **페이징 개념의 확장**: vLLM PagedAttention이 [[초거대 언어 모델|LLM]] KV 캐시를 블록 단위로 관리해 단편화 감소
- **큰 페이지**: THP(Transparent Huge Pages)·mTHP로 TLB 적중률 향상
