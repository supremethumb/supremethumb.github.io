# 랜덤 포레스트 (Random Forest)

---

## I. 앙상블 학습의 대표적 모델, 랜덤 포레스트의 개요

### 가. 랜덤 포레스트의 정의
- 훈련 데이터로부터 복원 추출한 다수의 부트스트랩 샘플과 무작위 특성 선택(Random Subspace)을 결합하여 여러 개의 의사결정나무를 독립 학습시킨 후, 다수결 투표나 평균으로 결과를 집계(Bagging)하는 앙상블 머신러닝 알고리즘이다.

### 나. 랜덤 포레스트의 등장 배경 및 주요 특징

| 구분 | 주요 내용 |
| --- | --- |
| 단일 트리 한계 극복 | 단일 의사결정나무의 치명적 약점인 높은 분산(Variance)과 과적합(Overfitting) 취약성 해결 |
| 다양성 및 비상관성 | 배깅(Bootstrapping)과 노드별 특성 무작위 선택을 통해 개별 트리 간 예측 상관관계를 최소화 |
| OOB 자체 검증 | 부트스트랩 미추출 데이터(Out-Of-Bag, 약 36.8%)를 활용해 별도 검증셋 없이 모델 오차 추정 |
| 특성 중요도 제공 | 지니 불순도 감소량(MDI) 또는 순열 중요도(Permutation)를 통해 각 변수의 상대적 영향도 산출 |



---

## II. 랜덤 포레스트의 개념도 및 핵심 기술 요소

### 가. 랜덤 포레스트의 아키텍처 및 동작 원리

```mermaid
flowchart TD
    Data[("원본 학습 데이터\n(Original Dataset)")]

    subgraph Bagging ["Bagging (데이터 복원 추출)"]
        direction TB
        B1["Bootstrap Sample 1"]
        B2["Bootstrap Sample 2"]
        Bn["Bootstrap Sample N"]
    end

    subgraph RandomSubspace ["Random Subspace (특성 무작위 선택)"]
        direction TB
        T1["Decision Tree 1\n(Random Features)"]
        T2["Decision Tree 2\n(Random Features)"]
        Tn["Decision Tree N\n(Random Features)"]
    end

    subgraph Aggregation ["Ensemble Aggregation (결과 집계)"]
        direction TB
        P1["Prediction 1"]
        P2["Prediction 2"]
        Pn["Prediction N"]
        Vote["Majority Voting (분류)\nAverage (회귀)"]
    end

    Final["최종 예측 결과\n(Final Prediction)"]
    OOB["Out-Of-Bag (OOB) Data\n(자체 검증용 약 37% 미추출 데이터)"]

    Data --> Bagging
    Data -. "선택되지 않은 데이터" .-> OOB
    B1 --> T1
    B2 --> T2
    Bn --> Tn

    T1 --> P1
    T2 --> P2
    Tn --> Pn

    P1 --> Vote
    P2 --> Vote
    Pn --> Vote

    Vote --> Final
    OOB -. "OOB Error 측정 및\n변수 중요도 평가" .-> T1

```

* 학습 데이터에서 복원 추출(Bootstrapping)로 다수의 데이터셋을 생성하고, 노드 분할 시 특성(Feature)을 무작위로 선택하여 개별 트리를 독립적으로 학습한 후, 최종 다수결/평균으로 결과를 집계함

### 나. 랜덤 포레스트의 핵심 기술 요소

| 구분 | 요소기술(키워드) | 세부 설명 |
| --- | --- | --- |
| **데이터 샘플링** | **Bootstrapping** | 원본 데이터에서 중복을 허용하여 무작위로 데이터셋을 추출하는 기법 (복원 추출) |
| **다양성 확보** | **Random Subspace** | 트리 노드 분할 시 전체 변수 중 일부 서브셋만 무작위로 선택하여 트리 간 상관관계를 낮춤 |
| **결과 결합** | **Majority Voting** | 분류(Classification) 문제에서 개별 트리의 예측 [[클래스]] 중 가장 많은 표를 얻은 클래스를 최종 선택 |
| **자체 검증** | **OOB (Out-Of-Bag)** | 부트스트랩 샘플링 과정에서 누락된 약 37%의 데이터를 모델 성능 검증(OOB Error)에 활용 |
| **설명력 제공** | **Feature Importance** | Gini 불순도 감소량(MDI) 또는 순열(Permutation) 기반으로 모델 예측에 대한 변수의 기여도 산출 |
| **기본 학습기** | **Decision Tree (CART)** | 지니 계수나 분산 감소량을 기준으로 데이터를 재귀적으로 분할하여 계층적 규칙을 생성하는 기반 모델 |
| **최신 구조 확장** | **Deep Forest (gcForest)** | 랜덤 포레스트를 다층(Cascade) 구조로 직렬 연결하여, 역전파 없이 [[딥러닝]] 수준의 계층적 특징 추출 수행 |
| **연산 가속화** | **[[GPU]] Acceleration (FIL)** | RAPIDS cuML 내의 Forest Inference Library 등을 통해 수천 개의 트리 추론 연산을 GPU로 병렬 가속 |

---

## III. 딥러닝/기반 모델과의 비교 및 발전 동향

### 가. 의사결정나무, 랜덤 포레스트, 딥 포레스트 모델 비교

| 비교 항목 | Decision Tree | Random Forest | Deep Forest (gcForest) |
| --- | --- | --- | --- |
| **알고리즘 구조** | 단일 트리 (Single Model) | 병렬 다중 트리 (Bagging 기반) | 직렬-병렬 결합 (Cascade Layer) |
| **의사결정 경계** | 축에 평행한(Axis-parallel) 단순 경계 | 트리 결합을 통한 복잡한 비선형 경계 | 레이어별 특징 변환(Feature Transformation) |
| **주요 장점** | 높은 해석력(White Box) 및 직관성 | 과적합 방지, 정형(Tabular) 데이터 최적화 | [[역전파\|역전파(Backpropagation)]] 불필요, 파라미터 튜닝 최소화 |
| **취약점/한계** | 작은 데이터 변화에도 구조가 변하는 불안정성 | 트리가 많아질수록 모델 해석력([[XAI]]) 저하 | 기존 신경망 대비 대용량 이미지/음성 데이터 적용 한계 |

### 나. 랜덤 포레스트의 한계점 극복 및 최신 발전 동향
- **TreeSHAP 기반 설명가능성(XAI) 확보**: 앙상블 다중 트리로 인한 불투명성 문제를 해결하기 위해 고속 트리 전용 TreeSHAP 알고리즘을 결합하여 개별 피처의 예측 기여도를 정밀하게 추적
- **사선 분할(Oblique Random Forest) 확장**: 축에 평행(Axis-parallel)하게만 데이터를 분할하는 전통적 결정 경계의 한계를 극복하기 위해 PCA 및 선형 결합 기반 사선 분할 기법 도입
- **GPU 가속화 및 분산 엔지니어링**: 대규모 정형(Tabular) 빅데이터 환경에서 수천 개 이상의 트리를 고속 학습·추론하기 위한 RAPIDS cuML(FIL) 등 GPU 병렬 가속 라이브러리 채택 확산
