# 프로젝트 위험관리 (Project Risk Management)

---

## I. 위협은 줄이고 기회는 키우는, 프로젝트 위험관리의 개요

### 가. 정의

- 프로젝트 목표에 **긍정적·부정적 영향을 줄 수 있는 불확실한 사건·조건**을 계획·식별·분석·대응·감시하는 지식 영역 (PMBOK 6판 11장, 7개 프로세스)

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 양면성 | 위협(Threat)과 기회(Opportunity) 모두 관리 대상 |
| 반복성 | 전 생애주기에 걸쳐 반복 수행, 신규·잔존 위험 지속 식별 |
| 정량화 | 확률·영향 분석, 시뮬레이션으로 의사결정 근거 제공 |
| 위험 수준 | 개별 위험과 프로젝트 전체 위험을 구분해 관리 |
| 예비비 | 알려진 위험은 우발사태 예비비, 미지의 위험은 관리 예비비 |

---

## II. 프로세스와 핵심 기법

### 가. 프로세스 흐름

```mermaid
flowchart LR
    P1["11.1 위험관리<br/>계획수립"] --> P2["11.2 위험 식별<br/>(위험 관리대장)"]
    P2 --> P3["11.3 정성적<br/>위험 분석"]
    P3 --> P4["11.4 정량적<br/>위험 분석"]
    P4 --> P5["11.5 위험 대응<br/>계획수립"]
    P5 --> P6["11.6 위험 대응<br/>실행"]
    P6 --> P7["11.7 위험 감시"]
    P7 -. "신규·잔존 위험" .-> P2
```

- 위험 관리대장(Risk Register)을 중심으로 우선순위화·수치화·대응·감시를 순환. 정량 분석은 필요한 경우에만 수행

### 나. 핵심 기법

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 식별 | 브레인스토밍, 체크리스트, 인터뷰 | 팀·전문가 지식과 과거 정보로 위험 도출 |
| | 델파이 기법 | 전문가 익명·반복 설문으로 합의 |
| | SWOT, 가정·제약 분석 | 강점·약점과 가정의 타당성에서 위험 도출 |
| 정성적 분석 | 확률·영향 매트릭스 | 발생 확률 × 영향으로 우선순위 등급화 |
| 정량적 분석 | [[몬테카를로 시뮬레이션]] | 분포 기반 반복 시뮬레이션으로 일정·원가 달성 확률 산출 |
| | 기대금전가치 (EMV) | 확률 × 금전 영향의 합, [[의사결정나무]]로 대안 비교 |
| | 민감도 분석 | 토네이도 다이어그램으로 영향이 큰 위험 식별 |
| 대응 | 예비비 분석 | 우발사태 예비비(Known-unknowns) 산정 |
| 감시 | 위험 감사, 기술적 성과 분석 | 위험관리 프로세스 효과성, 기술 목표 달성도 점검 |

## III. 비교 및 동향

### 가. 위협 vs 기회 대응 전략 (PMBOK 6판)

| 구분 | 위협 (Threat) | 기회 (Opportunity) |
| --- | --- | --- |
| 상위 이관 | 에스컬레이션 (Escalate) | 에스컬레이션 |
| 원천 조치 | 회피 (Avoid): 원인 제거, 계획 변경 | 활용 (Exploit): 기회 실현을 보장 |
| 제3자 | 전가 (Transfer): 보험, 계약 | 공유 (Share): 파트너십, 합작 |
| 확률·영향 조정 | 완화 (Mitigate): 확률·영향 감소 | 향상 (Enhance): 확률·영향 증가 |
| 수용 | 수용 (Accept): 능동적(예비비)·수동적 | 수용 (Accept) |

- 세부 내용은 [[위험 대응]] 참조

### 나. 동향

- **애자일 위험관리**: 짧은 반복과 데일리 스크럼·회고로 위험을 조기 노출, 위험 소진 차트(Risk Burndown) 활용
- **PMBOK 7판 불확실성 영역**: 리스크뿐 아니라 모호성·복잡성·변동성까지 포괄
- **예측 분석**: 과거 프로젝트 데이터로 지연·초과 위험 확률을 조기 경보
