# ISP (Information Strategy Planning)

---

## I. 경영 전략을 정보화 계획으로 옮기는, ISP의 개요

### 가. 정의

- 경영 목표 달성을 위해 **경영·IT 환경과 현황을 분석하고 목표 모델(To-Be)과 중장기 정보화 이행 계획을 수립**하는 전략 계획 활동

### 나. 필요성 및 특징

| 구분 | 내용 |
| --- | --- |
| 필요성 | 비즈니스–IT 정렬, 중복 투자 방지, 정보화 투자 효과 극대화 |
| 하향식 접근 | 경영 전략에서 출발해 IT 전략·과제로 구체화 (Top-Down) |
| 전사 관점 | 개별 시스템이 아닌 조직 전체 정보화 방향 수립 |
| 경영진 참여 | 경영진 후원과 현업 참여가 성공 요건 |

---

## II. ISP 수행 절차 및 구성요소

### 가. 수행 절차

```mermaid
flowchart LR
    S1["환경 분석<br/>경영·IT 동향, 벤치마킹"] --> S2["현황 분석<br/>업무·정보시스템 As-Is"]
    S2 --> S3["목표 모델<br/>비전, To-Be 아키텍처"]
    S3 --> S4["이행 계획<br/>과제 우선순위, 로드맵, 예산"]
```

- 외부 환경과 As-Is를 분석해 To-Be와의 차이(Gap)를 과제로 도출하고, 우선순위·로드맵·투자 계획으로 정리

### 나. 단계별 기법

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 환경 분석 | [[PEST 분석]] | 정치·경제·사회·기술 거시 환경 |
| | [[3C 4C 분석\|3C 분석]], [[SWOT분석\|SWOT]] | 시장·경쟁·내부 역량 분석과 전략 도출 |
| 현황 분석 | [[가치사슬]] | 활동별 부가가치와 정보화 기회 분석 |
| | CSF (핵심성공요인) | 목표 달성에 반드시 필요한 요인 식별 |
| 목표 모델 | EA (전사 아키텍처) | 업무·데이터·애플리케이션·기술 관점의 목표 청사진 |
| | 갭 분석 | As-Is와 To-Be 차이로 정보화 과제 도출 |
| 이행 계획 | McFarlan 전략 그리드 | 현재·미래 시스템의 전략적 영향도로 포트폴리오 분류 (지원·공장·전환·전략형) |
| | ROI·TCO 분석 | 투자 대비 효과와 총소유비용으로 경제성 검증 |

## III. 유사 계획 비교 및 동향

### 가. ISP vs ISMP vs BPR

| 구분 | ISP | [[ISMP\|ISMP]] | BPR |
| --- | --- | --- | --- |
| 목적 | 전사 중장기 정보화 전략 | 특정 정보시스템 구축의 상세 계획 | 업무 프로세스의 근본적 재설계 |
| 관점 | 경영 전략–IT 정렬 | 요구사항 상세화, 사업 범위·예산 확정 | 프로세스 혁신 (비용·품질·속도) |
| 산출물 | 정보화 비전, 목표 아키텍처, 로드맵 | 기능·비기능 요구사항, 제안요청서(RFP) | To-Be 프로세스, 조직 재설계 |
| 범위 | 전사 | 개별 사업 | 핵심 프로세스 |

### 나. 동향

- **공공 가이드 개정**: [[ISP 및 ISMP 수립 공통가이드 9판(2025.05)\|ISP/ISMP 수립 공통가이드]]가 클라우드·AI 도입 검토와 보안 요구사항을 강화
- **클라우드·AI 중심 ISP**: [[클라우드 네이티브]] 전환, AI 도입 전략, [[데이터 거버넌스]] 정비를 핵심 과제로 포함
- **지속적 계획**: 몇 년 주기의 대규모 ISP 대신 로드맵을 주기적으로 갱신하는 롤링 방식 확산
