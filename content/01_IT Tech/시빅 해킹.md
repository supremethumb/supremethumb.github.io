# 시빅 해킹 (Civic Hacking)

---

## I. 시민이 기술로 공공 문제를 푸는, 시빅 해킹의 개요

### 가. 정의

- 시민·개발자·디자이너가 자발적으로 모여 **공공데이터와 오픈소스로 사회·공공 문제를 해결하는 서비스를 만드는** 시민 참여 활동 (예: Code for America, 2009~)

### 나. 필요성 및 특징

| 구분 | 내용 |
| --- | --- |
| 공공데이터 개방 | 개방된 [[공공데이터]]를 민간이 활용해 새 가치 창출 |
| 참여 민주주의 | 시민이 서비스 수혜자에서 문제 해결 주체로 전환 |
| 상향식 | 현장의 필요에서 출발하는 Bottom-up 방식 |
| 신속성 | 해커톤·애자일로 빠른 시제품 개발 |

---

## II. 생태계 구조 및 구성요소

### 가. 선순환 구조

```mermaid
flowchart LR
    G["정부·지자체<br/>공공데이터 개방"] ==>|"Open API·데이터셋"| H["시빅 해커 커뮤니티<br/>해커톤, 오픈소스"]
    H ==>|"서비스 배포"| C["시민<br/>서비스 이용, 피드백"]
    C -.->|"개선·추가 개방 요구"| G
```

- 정부가 데이터를 개방하면 커뮤니티가 서비스를 만들고, 시민 이용과 피드백이 다시 정책 개선과 추가 데이터 개방으로 이어짐 (예: 2020년 공적 마스크 재고 지도)

### 나. 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 데이터 | 공공데이터 | 기계 판독 가능한 개방 데이터, 자유로운 [[재사용]] |
| | Open API·LOD | 실시간 연계 API, 의미 연결 데이터 |
| 개발 | 오픈소스 | 코드 공개·공동 개발, 이슈 관리 |
| | 클라우드 | 트래픽 급증에 대응하는 [[클라우드 네이티브]] 배포 |
| 방법 | 해커톤 | 단기간 협업으로 시제품 개발 |
| | [[리빙랩, S.O.S랩\|리빙랩]] | 실생활 공간에서 시민 참여 실증 |
| 거버넌스 | 민관 협력 | 정부·시민·기업의 수평적 협력 |
| 네트워크 | Code for All | 국가별 시빅 테크 단체의 국제 연대 |

---

## III. 전통적 공공 서비스 비교 및 동향

### 가. 비교

| 구분 | 전통적 공공 서비스 | 시빅 해킹 기반 서비스 |
| --- | --- | --- |
| 주도 | 정부 (Top-down) | 시민·커뮤니티 (Bottom-up) |
| 개발 방식 | [[워터폴]] 발주 사업 | [[Agile]], 해커톤 |
| 데이터 | 내부 데이터 중심 | 개방 데이터와 민간 데이터 결합 |
| 대응 속도 | 예산·절차로 느림 | 재난·감염병 등 위기 시 빠른 대응 |
| 지속성 | 예산 기반 운영 | 자원봉사 의존, 유지보수 취약 |

### 나. 동향

- **AI 활용 시빅 테크**: [[초거대 언어 모델|LLM]]으로 공공 정보를 쉬운 말·음성으로 제공해 디지털 취약계층 접근성 향상
- **공공 협업 제도화**: 공공데이터 활용 경진대회, 민간 서비스의 공공 연계 등 정부–커뮤니티 협력 경로 확대
- **지속 가능성 과제**: 재단·후원·정부 시범사업 연계로 운영·유지보수 비용 확보 필요
