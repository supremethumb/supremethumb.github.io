# 가설 검정 (Hypothesis Testing)

---

## I. 표본으로 모집단을 판단하는 통계적 추론, 가설 검정의 개요

### 가. 정의

- 모집단의 모수(평균, 분산 등)에 대해 세운 가설이 타당한지를 **표본에서 얻은 검정통계량으로 확률적으로 판정**하는 통계적 의사결정 절차
- 귀무가설($H_0$)이 참이라는 전제에서 [[유의확률]](p-value)을 구하고, 유의수준($\alpha$)과 비교하여 기각 여부를 결정

### 나. 핵심 개념

| 개념 | 설명 |
| --- | --- |
| 귀무가설 ($H_0$) | 기존 통념·"차이가 없다"는 가설, 등호($=, \le, \ge$) 포함 (예: $\mu_A = \mu_B$) |
| 대립가설 ($H_1$) | 연구자가 입증하려는 주장, 귀무가설과 배타적 (예: $\mu_A \neq \mu_B$) |
| 유의수준 ($\alpha$) | 제1종 오류의 최대 허용 확률, 통상 0.05 또는 0.01로 사전 설정 → 기각역 크기 결정 |
| 유의확률 (p-value) | $H_0$가 참일 때 관측값 이상으로 극단적인 결과가 나올 확률 |
| 검정통계량 / 임계치 | 표본으로 계산한 Z·t·F·$\chi^2$ 값 / 기각역의 경계값 |

- [[정규분포]] 양 끝의 기각역과 중앙의 채택역을 임계치로 구분하며, 검정통계량이 기각역에 들어가면 $H_0$를 기각

### 나. 수행 5단계

| 단계 | 절차 | 내용 |
| --- | --- | --- |
| 1 | 가설 설정 | $H_0$(변화 없음)와 $H_1$(입증하려는 주장) 설정 |
| 2 | 유의수준 결정 | $\alpha$ = 0.05 또는 0.01 |
| 3 | 검정통계량 계산 | 표본으로 Z, t, F, $\chi^2$ 값 산출 |
| 4 | 비교 | $p < \alpha$ 또는 \|검정통계량\| > 임계치 여부 확인 |
| 5 | 의사결정 | 조건 충족 시 $H_0$ 기각(통계적으로 유의), 아니면 기각하지 못함 |

## III. 오류 유형 및 주요 검정 기법

### 가. 가설 검정의 오류

| 구분 | 제1종 오류 ($\alpha$) | 제2종 오류 ($\beta$) |
| --- | --- | --- |
| 정의 | $H_0$가 참인데 기각 | $H_0$가 거짓인데 기각하지 못함 |
| 의미 | 거짓 양성 (False Positive), 무고한 사람에게 유죄 | 거짓 음성 (False Negative), 범인에게 무죄 |
| 위험 | 생산자 위험 | 소비자 위험 |

- 두 오류는 Trade-off 관계이며, **표본 크기를 늘리면 둘 다 줄일 수 있음**. 검정력(Power)은 $1-\beta$

### 나. 데이터 특성별 주요 검정 기법

| 기법 | 적용 조건 | 예시 |
| --- | --- | --- |
| [[Z-검정\|Z-검정]] | 모분산을 알거나 표본이 큼(n ≥ 30) | 모평균 검정 |
| [[t-검정 (t-test)\|t-검정]] | 모분산을 모르고 표본이 작음, 두 집단 평균 비교 (독립·대응표본) | 두 학급 성적 비교 |
| [[ANOVA(Analysis of variance)\|ANOVA]] | 세 집단 이상의 평균 비교 (F-분포) | 세 가지 약의 효과 비교 |
| 카이제곱 검정 ($\chi^2$) | 범주형 데이터의 독립성·적합도 | 성별과 선호 브랜드의 연관성 |

### 다. 동향

- **활용**: 확증적 데이터 분석(CDA)의 핵심 도구로 A/B 테스트 결과 검증, AI 모델 간 성능 차이의 유의성 판단에 활용 ([[탐색적 데이터 분석과 확증적 데이터 분석]])
- **p-value 남용 경계**: 미국통계학회(ASA)가 2016년 성명에서 p < 0.05 이분법 판단을 경계, 효과 크기·신뢰구간을 함께 보고하는 방식 권고
- **다중 검정 보정**: 여러 가설을 동시에 검정하는 A/B 테스트·유전체 분석에서 Bonferroni, FDR(Benjamini-Hochberg) 보정 적용
