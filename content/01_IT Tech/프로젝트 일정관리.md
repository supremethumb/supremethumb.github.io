# 프로젝트 일정관리 (Project Schedule Management)

---

## I. 적기 인도를 위한 일정 수립과 통제, 프로젝트 일정관리의 개요

### 가. 정의

- 프로젝트를 **적기에 완료**하기 위해 활동을 정의·순서 배열·기간 산정하고 일정을 개발·통제하는 [[프로젝트 관리 지식 영역]] (PMBOK 6판 6장, 6개 프로세스)

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 범위와 연계 | [[WBS]] 작업 패키지를 활동으로 분해해 시작 |
| 기준선 제공 | 일정 기준선은 성과 측정([[EVM(Earned Value Management, 획득 가치 관리)\|EVM]])의 기준 |
| 점진적 구체화 | 연동계획으로 가까운 활동부터 상세화 |
| 트레이드오프 | 단축 시 원가 증가(크래싱) 또는 위험 증가(패스트 트래킹) |

---

## II. 프로세스와 핵심 기법

### 가. 프로세스 흐름

```mermaid
flowchart LR
    P1["6.1 일정관리<br/>계획수립"] --> P2["6.2 활동 정의<br/>(활동 목록)"]
    P2 --> P3["6.3 활동 순서 배열<br/>(네트워크 다이어그램)"]
    P3 --> P4["6.4 활동기간 산정"]
    P4 --> P5["6.5 일정 개발<br/>(일정 기준선)"]
    P5 --> P6["6.6 일정 통제"]
    P6 -. "변경 요청, 단축 기법" .-> P5
```

- 활동과 의존관계로 네트워크를 만들고 기간을 넣어 주공정([[CPM]])을 산출, 승인된 기준선 대비 실적을 통제

### 나. 핵심 기법

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 활동 정의 | 분해, [[연동계획\|연동계획 (Rolling Wave)]] | 작업 패키지를 활동으로 분해, 가까운 작업부터 상세화 |
| 순서 배열 | PDM (선후행 도형법) | 노드에 활동을 두고 FS·SS·FF·SF 4가지 관계 표현 |
| | 의존관계 유형 | 강제적·임의적·외부·내부 의존관계 |
| | 선도 (Lead)·지연 (Lag) | 후속 활동을 앞당기거나 일부러 늦춤 |
| 기간 산정 | [[3점 산정]] | 낙관·최빈·비관치로 기대치와 불확실성 산출 |
| | 유사·모수·상향식 산정 | 정보 수준에 따라 선택 ([[활동기간 산정기법]]) |
| 일정 개발 | CPM | 총 여유가 0인 최장 경로로 최단 완료일 결정 |
| | [[자원 최적화]] | 자원 평준화(주공정 연장 가능), 평활화(여유 내 조정) |
| | 일정 압축 | 크래싱, 패스트 트래킹 ([[일정단축 기법]]) |
| | 애자일 릴리스 계획 | 백로그 기반 이터레이션 단위 일정 수립 |
| 일정 통제 | 성과 검토, 추세 분석 | 기준선 대비 편차, SPI, 버퍼 소진율 점검 |

---

## III. 비교 및 동향

### 가. 일정 단축 기법 비교

| 비교 항목 | 크래싱 (공정 압축) | 패스트 트래킹 (공정 중첩) |
| --- | --- | --- |
| 원리 | 주공정 활동에 자원 추가 | 순차 활동을 병행 |
| 대가 | 원가 증가 | 위험·재작업 증가 |
| 적용 대상 | 단위기간당 단축 비용이 작은 활동 | 임의적 의존관계를 가진 활동 |
| 전제 | 추가 예산·자원 | 의존관계 조정 가능성 |

### 나. 동향

- **하이브리드**: 마일스톤·마스터 일정은 CPM, 세부 개발은 스프린트 타임박스
- **확률적 일정**: 몬테카를로 시뮬레이션으로 완료 확률별(P50·P80) 일정 제시
- **CCPM**: 활동 여유 대신 버퍼로 관리하는 [[CCM]] 적용
