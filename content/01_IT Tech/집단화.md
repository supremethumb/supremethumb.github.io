# 집단화 (Clustering, 군집화)

---

## I. 비슷한 것끼리 묶기, 집단화의 개요

### 가. 정의

- 레이블 없이 **데이터 간 거리·유사도를 기준으로 비슷한 객체를 같은 군집으로 묶는 [[비지도 학습]] 기법** (군집화)

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 비지도 | 목표 변수 없이 데이터 구조만으로 그룹화 |
| 목표 | 군집 내 응집도 최대화, 군집 간 분리도 최대화 |
| 활용 | 고객 세분화, [[이상치]] 탐지, 문서·이미지 그룹화 |
| 용어 구분 | 데이터 모델링의 집단화(Aggregation, is-part-of)와 다른 개념 ([[관계성]]) |

---

## II. 처리 절차 및 구성요소

### 가. 군집화 절차

```mermaid
flowchart LR
    R[("레이블 없는 데이터")] --> P["전처리<br/>(정규화·차원 축소)"]
    P --> D["거리·유사도 정의"]
    D --> A["알고리즘 적용<br/>(분할·계층·밀도)"]
    A --> E["타당성 평가<br/>(실루엣 등)"]
```

- 변수 단위가 다르면 거리가 왜곡되므로 정규화가 선행되어야 함

### 나. 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 알고리즘 | [[K-평균 알고리즘\|K-Means]] (분할) | K개 중심과의 거리 제곱합 최소화, 빠르지만 K 지정 필요·이상치 민감 |
| | 계층적 군집 | 병합(Agglomerative)·분할(Divisive), 덴드로그램, K 사전 지정 불필요 |
| | [[DBSCAN(밀도 기반 클러스터링)\|DBSCAN]] (밀도) | 반경 Eps 안 MinPts 이상이면 연결, 임의 모양 군집·노이즈 처리 |
| | GMM (모델 기반) | 가우시안 혼합으로 확률적(소프트) 할당 |
| 거리 | 유클리드 거리 | L2, 연속형 변수 기본 |
| | 맨해튼 거리 | L1, 축 방향 절댓값 합 |
| | 코사인 유사도 | 벡터 방향 비교, 텍스트·임베딩에 활용 ([[유사도]]) |
| 평가 | 실루엣 계수 | -1~1, 1에 가까울수록 응집·분리 양호 |
| | Dunn Index | 군집 간 최소 거리 / 군집 내 최대 지름, 클수록 우수 |

---

## III. 비교 및 동향

### 가. 집단화 vs 분류

| 비교 항목 | 집단화 (Clustering) | [[분류화]] (Classification) |
| --- | --- | --- |
| 학습 방식 | 비지도 | 지도 |
| 데이터 | 레이블 없음 | 레이블 있음 |
| 목적 | 숨은 그룹 발견 | 새 데이터의 범주 예측 |
| 알고리즘 | K-Means, DBSCAN, 계층적, GMM | 의사결정나무, SVM, 랜덤 포레스트 |
| 활용 | 고객 세분화, 이상 탐지 | 스팸 필터, 신용 평가 |

### 나. 동향

- **딥 클러스터링**: 오토인코더 잠재 공간에서 군집화해 고차원 데이터 처리
- **임베딩 군집화**: LLM 임베딩을 군집화해 토픽 모델링(예: BERTopic)·RAG 문서 그룹화에 활용
