# 전자정부 성과관리 지침

---

## I. 공공 정보화 투자의 성과를 관리하는, 전자정부 성과관리 지침의 개요

### 가. 정의

- 행정기관 등의 정보화사업과 정보시스템에 대해 **성과계획 수립 → 성과측정 → 결과 활용**의 절차와 기준을 정한 행정안전부 고시 (「전자정부법」 근거)

### 나. 필요성 및 특징

| 구분 | 내용 |
| --- | --- |
| 필요성 | 기관별 개별 구축에 따른 중복 투자, 노후 시스템 유지비 증가, 저활용 시스템 방치 |
| 전 주기 관리 | 사업 기획 단계 성과계획부터 운영 단계 성과측정까지 관리 |
| 다관점 측정 | 비용·업무(이용)·기술 관점의 지표로 시스템 가치 평가 |
| 결과 환류 | 측정 결과를 유지·개선·통폐합·폐기 등 정비와 예산 편성에 반영 |

---

## II. 성과관리 절차 및 구성요소

### 가. 성과관리 절차

```mermaid
flowchart LR
    A["성과계획 수립<br/>목표·지표 설정"] --> B["사업 성과측정<br/>구축 사업 완료 후"]
    B --> C["운영 성과측정<br/>운영 중 시스템"]
    C --> D["결과 활용<br/>유지·개선·통폐합·폐기"]
    D -.->|"차기 사업 계획 반영"| A
```

- 기획 단계에서 성과 목표·지표를 정하고, 사업 완료 후와 운영 중에 각각 측정해 시스템 정비와 예산 편성에 환류

### 나. 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 계획 | 성과계획 | 사업 목적, 성과 목표, 측정 지표·방법 정의 |
| 측정 | 사업 성과측정 | 구축 사업의 목표 달성도 측정 |
| | 운영 성과측정 | 운영 중인 시스템의 활용도·효과·비용 적정성 측정 |
| 측정 관점 | 비용 관점 | 운영·유지관리 비용의 적정성 |
| | 업무·이용 관점 | 이용률, 사용자 만족도, 업무 개선 효과 |
| | 기술 관점 | 가용성·장애, 보안, 기술 노후도 |
| 기반 | 범정부 EA (GEAP) | 정보시스템 현황 정보 기반의 중복성·연계성 검토 |
| 결과 활용 | 정비 유형 결정 | 유지, 기능 개선·고도화, 통폐합, 폐기 |

---

## III. 민간 IT 투자 평가 비교 및 동향

### 가. 공공 성과관리 vs 민간 IT 투자 평가

| 구분 | 전자정부 성과관리 | 민간 [[IT 투자성과 평가]] |
| --- | --- | --- |
| 근거 | 전자정부법, 행안부 고시 | 내부 거버넌스 정책 |
| 목적 | 예산 효율성, 중복 방지, 대국민 서비스 품질 | 수익성, 경쟁 우위 |
| 주요 지표 | 이용률, 만족도, 비용 적정성 | ROI, NPV, IT-BSC |
| 결과 활용 | 시스템 정비, 예산 편성 | 투자 우선순위, 포트폴리오 조정 |

### 나. 동향

- **디지털플랫폼정부 연계**: 기관별 시스템을 통폐합하고 공공 클라우드·SaaS로 전환하는 판단 근거로 성과측정 결과 활용
- **클라우드 전환 정책**: 행정·공공기관 정보시스템의 [[클라우드 네이티브]] 전환 추진과 연계해 노후 시스템 정비
- **사전 단계 연계**: [[ISMP]] 및 정보화사업 사전협의 단계에서 성과 지표를 미리 설정하도록 강화
