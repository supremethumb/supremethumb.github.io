# 인공지능 감리 (AI Audit)

---

## I. AI의 신뢰성·안전성 확보를 위한 검증, 인공지능 감리의 개요

### 가. 인공지능 감리의 정의

- AI 시스템이 목적을 달성하면서 **데이터 편향, 알고리즘 오류, 보안 취약점, 윤리 문제 없이 공정·안전하게 작동하는지**를 독립된 제3자가 데이터 구축부터 운영까지 점검하고 개선을 권고하는 활동
- 기존 [[정보시스템 감리]]와 달리 데이터 편향성, 알고리즘 윤리성, 결과의 설명 가능성([[XAI]]) 검증에 중점

### 나. 필요성

| 구분 | 내용 |
| --- | --- |
| 블랙박스 특성 | 규칙 기반(결정론적) SW와 달리 AI는 데이터로 로직이 정해지는 확률론적 모델 → 코드 리뷰만으로 검증 불가 |
| 성능 노후화 | 배포 후 데이터 분포 변화(Drift)로 성능 저하 |
| 규제 대응 | [[AI 기본법]], EU AI Act 등 고위험 AI의 적합성 평가 의무화 |

---

## II. 인공지능 감리 프레임워크 및 점검 항목

### 가. 감리 프레임워크

```Plain Text
  [ 감리 관점 ]          [ AI 생명주기 ]               [ 점검 기준 ]

  절차 (Process) -----> 데이터 구축 (Data)   -----> 품질, 편향성, 비식별화
        |                     |
  산출물 (Product) ---> 모델 학습 (Training) -----> 알고리즘 적정성, 과적합, 성능지표
        |                     |
  성과 (Performance) -> 서비스 운영 (Deploy) -----> 설명가능성, 안전성, 윤리, Drift
                              |
                [ 기반: AI 윤리 가이드라인 / ISO/IEC 42001 ]
```

- 기존 감리의 3대 관점(절차·산출물·성과)에 AI 생명주기별 특화 점검 기준을 매핑

### 나. 생명주기별 주요 점검 항목

| 단계 | 점검 영역 | 핵심 점검 내용 |
| --- | --- | --- |
| 데이터 구축 | 품질·편향·프라이버시 | 데이터 대표성·균형성, 개인정보 [[비식별화]]·가명처리 적정성, [[데이터 라벨링과 어노테이션\|라벨링]] 정확도와 검수 절차, 데이터 오염 방어 |
| 모델 학습 | 성능·강건성 | Train/Validation/Test 분리, 목표 지표(Precision·Recall·F1) 달성, 과적합 방지([[Dropout]] 등), [[적대적 공격]] 대응 |
| 서비스 운영 | 투명성·윤리·모니터링 | 판단 근거 설명(XAI), [[AI 윤리]] 준수, [[모델 드리프트 컨셉 드리프트 & 데이터 드리프트\|Concept Drift]] 감시 및 재학습 통제, 법령·저작권 준수 |

## III. 기존 감리와의 비교 및 최신 동향

### 가. 정보시스템 감리 vs 인공지능 감리

| 비교 항목 | 정보시스템 감리 (Rule-based) | 인공지능 감리 (Data-driven) |
| --- | --- | --- |
| 개발 특성 | 결정론적, 논리 구현 | 확률론적, 데이터 학습 |
| 점검 대상 | 소스코드, [[데이터베이스 정규화\|DB 설계]], 아키텍처 | 데이터 품질·[[편향]], 모델 성능·파라미터 |
| 오류 성격 | 명확한 로직 오류 | 통계적 오차, 편향, [[할루시네이션]] |
| 테스트 | [[테스트 오라클]] 명확 | 오라클 부재 → 통계적 검증 |
| 유지보수 | 코드 수정(Patch) | 데이터 수집 후 재학습([[Fine-Tuning]]) |
| 핵심 가치 | 기능성, 효율성 | 신뢰성, 공정성, 설명 가능성 |

### 나. 최신 동향 및 제언

- **LLM 레드티밍**: 탈옥(Jailbreak) 프롬프트·민감 질문으로 유해 출력·환각을 검증하는 [[AI 레드팀(Red team) 테스트\|레드팀 테스트]]가 생성형 AI 감리의 핵심
- **EU AI Act 적합성 평가**: 채용·신용·생체인식 등 고위험 AI는 출시 전 적합성 평가 필요 → 감리가 사실상 시장 진입 요건화
- **[[AI TRiSM]] 기반 통제**: ModelOps, AI 보안, 프라이버시 강화를 감리 기준에 맞춰 상시 운영
- **표준·도구 활용**: ISO/IEC 42001, [[지능정보기술 감리 실무 가이드]](NIA)를 기준으로 하고, 편향 탐지·XAI 도구로 감리를 자동화
