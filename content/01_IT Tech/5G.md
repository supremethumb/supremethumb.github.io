# 5G (IMT-2020) 주요 기술

---

## I. 초연결 지능형 사회를 위한 인프라, 5G(IMT-2020)의 개요

### 가. 5G(IMT-2020)의 정의

- 최대 전송속도 20Gbps, 전송 지연 1ms, 연결 기기 수 106개/_k__m_2를 목표로 하여 초광대역(eMBB), 초저지연/고신뢰(URLLC), 대량연결(mMTC) 서비스를 제공하는 5세대 이동통신 기술 표준.
- 4G LTE 대비 데이터 전송 속도, 용량, 연결성 등에서 획기적인 성능 향상을 통해 4차 산업혁명의 핵심 인프라 역할을 수행함.
### 나. 5G의 3대 핵심 성능 비전 (삼각축)

- eMBB (초광대역): AR/VR, 홀로그램 등 대용량 콘텐츠 전송.
- URLLC (초저지연/고신뢰): [[Smart Car(자율주행)|자율주행]], 원격의료 등 미션 크리티컬 서비스.
- mMTC (대량연결): 스마트시티, 스마트팩토리 등 대규모 IoT 연결.

### 나. 5G 주요 기술 요소 상세 (소스 138, 143, 145, 146 기반)

| 구분 | 기술 항목 | 주요 특징 및 역할 |
| --- | --- | --- |
| 무선 접속<br>(Radio) | Massive [[MIMO]] | - 수십~수백 개의 안테나를 사용하여 용량 증대 및 빔포밍 구현. |
|  | Beamforming | - 전파를 특정 단말기에 집중시켜 전송 효율 및 커버리지 향상. |
|  | mmWave | - 28GHz 대역 등의 초고주파를 활용하여 광대역폭 확보. |
|  | [[비직교 다중접속|NOMA]] | - 비직교 다중 접속. 동일 시간/주파수/공간 자원에 여러 단말 데이터를 중첩 전송하여 주파수 효율 향상. |
|  | In-band Full Duplex | - 동일 주파수 대역에서 송신과 수신을 동시에 처리하여 전송 효율 2배 증대. |
| 네트워크<br>(Core) | Network Slicing | - 하나의 물리적 망을 다수의 논리적 가상 망(Slice)으로 분리하여 서비스별(eMBB/URLLC/mMTC) 전용망 제공. |
|  | MEC | - [[Mobile Edge Computing]]. 기지국 근처에 컴퓨팅 자원을 배치하여 트래픽 부하 감소 및 초저지연 실현. |
|  | [[SDN(Software Defined Network)|SDN]] / [[NFV]] | - 네트워크 기능을 소프트웨어화(Virtualization)하여 유연한 망 구성 지원. |

## III. 5G와 4G(LTE)의 성능 비교 및 최신 동향

### 가. 5G vs 4G 성능 비교 (소스 151 기반)

| 항목 | 4G (IMT-Advanced) | 5G (IMT-2020) | 비고 |
| --- | --- | --- | --- |
| 최대 전송속도 | 1 Gbps | 20 Gbps | 20배 향상 |
| 전송 지연 | 10 ms | 1 ms | 1/10 단축 (URLLC) |
| 연결 밀도 | 105 개/_k__m_2 | 106 개/_k__m_2 | 10배 향상 (mMTC) |
| 이동성 | 350 km/h | 500 km/h | 고속열차 지원 |
| 주파수 효율 | 1X | 3X | 효율성 증대 |

### 나. 최신 동향: 5G 특화망(Private 5G) 및 6G 진화

- [[5G 특화망]]: 통신사가 아닌 일반 기업이 특정 구역(건물, 공장 등)에 도입하는 맞춤형 5G망 (4.7GHz, 28GHz 활용).
- 6G 진화: 5G를 넘어 테라헤르츠(THz) 대역 활용, 위성 통신 결합 등을 통한 1Tbps 속도 지향.

# 5G (IMT-2020)

## I. 5G(IMT-2020)의 개요

정의: 국제전기통신연합(ITU-R)에서 제정한 5세대 이동통신 표준으로, 4G LTE 대비 20배 빠른 초고속(eMBB), 1ms 이하의 초저지연(URLLC), 1km²당 100만 기기 연결의 초연결(mMTC) 성능을 달성하여 가상현실, 자율주행, 스마트시티 등 융합 산업의 근간을 제공하는 차세대 이동통신 네트워크 체계

## II. 5G(IMT-2020) 주요 기술 요소 및 특징

| 구분       | 핵심 기술                            | 기술 설명 및 특징                                                                                      |
| -------- | -------------------------------- | ----------------------------------------------------------------------------------------------- |
| 무선/전송 기술 | Massive MIMO (대용량 다중 입출력)        | 기지국에 수십~수백 개의 안테나 배열을 장착하여 스펙트럼 효율과 데이터 전송 용량을 획기적으로 증대시키는 기술                                   |
|          | Beamforming (빔포밍)                | 안테나에서 방사되는 전파를 특정 단말기(사용자) 방향으로 집중시켜 간섭을 줄이고 커버리지 및 전송 속도를 높이는 지향성 전송 기술                        |
|          | mmWave (밀리미터파)                   | 28GHz, 39GHz 등 초고주파 대역을 활용하여 초광대역폭을 확보함으로써 eMBB(초고속 데이터 전송)를 실현하는 필수 주파수 자원 기술                  |
| 네트워크 구조  | Network Slicing ([[네트워크 슬라이싱]])      | 하나의 물리적 네트워크를 목적에 맞게 다수의 독립적인 논리적/가상 네트워크로 분할하여 eMBB, URLLC, mMTC별 맞춤형 [[SLA]] 독립적 제공               |
|          | SDN / NFV                        | SDN(소프트웨어 정의 네트워크): 제어부와 데이터 전달부를 분리하여 유연한 제어<br>NFV(네트워크 기능 [[가상화]]): 하드웨어 장비를 가상화된 소프트웨어(VNF)로 구현 |
| 코어 및 엣지  | MEC (Mobile [[EDGE|Edge]] Computing)      | 기지국 근처(Edge)에 컴퓨팅/스토리지 자원을 전진 배치하여 코어망 부하를 줄이고 물리적 거리를 단축해 URLLC(초저지연) 요구사항 실현                  |
|          | SBA (Service Based Architecture) | 5G 코어(5GC) 네트워크의 제어 기능을 모듈화하고 표준화된 웹 기반 서비스 API를 통해 상호작용하도록 설계된 [[클라우드 네이티브]] 아키텍처                  |

## III. 5G 기술의 진화 및 최신 동향 (5G-Advanced 및 6G 연계)

1. 5G-Advanced (3GPP Rel-18~20) 본격화

- RedCap (Reduced Capability): 기존 5G 대비 대역폭과 전력 소모를 대폭 줄여 웨어러블, 스마트워치, 산업용 무선 센서 등 IoT 디바이스의 배터리 수명과 비용 효율성을 극대화한 경량화 기술
- AI-Native 무선 네트워크: 기지국 [[스케줄링]], 빔 관리, 전력 최적화 등 무선 인터페이스(Air Interface) 전반에 [[인공지능]](AI/ML) 알고리즘을 기본 탑재하여 지능형 네트워크 및 에너지 절감 구현
- [[비지상네트워크|NTN]] (Non-Terrestrial Network) 고도화: 저궤도(LEO) 위성 통신망과 스마트폰의 직접 연결 지원을 강화하여 해상, 상공 등 음영 지역 없는 3차원 초공간 커버리지 확보
2. 6G(IMT-2030)를 향한 브릿지 역할

- XR/[[메타버스]] 특화 전송: 몰입형 확장현실(XR)을 위한 저지연 코덱 지원 및 대용량 트래픽 최적화를 통해 B2C 및 B2B 버티컬(Vertical) 서비스 시장 확대 주도
- 결언: 5G 기술은 초기 대역폭 중심의 인프라 구축 단계를 넘어, 현재 5G-Advanced 표준을 바탕으로 산업 특화망(이음5G) 고도화 및 다가올 6G(초공간·초지능) 생태계를 준비하는 핵심 혁신 기반으로 진화 중임
끝.
