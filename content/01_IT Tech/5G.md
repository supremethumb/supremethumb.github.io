# 5G (IMT-2020) 주요 기술

---

## I. 초연결 지능형 사회의 인프라, 5G(IMT-2020)의 개요

### 가. 5G의 정의

- ITU-R이 IMT-2020으로 규정한 5세대 이동통신 표준으로, **최대 20Gbps, 지연 1ms, 1km²당 100만 대 연결**을 목표로 하는 이동통신 기술
- 초고속(eMBB)·초저지연(URLLC)·초연결(mMTC) 서비스를 하나의 망에서 제공하여 자율주행, 스마트팩토리, XR 등 융합 산업의 기반 역할 수행

### 나. 5G의 3대 서비스 비전

| 서비스 | 의미 | 대표 응용 |
| --- | --- | --- |
| eMBB (enhanced Mobile Broadband) | 초고속·대용량 | AR/VR, 4K/8K 스트리밍, 홀로그램 |
| URLLC (Ultra-Reliable Low Latency) | 초저지연·고신뢰 | [[Smart Car(자율주행)\|자율주행]], 원격 수술, 산업 제어 |
| mMTC (massive Machine Type Comm.) | 대규모 연결 | 스마트시티, 대규모 IoT |

### 나. 계층별 핵심 기술

| 구분 | 기술 | 설명 |
| --- | --- | --- |
| 무선 접속 | Massive [[MIMO]] | 수십~수백 개 안테나로 스펙트럼 효율과 용량 증대 |
| | Beamforming | 전파를 특정 단말 방향으로 집중하여 간섭 감소·커버리지 확대 |
| | mmWave | 28GHz 이상 초고주파로 광대역폭 확보 (eMBB 핵심 자원) |
| | [[비직교 다중접속\|NOMA]] | 전력 차로 여러 단말 신호를 중첩 전송 (5G NR 표준에는 미채택, 6G 후보 기술) |
| 네트워크 | [[네트워크 슬라이싱\|Network Slicing]] | 물리망 하나를 서비스별 논리망으로 분리, 슬라이스별 [[SLA]] 보장 |
| | [[SDN(Software Defined Network)\|SDN]] / [[NFV]] | 제어·전달 분리(SDN), 네트워크 장비 기능의 SW화(NFV) |
| 코어 / 엣지 | [[Mobile Edge Computing\|MEC]] | 기지국 근처에서 연산 처리하여 지연 단축, 코어망 부하 감소 |
| | SBA (Service Based Architecture) | 5G 코어 기능을 모듈화하고 API로 연동하는 [[클라우드 네이티브]] 구조 |

## III. 4G와의 비교 및 진화 동향

### 가. 4G(LTE) vs 5G 성능 비교

| 항목 | 4G (IMT-Advanced) | 5G (IMT-2020) | 비고 |
| --- | --- | --- | --- |
| 최대 전송속도 | 1 Gbps | 20 Gbps | 20배 |
| 전송 지연 (사용자 평면) | 10 ms | 1 ms | 1/10 (URLLC 기준) |
| 연결 밀도 | 10⁵ 대/km² | 10⁶ 대/km² | 10배 (mMTC) |
| 이동성 | 350 km/h | 500 km/h | 고속철도 지원 |
| 주파수 효율 | 1x | 3x | |

### 나. 5G-Advanced (3GPP Rel-18~20)

- **RedCap**: 대역폭·전력을 줄인 경량 단말 규격 → 웨어러블, 산업용 센서
- **AI-Native 무선망**: 스케줄링·빔 관리·전력 제어에 AI/ML 적용
- **[[비지상네트워크|NTN]]**: [[저궤도 위성]]과 단말 직접 연결로 해상·상공 커버리지 확보

### 다. 시사점

- 기업 전용 [[5G 특화망]](이음5G) 확산으로 B2B 버티컬 서비스가 성장 중이며, 5G-Advanced는 [[6G]](IMT-2030)로 가는 가교 역할을 함
