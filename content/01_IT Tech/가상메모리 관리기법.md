### 나. 가상 메모리 핵심 기술요소

| 구분    | 기술            | 설명                 |
| ----- | ------------- | ------------------ |
| 할당 방식 | Paging        | - 고정크기 분할          |
|       | Segmentation  | - 논리적 단위로 가변 분할 수행 |
| 반입    | Demand Paging | - 필요한 페이지만 적재      |
|       | Pre paging    | - 미리 적재            |
| 교체    | [[LRU]]           | - 오래 미사용 페이지       |
|       | [[LFU]] / [[NUR]]     | - 최근 미참조 페이지       |
| 최적화   | TLB           | - 하드웨어 캐시          |
|       | Working Set   | - 페이지 집합 유지        |
|       | PFF           | - 동적 프레임 할당        |
- THP, Memory Tiering을 통한 관리기법 등장

## III. 가상 메모리의 성능저하 요인 및 최신 기술 동향
### 가. 성능저하 요인 및 해결 방안
- 스래싱: Working Set으로 프레임수 조절
- Belady의 모순: 페이지 부재 증가 현상
### 나. 최신 기술 동향
- THP (Transparent Huge Pages)
- Memory Tiering ([[CXL]] 기반)
