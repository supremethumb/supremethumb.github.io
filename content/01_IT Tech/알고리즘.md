# 알고리즘 (Algorithm)

---

## I. 문제 해결의 유한한 절차, 알고리즘의 개요

### 가. 정의

- 주어진 문제를 해결하기 위한 **명확하고 유한한 단계의 연산 절차**

### 나. 성립 조건 (Knuth)

| 구분 | 내용 |
| --- | --- |
| 입력 (Input) | 0개 이상의 입력 |
| 출력 (Output) | 1개 이상의 출력 |
| 명확성 (Definiteness) | 각 단계가 모호하지 않음 |
| 유한성 (Finiteness) | 유한한 단계 후 반드시 종료 |
| 유효성 (Effectiveness) | 각 연산이 실제로 수행 가능할 만큼 기본적 |

---

## II. 설계 기법 및 평가

### 가. 설계·평가 흐름

```mermaid
flowchart LR
    P["문제 분석<br/>최적 부분 구조 · 중복 부분 문제"] --> D["설계 기법 선택<br/>분할 정복 · DP · 탐욕 · 백트래킹"]
    D --> V["정확성 검증"]
    V --> E["복잡도 평가<br/>시간 · 공간, 점근 표기"]
```

- 문제의 성질에 맞는 설계 기법을 고르고, 입력 크기 n에 대한 시간·공간 복잡도로 효율을 비교

### 나. 설계 기법 및 평가 요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 평가 | 점근 표기 ([[O-Notation (O-표기법)\|O]]·Ω·Θ) | 상한·하한·정확한 증가율로 성능 표현 |
| | 시간·공간 복잡도 | 연산 횟수 / 필요 메모리 |
| 설계 기법 | 분할 정복 | 문제를 독립된 부분 문제로 나눠 풀고 결합 ([[병합 정렬]], [[퀵 정렬]]) |
| | [[동적 계획법]] | 중복되는 부분 문제의 해를 저장해 재사용 (메모이제이션·테이블) |
| | [[그리디 알고리즘\|탐욕법]] | 매 단계 국소 최적 선택, 탐욕 선택 속성이 성립할 때만 최적해 보장 |
| | 백트래킹 | 상태 공간 트리를 DFS로 탐색하며 유망하지 않은 분기 가지치기 |
| | 분기 한정 | 한계값(Bound)으로 탐색 범위를 줄이는 최적화 탐색 |
| 근사 | 휴리스틱·근사 알고리즘 | NP-Hard 문제에서 허용 시간 내 근사해 도출 |

---

## III. 비교 및 동향

### 가. 분할 정복 vs 동적 계획법 vs 탐욕법

| 비교 항목 | 분할 정복 | 동적 계획법 | 탐욕법 |
| --- | --- | --- | --- |
| 접근 | 하향식 분할·결합 | 상향식(테이블) 또는 하향식(메모이제이션) | 단계별 선택 |
| 부분 문제 | 서로 독립 | 서로 중복 | 선택 후 남은 하나의 부분 문제 |
| 최적해 | 문제에 따라 정확한 해 | 최적 부분 구조면 보장 | 탐욕 선택 속성이 있을 때만 보장 |
| 예 | 병합 정렬, 이진 탐색 | 0-1 배낭, LCS, 플로이드 | [[다익스트라 알고리즘\|다익스트라]], 크루스칼, [[허프만 코딩]] |

### 나. 동향

- **양자 알고리즘**: Shor는 소인수분해를 다항 시간에, Grover는 비정렬 탐색을 O(N)에서 O(√N)으로 단축 → RSA·ECC 대비 [[양자내성암호]](PQC) 전환 추진
- **학습 기반 최적화**: 강화학습·[[유전 알고리즘]] 등 메타휴리스틱으로 조합 최적화(물류·칩 배치) 근사해 탐색
- **알고리즘 책임성**: [[편향]] 감사와 [[XAI]] 요구, EU AI Act 등 규제 확대
