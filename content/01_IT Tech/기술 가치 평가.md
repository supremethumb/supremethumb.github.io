# 기술 가치 평가 (Technology Valuation)

---

## I. 기술의 미래 수익을 금액으로 환산하는, 기술 가치 평가의 개요

### 가. 정의

- 기술(특허 등 지식재산 포함)이 **사업화로 창출할 미래 경제적 이익을 평가 시점의 화폐 가치로 산정**하는 활동

### 나. 필요성 및 특징

| 구분 | 내용 |
| --- | --- |
| 필요성 | 기술 거래·이전, IP 담보 대출·투자, M&A, 현물 출자, 기술특례 상장 |
| 미래 추정 | 매출·현금흐름 예측과 할인율 설정에 따라 결과가 크게 달라짐 |
| 기술 몫 분리 | 사업 가치 중 기술이 기여한 부분(기술기여도)만 산정 |
| 수명 반영 | 기술의 경제적 수명 동안의 이익만 반영 |

---

## II. 평가 절차 및 구성요소

### 가. 평가 절차

```mermaid
flowchart LR
    A["기초 분석<br/>기술성·권리성·시장성·사업성"] --> B["재무 추정<br/>매출, 현금흐름, 경제적 수명"]
    B --> C["가치 산정<br/>할인율, 기술기여도, 평가 방법"]
    C --> D["결과 활용<br/>거래, 금융, 출자, M&A"]
```

- 정성 분석으로 기술의 차별성·권리 안정성·시장 규모를 확인한 뒤, 현금흐름·할인율·기술기여도를 적용해 현재가치를 산정

### 나. 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 정성 분석 | 기술성 | 차별성, 모방 난이도, 대체 기술 존재 여부 |
| | 권리성 | 특허 존속기간, 청구항 범위, 무효·침해 위험 |
| | 시장성·사업성 | 시장 규모·성장률, 사업화 역량 |
| 정량 요소 | 기술 수명 | 인용 특허 수명(TCT) 등으로 경제적 수명 추정 |
| | 현금흐름 (FCF) | 매출 − 비용 − 세금 − 투자 ± 운전자본 변동 |
| | 할인율 | 가중평균자본비용(WACC)에 기술 사업화 위험 가산 |
| | 기술기여도 | 사업 가치 중 기술이 기여한 비율 (산업기술요소 × 개별기술강도) |
| 평가 방법 | DCF, 로열티 공제법, 실물옵션 | 현금흐름 할인, 절감 로열티 할인, 투자 유연성 가치 |

---

## III. 평가 접근법 비교 및 동향

### 가. 3대 접근법

| 구분 | 수익 접근법 | 시장 접근법 | 원가 접근법 |
| --- | --- | --- | --- |
| 원리 | 미래 수익의 현재가치 | 유사 기술 거래 가격 비교 | 동일 기술 재개발·대체 비용 |
| 기법 | DCF, 로열티 공제법 | 유사 거래 비교법 | 재생산 원가법, 대체 원가법 |
| 장점 | 수익 창출력 직접 반영 | 시장 근거로 설득력 | 산정 용이, 초기 기술에 적용 |
| 단점 | 추정·할인율의 주관성 | 비교 거래 정보 부족 | 미래 수익성 미반영 |

### 나. 동향

- **공공 평가 체계**: 산업통상자원부 기술가치평가 실무가이드, 기술보증기금·기술평가기관의 기술평가 모델로 평가 기준 표준화
- **AI·데이터 활용**: 특허 인용 관계·텍스트 분석으로 기술 수명·유사 기술을 자동 탐색해 평가 보조
- **IP 금융 확대**: IP 담보 대출·보증·투자와 기술특례 상장 평가로 활용 범위 확대, 가치 추정의 투명성 요구 증가
