# 가용성 (Availability)

---

## I. 필요할 때 쓸 수 있는 상태, 가용성의 개요

### 가. 정의

- 정보보안 3요소(CIA) 중 하나로, **인가된 사용자가 필요한 시점에 정보와 서비스에 지체 없이 접근·사용할 수 있도록 보장**하는 특성
- 산정식: $\text{Availability} = \frac{\text{MTBF}}{\text{MTBF} + \text{MTTR}}$ (총 운영 시간 대비 정상 가동 시간 비율)

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| Nines 지표 | 99.9%(연 약 8.76시간 중단) ~ 99.999%(연 약 5.26분 중단)로 등급화, [[SLA]] 기준으로 활용 |
| SPOF 제거 | 단일 장애점(Single Point of Failure)을 이중화·다중화로 제거 |
| 결함 허용 | 장애 시 자동 전환(Failover)·자동 복구 구조 확보 |
| 위협 요인 | [[DoS (Denial of Service)\|DoS]]·[[DDOS\|DDoS]], [[랜섬웨어]], 하드웨어 장애, 재해 |

### 나. 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 구조 | Active-Standby | 평상시 주 서버만 동작, 장애 시 대기 서버가 인수 (비용 효율적) |
| | Active-Active | 복수 서버가 부하 분담, 한쪽 장애 시 나머지가 즉시 처리 |
| 장애 대응 | Failover / Failback | 장애 시 예비 시스템으로 자동 전환, 복구 후 원위치 |
| | Checkpoint / Recovery | 상태를 주기적으로 저장해 재시작 시 손실 최소화 |
| 스토리지 | [[RAID]] | 디스크 다중화로 디스크 장애 시에도 데이터·서비스 유지 |
| | 원격 복제 | 지역 간 데이터 복제로 재해복구(DR) 체계 구축 |
| 운영 | [[카오스 엔지니어링]] | 의도적 장애 주입으로 복원력을 사전 검증 |
| | [[SRE (Site Reliability Engineering)\|SRE]] | SLO·에러 버짓 기반 신뢰성 운영 |

## III. 비교 및 동향

### 가. 가용성 등급(Nines) 비교

| 가용성 | 연간 허용 중단 시간 | 적용 예 |
| --- | --- | --- |
| 99% | 약 3.65일 | 내부 업무 시스템 |
| 99.9% | 약 8.76시간 | 일반 웹 서비스 |
| 99.99% | 약 52.6분 | 전자상거래, 클라우드 관리형 서비스 |
| 99.999% | 약 5.26분 | 통신·금융 핵심 시스템 |

### 나. 동향

- **멀티 리전·[[멀티클라우드]] Active-Active**: 단일 클라우드·리전 장애에 대비한 분산 배치 확대
- **[[사이버 레질리언스]]**: 랜섬웨어 대응을 위해 불변(Immutable) 백업, 격리 복구 환경을 가용성 설계에 포함
- **카오스 엔지니어링 일상화**: 운영 환경에서 장애 주입 실험을 정기 수행해 복구 절차 검증
