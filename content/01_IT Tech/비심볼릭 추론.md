# 비심볼릭 추론 (Sub-symbolic Reasoning)

---

## I. 규칙 대신 가중치로 배우는, 비심볼릭 추론의 개요

### 가. 정의

- 지식을 명시적 기호·규칙이 아닌 **신경망의 가중치와 연속 벡터에 분산 표현해, 데이터에서 학습한 통계적 패턴으로 추론**하는 [[인공지능]] 방식 (연결주의)

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 데이터 중심 | 사람이 규칙을 작성하지 않고 대량 데이터에서 특징을 스스로 학습 |
| 연결주의 | 뉴런 간 연결 강도의 집합적 동작으로 결과 도출 |
| 강건성 | 이미지·음성 등 비정형·잡음 데이터의 패턴 인식에 강함 |
| 블랙박스 | 추론 근거를 명시적으로 설명하기 어려움 |

---

## II. 동작 원리 및 핵심 요소

### 가. 개념도

```mermaid
flowchart LR
    IN["비정형 입력<br/>(이미지, 텍스트, 음성)"] --> EMB["벡터화<br/>(임베딩)"]
    EMB --> NN["신경망<br/>가중치·활성화 함수"]
    NN --> OUT["확률적 출력"]
    OUT -- "손실 계산" --> BP["역전파<br/>가중치 갱신"]
    BP -.-> NN
```

- 입력 벡터가 가중치·활성화 함수를 거쳐 확률적 출력을 내고, 오차를 [[역전파]]해 가중치에 지식을 누적

### 나. 핵심 요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 지식 표현 | 분산 표현 | 하나의 개념을 여러 차원 값의 조합으로 표현 (임베딩) |
| 추론 구조 | 인공신경망 | [[CNN]], [[RNN (Recurrent Neural Network)\|RNN]], [[트랜스포머]] 등 다층 네트워크 |
| 지식 저장 | 가중치·편향 | 학습된 패턴을 파라미터로 저장 |
| 비선형성 | [[활성화함수]] | ReLU, Sigmoid 등으로 복잡한 패턴 표현 |
| 학습 | [[손실함수]]·[[경사하강법]] | 오차를 수치화하고 기울기로 가중치 갱신 |
| 출력 | 확률적 추론 | 참·거짓 대신 가장 가능성 높은 답을 확률로 반환 |

---

## III. 비교 및 동향

### 가. 비심볼릭 vs 심볼릭 추론

| 비교 항목 | 비심볼릭 추론 | [[심볼릭 추론]] |
| --- | --- | --- |
| 패러다임 | 연결주의, 데이터 중심 | 기호주의, 규칙·논리 중심 |
| 지식 표현 | 벡터, 가중치 | IF-THEN 규칙, 온톨로지, 논리식 |
| 추론 방식 | 귀납적 통계 학습 | 연역적 논리 추론 |
| 장점 | 비정형 데이터·잡음에 강함, 확장성 | 추론 근거가 명확, 적은 데이터로 동작 |
| 단점 | 설명력 부족, 대량 데이터·연산 필요 | 예외 처리 취약, 규칙 구축 병목 |
| 대표 기술 | [[딥러닝]], [[초거대 언어 모델\|LLM]], Word2Vec | 전문가 시스템, [[지식그래프]], 논리 프로그래밍 |

### 나. 동향

- **뉴로-심볼릭 AI**: 신경망의 지각 능력과 기호 추론의 논리·설명력을 결합 (예: AlphaGeometry의 언어 모델 + 기호 추론 엔진)
- **설명력 보완**: [[XAI]] 기법과 단계적 추론 프롬프팅([[COT|CoT]]), 외부 도구·코드 실행 연동으로 블랙박스 추론의 검증성 향상
