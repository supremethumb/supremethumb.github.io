# 경사하강법 (Gradient Descent)

---

## I. 손실 최소화를 위한 반복 최적화, 경사하강법의 개요

### 가. 경사하강법의 정의

- 손실 함수(Loss Function)를 최소화하기 위해 **현재 위치의 기울기(Gradient) 반대 방향으로 학습률만큼 파라미터를 반복 갱신**하는 1차 근사 [[최적화 알고리즘]]
- 안개 낀 산에서 발밑의 가장 가파른 내리막을 따라 한 걸음씩 내려가 가장 낮은 골짜기(최적 파라미터)를 찾는 방식

### 나. 필요성

| 구분 | 내용 |
| --- | --- |
| 해석적 해의 한계 | 수백만~수천억 개 파라미터의 최적값을 방정식으로 한 번에 구할 수 없음 |
| 오차 최소화 | 예측값과 실제값의 차이를 줄이는 가중치(W)·[[편향]](b) 도출 |
| 신경망 학습의 기반 | [[역전파]]로 구한 기울기를 이용해 모든 층의 가중치 갱신 |

$$W_{new} = W_{old} - \alpha \cdot \frac{\partial J(W)}{\partial W}$$

- $W$: 가중치, $\alpha$: 학습률, $\frac{\partial J}{\partial W}$: 손실 함수의 기울기
- 학습률에 따라 정상 수렴, 오버슈팅(발산), 느린 수렴으로 결과가 달라짐

### 나. 핵심 구성요소

| 요소 | 설명 | 역할 |
| --- | --- | --- |
| [[손실함수\|손실 함수]] | 예측값과 정답의 차이 (MSE, Cross-Entropy 등) | 최소화할 목표 함수 |
| 기울기 (Gradient) | 파라미터에 대한 손실 함수의 편미분값, 함수가 가장 크게 증가하는 방향 | 반대 방향(−)으로 이동할 나침반 |
| 학습률 ($\alpha$) | 한 번에 이동할 보폭 (하이퍼파라미터) | 너무 크면 오버슈팅, 너무 작으면 수렴 지연 |
| 에포크 / 배치 | 전체 데이터 1회 학습 단위 / 1회 갱신에 쓰는 데이터 묶음 | 갱신 빈도·안정성 결정 |

### 다. 데이터 사용량에 따른 유형

| 유형 | 1회 갱신에 쓰는 데이터 | 특징 |
| --- | --- | --- |
| 배치 경사하강법 (BGD) | 전체 데이터 | 안정적이나 메모리·시간 소모 큼 |
| 확률적 경사하강법 (SGD) | 1개 | 빠르고 지역 최솟값 탈출에 유리, 진동 큼 |
| 미니배치 경사하강법 | 소규모 묶음 | 속도와 안정성의 절충, 실무 표준 |

## III. 한계점 및 옵티마이저 발전

### 가. 주요 한계

- **지역 최솟값(Local Minimum)**: 전역 최솟값이 아닌 곳에 갇힘
- **안장점·플래토(Plateau)**: 기울기가 0에 가까운 평탄 구간에서 학습 정체
- **오버슈팅**: 학습률이 크면 최솟값을 지나쳐 발산

### 나. 옵티마이저의 발전

| 구분 | 알고리즘 | 개선점 |
| --- | --- | --- |
| 관성 | Momentum | 이전 이동 방향의 관성을 반영해 진동 감소·수렴 가속 |
| 적응형 학습률 | AdaGrad | 많이 갱신된 변수의 학습률을 줄임 (학습률이 0으로 수렴하는 문제) |
| | RMSProp | 최근 기울기의 지수 이동 평균으로 AdaGrad의 학습률 소실 보완 |
| 통합 | Adam | Momentum(방향) + RMSProp(보폭) 결합, 가장 널리 사용 |
| | AdamW | 가중치 감쇠(Weight Decay)를 분리해 일반화 성능 개선 → [[초거대 언어 모델\|LLM]] 학습 표준 |

### 다. 최신 실무 동향

- **학습률 스케줄링**: 초기 Warm-up으로 안정화 후 Cosine Annealing으로 점진 감소
- 옵티마이저 상세 비교는 [[최적화 알고리즘|머신러닝 옵티마이저]] 참고
