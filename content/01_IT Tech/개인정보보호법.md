# 개인정보보호법 (Personal Information Protection Act)

---

## I. 데이터 활용과 정보주체 권리의 균형, 개인정보보호법의 개요

### 가. 개인정보보호법의 정의
- 개인정보의 수집·유출·오용·남용으로부터 사생활을 보호하기 위해 처리 원칙, 정보주체의 권리, 개인정보처리자의 법적 의무 및 처벌 기준을 규정한 공공·민간 통합 일반법.

### 나. 주요 특징

| 구분 | 내용 |
| --- | --- |
| 일반법 지위 | 공공·민간, 온라인·오프라인을 포괄 (2023 개정으로 정보통신서비스 특례 일원화) |
| 활용과 보호의 조화 | 통계·연구·공익 기록 보존 목적의 가명정보 처리 허용 |
| 제재 방식 전환 | 형벌 중심 → 과징금 등 경제 제재 중심 |

### 나. 주요 개정 내용

| 방향 | 개정 내용 | 설명 |
| --- | --- | --- |
| 데이터 경제 활성화 | 개인정보 [[데이터 전송요구권\|전송요구권]] | 본인 정보를 본인 또는 제3자에게 전송 요구 → [[마이데이터]] 전 분야 확산 |
| | 온·오프라인 규제 일원화 | 정보통신서비스 특례를 일반 규정으로 통합 |
| | 이동형 영상정보처리기기 | 드론·자율주행차 등 이동형 기기의 촬영 기준 신설 |
| 신뢰사회 구축 | 동의 제도 개선 | 필수 동의 관행 개선, 동의 외 처리 근거 정비 |
| | 자동화된 결정 대응권 | AI 등 완전 자동화된 결정에 대한 거부·설명 요구권 ([[AI 윤리]]) |
| | 분쟁조정·피해구제 | 분쟁조정 제도 개선, 침해 구제 강화 |
| 글로벌 스탠다드 | 국외 이전 요건 다양화 | 인증·적정성 결정 등 이전 요건 확대, 국외 이전 중지 명령 신설 |
| | 경제 제재 중심 | 과징금 상한을 **전체 매출액의 3% 이하**로 상향 (위반 무관 매출 제외), 형벌 축소 |

### 다. 법 개정에 따른 기업의 대응 시사점
- **전송요구권 및 마이데이터 인프라 구축**: 개인정보 전송요구권의 전 산업 확산에 대비하여 표준 API 연동 규격 준수 및 안전한 전송 구간 암호화 인프라 선제 확보.
- **자동화된 결정 대응권 및 AI 거버넌스 확립**: AI 채용, 신용평가 등 인공지능 기반 의사결정에 대한 정보주체의 설명 요구권과 거부권 행사에 대응할 수 있는 설명가능 AI([[XAI]]) 및 투명성 로깅 체계 내재화.
- **Privacy by Design 및 ISMS-P 기반 컴플라이언스 강화**: 전체 매출액 3% 이하 과징금 상한 상향 등 경제적 제재 강화에 대응하여 [[개인정보보호 중심 설계]](PbD)를 초기 개발부터 적용하고 [[ISMS-P]] 인증을 통한 사후 관리 체계 공고화.
