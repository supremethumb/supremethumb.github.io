# 포아송 분포 (Poisson Distribution)

---

## I. 단위 구간당 사건 발생 수, 포아송 분포의 개요

### 가. 정의

- 일정한 시간·공간 구간에서 **독립적으로 일정한 평균 비율 $\lambda$로 발생하는 사건의 횟수**가 따르는 이산확률분포, $X \sim Poisson(\lambda)$

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 단일 모수 | 단위 구간당 평균 발생 횟수 $\lambda$ 하나로 결정 |
| 평균 = 분산 | $E(X) = Var(X) = \lambda$ |
| 이항 극한 | [[이항분포]]에서 $n \to \infty$, $p \to 0$, $np = \lambda$ 일정할 때의 극한 |
| 가법성 | 독립 포아송 변수의 합도 포아송 ($\lambda_1 + \lambda_2$) |

---

## II. 가정 및 구성요소

### 가. 개념도

```mermaid
flowchart LR
    C["포아송 과정 가정<br/>독립성, 비동시성, 발생률 일정"] --> L["모수 λ<br/>단위 구간 평균 발생 수"]
    L --> P["PMF<br/>P(X=k) = e^-λ · λ^k / k!"]
    L --> E["사건 간 대기 시간<br/>지수분포 (평균 1/λ)"]
    P --> A["적용<br/>콜 인입, 장애 건수, 요청 도착"]
```

- 겹치지 않는 구간의 사건이 독립이고 아주 짧은 구간에 두 사건이 동시에 일어나지 않으며 발생률이 일정하면 발생 횟수는 포아송 분포

### 나. 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 모수 | $\lambda$ | 단위 구간 평균 발생 횟수, $\lambda > 0$ |
| 확률 함수 | PMF | $P(X=k) = \frac{e^{-\lambda}\lambda^k}{k!}$, $k = 0, 1, 2, \dots$ |
| 성질 | 평균·분산 | 모두 $\lambda$ |
| 확률 과정 | 포아송 과정 | 시간에 따라 사건이 독립·일정 비율로 도착하는 계수 과정 |
| 관련 분포 | 지수분포 | 사건 간 대기 시간 분포, 무기억성 ([[기하 분포]]의 연속형 대응) |
| 근사 | 이항 근사 | 예: $n \ge 20$, $p \le 0.05$이면 $B(n,p) \approx Poisson(np)$ |
| 확장 | 과대산포 | 분산 > 평균인 데이터는 음이항 분포로 모델링 |

---

## III. 비교 및 동향

### 가. 이항분포 vs 포아송 분포

| 비교 항목 | [[이항분포\|이항분포]] | 포아송 분포 |
| --- | --- | --- |
| 확률변수 | $n$회 시행 중 성공 횟수 | 단위 구간 발생 횟수 |
| 범위 | $0 \sim n$ | $0, 1, 2, \dots$ |
| 모수 | $n$, $p$ | $\lambda$ |
| 평균·분산 | $np$ ≥ $np(1-p)$ | $\lambda$ = $\lambda$ |
| 예 | 동전 10번 중 앞면 수 | 하루 웹서버 오류 건수 |

### 나. 동향

- **용량·신뢰성 계획**: 장애·요청 도착률을 포아송으로 모델링해 [[SRE (Site Reliability Engineering)|SRE]]의 용량 계획과 [[SLA]] 기준 수립에 활용
- **대기행렬 이론**: M/M/1 등 큐잉 모델에서 도착 과정을 포아송으로 가정해 대기 시간·처리량 분석
- **포아송 회귀**: 방문자 수·결함 수 같은 계수(Count) 데이터를 로그 링크 GLM으로 예측
