# BCP (Business Continuity Planning, 비즈니스 연속성 계획)

---

## I. 중단 없는 기업 운영을 위한 전사적 대응 체계, BCP의 개요

### 가. BCP의 정의

- 재난·재해·사이버 공격 등 위기 상황에서도 **핵심 비즈니스 기능을 중단 없이 유지하거나 목표 시간(RTO) 안에 복구**하기 위한 전사적 위기 대응 계획

### 나. 등장 배경 및 특징

| 구분 | 내용 |
| --- | --- |
| 등장 배경 | 재난의 대형화, IT 의존도 심화로 서비스 중단 파급력 증가, [[랜섬웨어]]·클라우드 장애, [[ISO 22301]] 등 컴플라이언스 요구 |
| 비즈니스 중심 | IT 복구([[DRP(RTO, RPO 등)\|DRP]])를 넘어 인력·프로세스·시설까지 포함 |
| 분석 기반 | [[BIA (Business Impact Analysis)\|BIA]]와 위험 평가(RA)로 복구 우선순위 결정 |
| 생애주기 관리 | 예방 → 대비 → 대응 → 복구의 지속적 관리 |

---

## II. BCP 수립 절차 및 핵심 지표

### 가. 수립 절차 및 산출물

```mermaid
flowchart LR
    P1["1. 착수<br/>(정책 · 조직)"] --> P2["2. BIA / RA<br/>(핵심 업무 · RTO/RPO)"]
    P2 --> P3["3. 복구 전략<br/>(대체 사업장 · DR 센터)"]
    P3 --> P4["4. 계획 수립<br/>(비상 매뉴얼 · 연락망)"]
    P4 --> P5["5. 훈련 · 유지보수<br/>(모의 훈련 · 개선)"]
    P5 -. "지속적 개선" .-> P2
```

- 정책·조직을 세우고 BIA·위험 평가로 복구 목표를 정한 뒤, 복구 전략과 비상 계획을 수립하고 훈련 결과로 계속 보완

### 나. 복구 목표 지표

```mermaid
flowchart LR
    BUP["마지막 백업"] -- "RPO<br/>(허용 데이터 손실)" --> DIS(("재해 발생"))
    DIS -- "RTO<br/>(IT 복구 목표 시간)" --> IT["IT 시스템 복구"]
    IT -- "WRT<br/>(업무 복구 시간)" --> BIZ["업무 재개"]
```

| 지표 | 의미 |
| --- | --- |
| RPO (Recovery Point Objective) | 허용 가능한 최대 데이터 손실 시점 → 백업 주기 결정 |
| RTO (Recovery Time Objective) | 재해 발생부터 IT 서비스 복구까지의 목표 시간 |
| WRT (Work Recovery Time) | IT 복구 후 데이터 검증·잔여 작업을 거쳐 업무가 재개되기까지의 시간 |
| MTPD (최대 허용 중단 시간) | 조직 생존에 치명적 손실이 생기기 전까지 견딜 수 있는 시간, **MTPD ≥ RTO + WRT** |

### 다. 핵심 구성요소

| 분류 | 요소 | 설명 |
| --- | --- | --- |
| 분석 | BIA | 업무 중단 시 재무·비재무 손실 분석, 핵심 업무와 복구 우선순위 결정 |
| | RA (Risk Assessment) | 위협·취약성 식별, 발생 가능성과 영향도 평가 |
| 복구 체계 | DRP | BCP 하위의 IT 시스템·데이터 복구 기술 계획 |
| | DR 센터 / 대체 사업장 | Mirror·Hot·Warm·Cold Site ([[DRS (Disaster Recovery System)\|DRS]]) |
| 유지 관리 | 모의 훈련 | 도상 훈련(Table-top), 실제 전환 훈련(Full-scale) |
| 표준 | ISO 22301 (BCMS) | 비즈니스 연속성 경영시스템 국제 표준 |

## III. 위기관리 체계 비교 및 동향

### 가. DRP vs BCP vs BCM

| 비교 항목 | DRP | BCP | [[BCM]] |
| --- | --- | --- | --- |
| 개념 | 재해 복구 계획 | 업무 연속성 계획 | 업무 연속성 관리 체계 |
| 범위 | IT 중심 (최하위) | 비즈니스 중심 | 전사 경영 활동 (최상위) |
| 복구 대상 | 데이터, 서버, 네트워크 | 핵심 업무, 인력, 시설, 협력사 | 조직 전체의 생존력·거버넌스 |
| 주요 활동 | 백업·소산, DR 센터 페일오버 | 비상 연락, 대체 업무 장소 전환 | BCP/DRP 통합 관리, 감사 |
| 주도 | [[CIO]], CISO, IT 부서 | 경영진, 현업 부서 | 최고경영진 |
| 시점 | 재해 이후 기술 조치 | 재해 직후 ~ 복구 | 평상시 예방 ~ 사후 관리 |

### 나. 최신 동향

- **[[DRaaS]] 확산**: 자체 DR 센터 대신 클라우드 자원을 온디맨드로 활용해 초기 비용(CAPEX) 절감
- **[[사이버 레질리언스]] 통합**: 랜섬웨어 대응을 위한 불변(Immutable) 백업, 사이버 볼트, Air-Gap 백업을 BCP 필수 항목으로 포함
- **공급망·클라우드 의존 관리**: 핵심 협력사·클라우드 사업자 중단을 시나리오에 포함하고 대체 공급원 확보
