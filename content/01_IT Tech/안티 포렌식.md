# 안티 포렌식 (Anti-forensics)

---

## I. 디지털 증거의 무력화 및 수사 방해 기술, 안티 포렌식의 개요

* **정의**: [[디지털 포렌식]] 수사 과정에서 증거의 수집, 식별, 추출, 분석을 방해하거나 무력화하기 위해 디지털 증거를 조작·은닉·파괴·암호화하는 일련의 기술적 행위
* **필요성 및 등장배경**:
* **공격자의 흔적 은폐 요구**: 사이버 범죄자 및 공격 그룹(APT)의 침해 흔적 인멸 및 수사 추적 회피
* **프라이버시 보호 요구**: 개인정보 유출 방지 및 GDPR/개인정보보호법에 따른 안전한 데이터 완전 삭제 필요성


* **특징**: 증거의 [[무결성]](Integrity)과 [[신뢰성]](Authenticity) 훼손, 디지털 포렌식 5대 원칙의 성립 방해

## II. 안티 포렌식의 메커니즘 및 핵심 기술 요소

### 가. 안티 포렌식의 공격 영역 및 대응 메커니즘 개념도

```mermaid
flowchart TB
    subgraph Anti_Forensics ["안티 포렌식 공격 영역 (4대 기술 축)"]
        direction LR
        Destruction["1. 데이터 파괴<br/>(Wiping, Degaussing)"]
        Hiding["2. 데이터 은닉<br/>(Steganography, Slack)"]
        Tampering["3. 데이터 변조<br/>(Timestomp, Log 삭제)"]
        Obfuscation["4. 분석 방해<br/>(Fileless, Anti-VM)"]
    end

    subgraph Forensic_Target ["디지털 증거 자산"]
        direction TB
        Disk["보조기억장치 (HDD, SSD)"]
        Memory["주기억장치 (RAM, Cache)"]
        Artifacts["운영체제 아티팩트 (MFT, Registry)"]
    end

    Destruction ==>|"증거 원천 소멸"| Disk
    Hiding ==>|"미할당/슬랙 영역 매핑"| Disk
    Tampering ==>|"메타데이터/MACB 왜곡"| Artifacts
    Obfuscation ==>|"비휘발성 흔적 미생성"| Memory

    subgraph Anti_Anti_Forensics ["포렌식 수사 대응 (Anti-Anti Forensics)"]
        direction TB
        Live["라이브 포렌식 (메모리 덤프)"]
        Carving["파일 카빙 / VSS 섀도우 복원"]
        Timeline["$LogFile / USN 저널 교차 분석"]
    end

    Forensic_Target <== "증거 수집 및 복원 분석" === Anti_Anti_Forensics

```

* 공격자는 증거 수명주기 전반(디스크, 메모리, 아티팩트)에 걸쳐 증거 파괴, 은닉, 변조, 분석 방해 기술을 적용함
* 이에 맞서 포렌식 수사관은 휘발성 메모리 우선 수집(라이브 포렌식)과 파일 카빙 및 저널 파일 교차 분석을 통해 대응함

### 나. 안티 포렌식의 핵심 기술 및 구성 요소

| 분류 | 핵심 기술 (키워드) | 세부 설명 |
| --- | --- | --- |
| **데이터 파괴** | **와이핑 (Wiping)** | 디스크 섹터에 0, 1 또는 난수를 다회 덮어쓰기(Overwrite)하여 복구를 차단 (DoD 5220.22-M, NIST SP 800-88) |
| **데이터 파괴** | **디가우징 (Degaussing)** | 강력한 자기장을 인가하여 자기 매체(HDD)의 자화 패턴을 완전히 파괴하는 물리적 소각 기법 |
| **데이터 은닉** | **슬랙 공간 은닉 (Slack Space)** | 클러스터 슬랙(RAM Slack, File Slack) 및 디스크 볼륨 미할당 영역에 악성코드 및 기밀 데이터 은닉 |
| **데이터 은닉** | **스테가노그래피 (Steganography)** | 이미지, 오디오 파일의 최하위 비트(LSB)를 조작하여 눈에 띄지 않게 비밀 메시지를 삽입·은닉 |
| **데이터 은닉** | **ADS (대체 데이터 스트림)** | NTFS 파일 시스템의 특성을 악용하여 일반 파일 이름 뒤에 숨겨진 스트림 영역에 악성 바이너리 저장 |
| **데이터 변조** | **타임스탬프 조작 (Timestomp)** | 파일 시스템의 MACB(수정, 접근, 생성, MFT변경) 시간 정보를 임의로 조작하여 타임라인 분석 교란 |
| **데이터 변조** | **로그 소거 및 변조** | Event Viewer 로그, syslog 삭제 및 권한 상승을 통한 시스템 감사 추적(Audit Trail) 무력화 |
| **분석 방해** | **파일리스 공격 (Fileless / LOLBins)** | 디스크에 악성 파일을 쓰지 않고 PowerShell, WMI, 메모리 인젝션을 통해서만 악성 행위 수행 |
| **분석 방해** | **안티 디버깅 / 안티 VM** | [[가상화]] 환경(Sandbox, VMware) 및 디버거 탐지 시 프로세스를 강제 종료하여 동적 분석 회피 |
| **데이터 보호** | **전체 볼륨 [[암호화]] (FVE)** | BitLocker, VeraCrypt 등을 적용하여 복호화 키 없이는 디스크 포렌식 이미징 자체를 원천 차단 |

## III. 디지털 포렌식 vs 안티 포렌식 비교 및 향후 전망

### 가. 디지털 포렌식과 안티 포렌식 기술 비교

| 비교 항목 | 디지털 포렌식 (Digital Forensics) | 안티 포렌식 (Anti-forensics) |
| --- | --- | --- |
| **목적 및 행위** | 증거의 식별, 보존, 수집, 분석 및 법적 증명 | 증거의 파괴, 조작, 은닉 및 수사 회피 |
| **주요 기술 체계** | 휘발성 메모리 분석, 파일 카빙, 타임라인 분석 | 디스크 와이핑, 스테가노그래피, Timestomp |
| **법적/절차적 요건** | **포렌식 5대 원칙** (정당성, 재현성, 신속성, 연계보관성, 무결성) | 법적 책임 회피 및 사법 방해 (증거인멸죄 성립) |
| **핵심 성공 요인** | 훼손되지 않은 원본 데이터 확보 및 교차 검증 | 데이터 복원 불가능성 달성 및 침해 흔적 제로화 |

### 나. 안티 포렌식의 최신 진화 트렌드 및 향후 수사 대응 과제

* **클라우드 및 컨테이너의 휘발성 악용**: 에페머럴(Ephemeral) [[컨테이너]] 인스턴스를 활용하여 공격 수행 후 컨테이너를 즉각 파기함으로써 로그 및 아티팩트 잔재를 원천 소멸시키는 수법 증가
* *대응*: 클라우드 [[CSP]] 레벨의 실시간 API 로깅(CloudTrail 등) 및 eBPF 기반 실시간 런타임 보안 텔레메트리 연동 필수


* **AI 기반 스테가노그래피(DeepSteg)의 출현**: 생성형 AI([[GAN (Generative Adversarial Network)|GAN]], [[VAE]])를 활용하여 정교한 이미지·오디오 내부에 데이터를 은닉하여 기존 통계적 스테그분석(Steganalysis)을 무력화
* *대응*: [[딥러닝]] 기반 이상 탐지 모델을 활용한 잠재 공간(Latent Space) 변조 감지 기법 도입


* **안티-안티 포렌식(Anti-Anti Forensics)의 고도화**: MFT 레코드와 저널 파일($LogFile,$UsnJrnl), 볼륨 섀도우 복사본(VSS) 간의 다차원 불일치(Discrepancy)를 자동 교차 분석하는 지능형 포렌식 자동화([[SOAR (Security Orchestration, Automation and Response)|SOAR]]) 체계 구축 확산
