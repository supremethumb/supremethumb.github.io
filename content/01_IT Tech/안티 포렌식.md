# 안티 포렌식 (Anti-forensics)

---

## I. 증거를 지우고 숨기는 기술, 안티 포렌식의 개요

### 가. 정의

- [[디지털 포렌식]]의 **증거 수집·분석을 방해하기 위해 데이터를 파괴·은닉·변조하거나 분석 자체를 어렵게 만드는** 기술과 행위

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 공격자 동기 | 침해 흔적 은폐, 수사 추적 회피 |
| 정당한 용도 | 매체 폐기 시 완전 삭제(NIST SP 800-88), 프라이버시 보호 |
| 증거 신뢰성 훼손 | [[무결성]]·연계보관성 등 포렌식 원칙 무력화 |
| 4대 유형 | 파괴, 은닉, 변조, 분석 방해 |

---

## II. 기법 및 구성요소

### 가. 기법 영역과 대응

```mermaid
flowchart LR
    subgraph AF["안티 포렌식"]
        direction TB
        D1["파괴<br/>와이핑 · 디가우징"]
        D2["은닉<br/>스테가노그래피 · 슬랙 · ADS"]
        D3["변조<br/>타임스탬프 · 로그 삭제"]
        D4["분석 방해<br/>파일리스 · 안티 VM · 암호화"]
    end
    subgraph AAF["대응"]
        direction TB
        R1["라이브 메모리 수집"]
        R2["파일 카빙 · VSS 복원"]
        R3["$MFT · $LogFile · $UsnJrnl 교차 분석"]
        R4["원격 로그 · EDR 텔레메트리"]
    end
    AF ==> AAF
```

- 디스크·메모리·아티팩트 전반의 안티 포렌식에 대해 휘발성 데이터 우선 수집과 다중 아티팩트 교차 분석으로 대응

### 나. 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 파괴 | 와이핑 | 덮어쓰기로 복구 차단 (현대 HDD는 1회 덮어쓰기로 충분, NIST SP 800-88) |
| | 디가우징 | 강한 자기장으로 HDD·테이프 기록 소거 (SSD에는 무효) |
| | 암호화 삭제 | 자체 암호화 드라이브의 키 폐기로 전체 데이터 무력화 |
| 은닉 | 슬랙·비할당 영역 | 파일 슬랙·미할당 공간에 데이터 숨김 |
| | 스테가노그래피 | 이미지·오디오 LSB 등에 데이터 삽입 |
| | ADS | NTFS 대체 데이터 스트림에 숨김 |
| 변조 | 타임스탬프 조작 | MACB 시간 변경으로 타임라인 교란 (Timestomp) |
| | 로그 삭제 | 이벤트 로그·syslog 삭제, 감사 기능 비활성화 |
| 분석 방해 | 파일리스·LotL | 디스크에 파일 없이 메모리·내장 도구로 실행 |
| | 안티 디버깅·안티 VM | 분석 환경 탐지 시 동작 중단 |
| | 전체 디스크 암호화 | 키 없이는 이미지 분석 불가 |

## III. 비교 및 동향

### 가. 디지털 포렌식 vs 안티 포렌식

| 비교 항목 | 디지털 포렌식 | 안티 포렌식 |
| --- | --- | --- |
| 목적 | 증거 식별·보존·분석·법적 입증 | 증거 파괴·은닉·조작 |
| 기술 | 메모리 분석, 카빙, 타임라인 | 와이핑, 스테가노그래피, Timestomp |
| 원칙·법적 측면 | 정당성·재현성·신속성·연계보관성·무결성 | 타인 형사사건 증거 인멸 시 증거인멸죄 |
| 성공 조건 | 훼손되지 않은 원본과 교차 검증 | 복구 불가능성과 흔적 최소화 |

### 나. 동향

- **클라우드·컨테이너 휘발성**: 짧게 살다 사라지는 컨테이너로 흔적 소멸 → CloudTrail 등 API 로그, eBPF 런타임 텔레메트리 보존
- **SSD 특성**: TRIM·가비지 컬렉션으로 삭제 데이터가 자동 소거되어 복구 가능성 감소
- **AI 기반 은닉**: 생성 모델 기반 스테가노그래피 증가 → [[딥러닝]] 스테그분석 연구
