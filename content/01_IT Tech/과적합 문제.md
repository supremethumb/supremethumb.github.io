# 과적합 (overfitting)문제

카테고리: 신기술 트렌드 / [[인공지능]](AI) 및 기계학습
## I. 과적합(Overfitting)의 개요

정의: 기계학습 모델이 학습 데이터(Training Data)의 미세한 노이즈와 특이점까지 과도하게 암기하여, 학습 데이터에 대해서는 매우 높은 정확도를 보이지만 처음 보는 새로운 데이터(Test Data)에 대해서는 예측 성능이 급격히 떨어지는 현상을 말합니다.

배경 및 비유: 모의고사 문제의 정답 번호까지 통째로 외워버린 학생이, 정작 수능 시험장에서는 문제의 숫자나 유형이 조금만 바뀌어도 답을 맞히지 못하는 상황과 같습니다. 인공지능 모델의 궁극적인 목적은 학습 데이터의 암기가 아니라, 미지의 데이터에 대한 '[[일반화]](Generalization) 능력'을 확보하는 것이므로 과적합은 모델 개발 시 가장 경계해야 할 핵심 문제입니다.

## II. 과적합의 발생 원인 및 징후

과적합은 모델의 복잡도와 제공된 데이터의 양/질 사이의 불균형에서 발생합니다.

| 구분 | 주요 내용 및 특징 |
| --- | --- |
| 발생 원인 | 1. 모델의 과도한 복잡성: 해결해야 할 문제에 비해 신경망의 층(Layer)이 너무 깊거나 파라미터 수가 지나치게 많을 때 발생합니다.<br>2. 데이터 부족: 모델이 패턴을 일반화하기에 충분한 양의 학습 데이터가 제공되지 않았을 때 발생합니다.<br>3. 데이터 노이즈: 데이터 라벨링에 오류가 많거나, 의미 없는 [[이상치]](Outlier)가 많이 섞여 있을 때 모델이 이를 유의미한 패턴으로 착각하여 학습합니다. |
| 징후 판단 | 학습 오차(Train Loss) $\ll$ 검증 오차(Validation Loss)<br>학습 데이터의 정확도는 99%에 달하지만, 검증 데이터의 정확도는 70% 수준에 머무르는 등 두 지표 간의 격차(Variance)가 크게 벌어지는 현상이 가장 명확한 징후입니다. |

## III. 과적합 방지 및 해결 기법 (Regularization)

과적합을 막고 모델의 일반화 성능을 높이는 기법들을 통칭하여 정규화(Regularization)라고 합니다.

| 기법 명칭 | 원리 및 실무 적용 방법 |
| --- | --- |
| 데이터 증강<br>(Data Augmentation) | 가장 근본적인 해결책입니다. 이미지의 경우 회전, 반전, 크롭, 노이즈 추가 등을 통해 제한된 원본 데이터를 임의로 변형하여 학습 데이터의 양과 다양성을 인위적으로 늘립니다. |
| 조기 종료<br>(Early Stopping) | 매 에포크(Epoch)마다 검증 데이터의 오차를 모니터링하다가, 오차가 다시 증가하기 시작하는 시점(개념도 참고)에서 학습을 강제로 중단시키고 이전 가중치를 복원합니다. |
| 드롭아웃<br>([[Dropout]]) | 학습 과정에서 신경망의 뉴런(노드) 중 일부를 무작위로 $0$으로 만들어(비활성화) 학습에 참여하지 않게 합니다. 특정 뉴런에 의존하는 것을 막고 여러 뉴런이 고르게 특징을 학습하게 하여 강건성(Robustness)을 높입니다. |
| 가중치 감소<br>(Weight Decay / L1, L2) | 손실 함수(Loss Function)에 가중치의 크기에 비례하는 페널티 항을 추가하여, 모델이 특정 가중치 값을 너무 크게 가지지 않도록 억제합니다.$Loss = \text{Original Loss} + \lambda \sum w_i^2 \quad \text{(L2 Regularization)}$ |
| 교차 검증<br>(Cross Validation) | 전체 데이터를 $K$개의 폴드(Fold)로 나누어, 번갈아 가며 학습과 검증을 수행(K-Fold)함으로써 특정 데이터 셋에만 모델이 과적합되는 것을 방지합니다. |

## IV. 최근 트렌드 (2025~2026) 및 심화 개념

### 1. 이중 하강 현상 (Double Descent Phenomenon)

- 과거의 기계학습 이론([[편향]]-분산 트레이드오프)에서는 모델이 지나치게 커지면 무조건 과적합이 발생하여 성능이 떨어진다고 믿었습니다.
- 그러나 최근의 딥러닝과 대형언어모델([[초거대 언어 모델|LLM]]) 연구에 따르면, 모델의 파라미터 크기를 과적합 구간을 넘어서 '극단적으로 더 크게(Over-parameterized)' 키울 경우, 어느 순간 다시 검증 오차가 하락하며 일반화 성능이 비약적으로 좋아지는 '이중 하강(Double Descent)' 현상이 발견되었습니다. 이는 최근 빅테크 기업들이 천문학적인 비용을 들여 파라미터 수를 수백억~수조 개로 늘리는 이론적 근거가 되었습니다.
### 2. 생성형 AI(LLM) 환경에서의 과적합 문제

- 데이터 암기(Memorization)와 프라이버시: LLM이 학습 데이터를 과적합하게 되면, 사용자가 교묘한 프롬프트를 입력했을 때 학습 데이터에 포함되어 있던 개인정보(주민등록번호, 이메일, 저작권 있는 코드 등)를 그대로 출력해 버리는 보안 리스크가 발생합니다.
- 해결책: 이를 방지하기 위해 2026년 현재는 학습 단계에서 데이터의 중복을 철저히 제거(De-duplication)하고, [[강화학습]](RLHF) 단계에서 특정 문장을 그대로 외워서 답하는 행위에 페널티를 부여하는 등 모델 조정(Alignment) 기술이 필수적으로 적용되고 있습니다.
