# 과적합 (overfitting)문제
---

## I. 학습 데이터 암기로 인한 일반화 실패 현상, 과적합(Overfitting)의 개요

### 가. 과적합의 정의
기계학습 모델이 학습 데이터(Training Data)의 미세한 노이즈와 특이점까지 과도하게 암기하여, 학습 데이터에 대해서는 오차가 극히 낮지만 새로운 평가 데이터(Test Data)에 대해서는 예측 성능이 급격히 저하되는 현상이다.

### 나. 과적합의 발생 원인 및 징후
| 구분 | 세부 특징 |
| --- | --- |
| 모델 복잡도 과다 | 파라미터 수가 지나치게 많거나 은닉 계층이 깊어 복잡한 비선형 결정 경계를 형성할 때 발생 |
| 학습 데이터셋 부족 | 특징 분포를 충분히 대변할 수 없는 소규모 데이터셋으로 인해 일반화 규칙 학습 실패 |
| 노이즈 및 이상치 학습 | 라벨링 오류나 극단적 이상치가 포함된 데이터를 유효한 신호로 오인하여 암기 |
| 성능 격차 징후 | 학습 오차($Train\ Loss$)는 지속 하락하나 검증 오차($Val\ Loss$)가 반등하여 분산(Variance) 급증 |

### 나. 과적합 방지(Regularization) 핵심 기술 요소

| 구분 | 요소기술 | 세부 설명 및 적용 방법 |
| --- | --- | --- |
| **데이터 기법** | 데이터 증강 (Augmentation) | 회전, 반전, 크롭, 노이즈 추가를 통해 원본 데이터를 다양하게 변형하여 표본 공간 확장 |
| **학습 제어** | 조기 종료 (Early Stopping) | 에포크별 검증 오차(Val Loss)를 모니터링하여 오차가 증가하기 시작하는 최적점에서 학습 중단 |
| **네트워크 제어** | 드롭아웃 ([[Dropout]]) | 학습 단계마다 은닉 노드의 일정 비율($p$)을 무작위 비활성화하여 특정 뉴런 의존성 탈피 |
| **손실 규제** | 가중치 감소 (L1/L2) | 손실 함수에 가중치 놈($\lambda \|w\|_1, \lambda \|w\|_2^2$) 페널티를 부과하여 가중치 크기 제한 |
| **검증 기법** | 교차 검증 (Cross-Validation) | 데이터셋을 K개 폴드로 분할하여 교차 검증(K-Fold)을 수행함으로써 분산 편향 완화 |
| **정규화 계층** | 배치 정규화 (Batch Norm) | 미니배치 단위로 입력 분포를 평균 0, 분산 1로 정규화하여 공변량 변화 방지 및 가중치 안정화 |

## III. 모델 적합도 비교 및 최신 동향

### 가. 과소적합(Underfitting) vs 적정 적합(Good Fit) vs 과적합(Overfitting) 비교

| 비교 항목 | 과소적합 (Underfitting) | 적정 적합 (Good Fit) | 과적합 (Overfitting) |
| --- | --- | --- | --- |
| **모델 복잡도** | 지나치게 단순함 | 문제 복잡도에 적합함 | **지나치게 복잡하고 층이 깊음** |
| **학습 상태** | 특징 패턴을 충분히 학습하지 못함 | 내재된 데이터 규칙을 올바르게 일반화 | **데이터 노이즈와 특이치까지 암기** |
| **편향 및 분산** | **높은 편향(Bias), 낮은 분산** | 균형 잡힌 편향과 분산 (Trade-off) | **낮은 편향, 높은 분산(Variance)** |
| **학습/검증 오차** | 학습 오차 높음, 검증 오차 높음 | 학습 오차 낮음, 검증 오차 낮음 | **학습 오차 매우 낮음, 검증 오차 급등** |
| **해결 방안** | 모델 복잡도 증대, 추가 특성 엔지니어링 | 현 상태 유지 및 MLOps 드리프트 모니터링 | **정규화(Dropout/L2), 데이터 증강, 조기 종료** |

### 나. 과적합 관련 최신 연구 및 엔터프라이즈 동향

* **이중 하강(Double Descent) 현상 규명**: 모델 파라미터가 보간 임계치를 넘어 초과 파라미터화될 경우 검증 오차가 다시 감소하는 현상이 입증되어 대규모 LLM 사전학습의 이론적 기반 제공
* **초거대 언어 모델(LLM) 데이터 암기 및 개인정보 보호**: LLM이 학습 말뭉치를 그대로 암기하여 출력하는 프라이버시 침해를 억제하기 위해 사전학습 데이터 중복제거(De-duplication)와 정렬 튜닝(DPO/RLHF) 적용
* **합성 데이터(Synthetic Data)를 통한 데이터 기근 해소**: 고품질 실사 데이터 부족으로 인한 과적합을 방지하기 위해 물리 시뮬레이션 및 생성형 AI 기반 합성 데이터를 증강하는 MLOps 파이프라인 보편화
