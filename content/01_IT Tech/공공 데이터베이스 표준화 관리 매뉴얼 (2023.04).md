# 공공 데이터베이스 표준화 관리 매뉴얼 (2023.04)

---

## I. 사전 예방형 공공데이터 품질관리, 표준화 관리 매뉴얼의 개요

### 가. 정의

- 공공기관이 DB를 신규 구축·고도화할 때 **범정부 데이터 표준(단어·도메인·용어·코드)을 일관되게 적용**하고, 구축 단계부터 표준·구조·값·관리체계를 점검하도록 행정안전부가 제시한 **예방적 품질관리 지침**
- 「공공데이터법」 제22조(품질관리)에 근거하며, 사후 정비 중심에서 **사전 예방 중심**으로 품질관리 패러다임 전환

### 나. 2023.04 개정 핵심

| 구분 | 내용 |
| --- | --- |
| 사전 진단 강화 | 기획·발주 단계에서 '표준화 사전 진단'으로 공통표준용어 적용 가능성 검토 |
| 공통표준 일괄 적용 | 범정부 공통표준용어를 논리·물리 모델에 적용하는 것이 원칙 |
| 평가 연계 | 공공데이터 품질관리 수준평가 지표(표준 준수율, 메타데이터 현행화율)와 연계 |

## III. 비교 및 동향

### 가. 사후 정비형 vs 사전 예방형 품질관리

| 비교 항목 | 사후 정비형 | 사전 예방형 (본 매뉴얼) |
| --- | --- | --- |
| 시점 | 구축·운영 후 오류 정비 | 기획·설계 단계부터 점검 |
| 표준 적용 | 기관별 개별 표준 | 범정부 공통표준 우선 적용 |
| 비용 | 재설계·데이터 정비 비용 큼 | 초기 점검 비용, 이후 정비 비용 감소 |
| 사업 반영 | 별도 정비 사업 | [[ISP (Information Strategy Plan)\|ISP]]·[[ISMP]]·RFP에 품질관리 활동 명시 |

### 나. 동향

- **상향식 표준 연계**: 기관 고유 용어는 기관표준으로 두되, 범정부 공동 활용이 필요하면 공통표준 등록 제안
- **메타데이터 현행화**: 공통표준 개정에 맞춰 기관 메타데이터 관리시스템을 주기적으로 갱신, [[공공데이터 품질인증 매뉴얼(2025.07.)|공공데이터 품질인증]] 대응
- **지능형 표준화**: 레거시 DB의 비표준 용어를 의미 유사도 기반으로 자동 식별·매핑하는 도구 도입
