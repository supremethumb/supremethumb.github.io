# BCM (Business Continuity Management)

---

## I. 업무 연속성을 상시 관리하는 경영 체계, BCM의 개요

### 가. 정의

- 재난·장애·사이버 공격 등으로 업무가 중단될 때 **핵심 업무를 정해진 시간 안에 유지·복구하도록 분석·전략·계획·훈련·개선을 반복**하는 전사 관리 체계 ([[ISO 22301]] BCMS)

### 나. 필요성 및 특징

| 구분 | 내용 |
| --- | --- |
| 필요성 | 재난 대형화, IT 의존도 증가, 공급망 연쇄 중단, 금융·공공 규제 |
| 비즈니스 관점 | IT 복구([[DRP(RTO, RPO 등)\|DRP]])를 넘어 인력·시설·공급망까지 포함 |
| 분석 기반 | BIA·위험 평가로 우선순위와 복구 목표 결정 |
| 지속 개선 | [[PDCA(Plan-Do-Check-Act, Deming Cycle)\|PDCA]] 사이클로 계획을 현행화 |

---

## II. BCM 수명주기 및 구성요소

### 가. 수명주기

```mermaid
flowchart LR
    A["분석<br/>BIA, 위험 평가"] --> B["전략<br/>복구 방식·자원"]
    B --> C["계획·구현<br/>BCP, DRP"]
    C --> D["훈련·검토<br/>모의 훈련, 감사"]
    D -.->|"PDCA 개선"| A
```

- 영향·위험 분석으로 복구 목표를 정하고, 전략과 계획(BCP·DRP)을 수립한 뒤 훈련·감사 결과로 다시 분석·계획을 갱신

### 나. 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 분석 | [[BIA (Business Impact Analysis)\|BIA]] | 업무 중단 영향 분석, 핵심 업무·복구 우선순위 결정 |
| | 위험 평가 (RA) | 위협·취약성 식별, 발생 가능성·영향도 평가 |
| 복구 목표 | MTPD | 조직이 견딜 수 있는 최대 중단 기간 |
| | RTO / RPO | 목표 복구 시간 / 목표 복구 시점 |
| | MBCO | 중단 중 유지할 최소 서비스 수준 |
| 계획 | [[BCP]] | 업무 연속성 계획 (비상 조직, 대체 업무, 연락망) |
| | DRP | IT 시스템·데이터 복구 계획 |
| 자원 | DR 센터·대체 사업장 | Mirror·Hot·Warm·Cold 사이트 ([[DRS (Disaster Recovery System)\|DRS]]) |
| 운영 | 훈련·감사 | 도상 훈련, 실제 전환 훈련, 경영진 검토 |

---

## III. BCM·BCP·DRP 비교 및 동향

### 가. 비교

| 구분 | BCM | BCP | DRP |
| --- | --- | --- | --- |
| 개념 | 관리 체계 (최상위) | 업무 연속성 계획 | IT 재해복구 계획 |
| 목적 | 회복탄력성 내재화, 지속 개선 | 핵심 업무 유지·재개 | 시스템·데이터 복구 |
| 대상 | 정책, 조직, 프로세스, 문화 | 업무, 인력, 시설, 공급망 | 서버, 네트워크, DB, 백업 |
| 산출물 | BCM 정책, 인증 체계, 감사 보고 | 업무 복구 매뉴얼, 연락망 | 시스템 복구 절차, 백업 지침 |

### 나. 동향

- **[[DRaaS]]**: 자체 DR 센터 대신 클라우드 자원으로 재해복구 구성
- **[[사이버 레질리언스]]**: [[랜섬웨어]]에 대비한 불변·격리 백업과 복구 훈련을 BCM에 포함
- **디지털 운영 회복력 규제**: EU DORA(2025 시행) 등 금융권 ICT 위험·제3자(클라우드) 의존 관리 의무화
