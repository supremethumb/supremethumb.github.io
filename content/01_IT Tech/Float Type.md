# Float Type (부동소수점형)

---

## I. 넓은 범위의 실수를 근사하는, 부동소수점형의 개요

### 가. 정의

- 실수를 **부호·지수·가수로 나누어 (-1)^S × 1.M × 2^(E-bias) 형태로 저장하는 자료형**으로, IEEE 754 표준(1985년 제정, 2008·2019년 개정)을 따름

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 넓은 범위 | 같은 비트로 매우 큰 수와 매우 작은 수 표현 |
| 근사값 | 0.1처럼 2진수로 유한하게 표현되지 않는 값은 반올림 오차 |
| 상대 정밀도 | 값의 크기에 따라 표현 간격이 달라짐 (큰 수일수록 간격이 넓음) |
| 특수값 | ±0, ±∞, NaN, 비정규화 수 |

---

## II. 구조 및 구성요소

### 가. 비트 구성 (32비트 float)

```mermaid
flowchart LR
    S["부호 S<br/>1비트"] --- E["지수 E<br/>8비트, bias 127"] --- M["가수 M<br/>23비트 (앞의 1 생략)"]
```

- 예: 0.15625 = 1.01₂ × 2⁻³ → S=0, E=124, M=0100…0

### 나. 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 형식 | float (binary32) | 부호 1·지수 8·가수 23비트, 유효 숫자 약 7자리, 최대 약 3.4 × 10³⁸ |
| | double (binary64) | 부호 1·지수 11·가수 52비트, 유효 숫자 약 15~16자리, 최대 약 1.8 × 10³⁰⁸ |
| 필드 | 지수 바이어스 | 지수에 127(float)·1023(double)을 더해 부호 없는 값으로 저장 |
| | 정규화 가수 | 1.xxx 형태로 맞추고 앞의 1은 저장하지 않음 (Hidden Bit) |
| 특수값 | ∞ / NaN | 지수 전부 1: 가수 0이면 무한대, 아니면 NaN |
| | 비정규화 수 | 지수 전부 0, 0 근처의 아주 작은 수를 점진적으로 표현 |
| 반올림 | 기본 모드 | 가장 가까운 값, 같으면 짝수 쪽 (Round to Nearest, ties to Even) |
| 오차 | 머신 엡실론 | float 약 1.19 × 10⁻⁷, double 약 2.22 × 10⁻¹⁶ |
| 연산 | FPU·SIMD·FMA | 부동소수점 전용 유닛, 곱셈-덧셈 융합으로 반올림 1회 |

## III. 비교 및 동향

### 가. AI·과학 계산용 부동소수점 형식

| 형식 | 비트 (부호·지수·가수) | 특징 | 용도 |
| --- | --- | --- | --- |
| FP64 | 1·11·52 | 높은 정밀도 | 과학·공학 시뮬레이션 |
| FP32 | 1·8·23 | 표준 단정밀도 | 일반 연산, 학습 누산 |
| FP16 | 1·5·10 | 범위 좁음 | 추론, 혼합 정밀도 학습 |
| BF16 | 1·8·7 | FP32와 같은 범위, 낮은 정밀도 | 딥러닝 학습 |
| FP8 (E4M3·E5M2) | 1·4·3 / 1·5·2 | 매우 작은 크기 | 대규모 모델 학습·추론 ([[GPU]]·[[NPU]]) |

### 나. 동향

- **비교·누적 오차 주의**: 0.1 + 0.2 ≠ 0.3이므로 == 대신 허용 오차 비교, 금액은 [[Int Type|정수]](최소 단위)나 Decimal 사용
- **저정밀 확산**: FP8·FP4와 블록 단위 스케일을 공유하는 OCP MX 포맷으로 AI 가속기 처리량 향상
- **결정적 계산**: 병렬 합산 순서에 따라 결과가 달라지는 문제를 줄이기 위한 재현 가능한(Deterministic) 연산 옵션 제공
