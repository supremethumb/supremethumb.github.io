# BIA (Business Impact Analysis)

---

## I. 중단의 영향을 시간 축으로 재는, BIA의 개요

### 가. 정의

- 업무가 중단될 때 **시간 경과에 따른 재무·비재무 영향을 분석해 핵심 업무, 복구 우선순위, 복구 목표(MTPD·RTO·RPO)를 정하는** 분석 기법 (ISO/TS 22317 지침)

### 나. 필요성 및 특징

| 구분 | 내용 |
| --- | --- |
| BCP 기초 | [[BCP]]·DR 전략의 복구 목표와 우선순위 근거 제공 |
| 자원 배분 | 한정된 복구 자원을 핵심 업무에 집중 |
| 시간 기반 | 중단 1시간·1일·1주 등 구간별 영향 증가 분석 |
| 표준 요구 | [[ISO 22301]] BCMS의 필수 활동 |

---

## II. BIA 절차 및 구성요소

### 가. 절차와 복구 지표

```mermaid
flowchart LR
    S1["업무·프로세스 식별"] --> S2["중단 영향 평가<br/>재무·비재무"] --> S3["복구 목표 산정<br/>MTPD, RTO, RPO, MBCO"] --> S4["의존 자원 식별<br/>IT, 인력, 공급사"]
```

- 업무별 중단 영향을 평가해 MTPD를 정하고, 그 안에서 RTO(+ WRT)와 RPO를 산정한 뒤 필요한 자원·의존성을 식별 (MTPD ≥ RTO + WRT)

### 나. 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 복구 지표 | MTPD (MTD) | 조직에 치명적 영향이 생기기 전 최대 허용 중단 기간 |
| | RTO | 서비스·시스템 재가동 목표 시간 |
| | RPO | 허용 가능한 데이터 손실 시점 (백업·복제 주기 기준) |
| | WRT (Work Recovery Time) | 시스템 복구 후 데이터 검증·밀린 업무 처리 시간 |
| | MBCO | 중단 중 유지해야 할 최소 서비스 수준 |
| 영향 분석 | 정량 영향 | 매출 손실, 위약금, 과징금, 복구 비용 |
| | 정성 영향 | 평판·고객 신뢰, 규제 제재, 안전 |
| 의존성 | 자원·의존성 매핑 | IT 시스템, 인력, 시설, 외부 공급사·클라우드 |

---

## III. 위험 평가 비교 및 동향

### 가. BIA vs RA (Risk Assessment)

| 구분 | BIA | RA |
| --- | --- | --- |
| 초점 | 중단의 결과(영향) | 중단의 원인·가능성 |
| 핵심 질문 | 멈추면 얼마나 손실이며 언제까지 복구해야 하나? | 어떤 위협·취약점이 중단을 일으키나? |
| 산출물 | 복구 목표, 업무 우선순위 | 위험 목록, 위험도, 완화 계획 |
| 활용 | 복구 전략·자원 결정 | 예방·완화 통제 결정 |

### 나. 동향

- **외부 의존성 확대**: 클라우드 [[CSP]]·SaaS·핵심 협력사 장애를 BIA 범위에 포함
- **지속적 BIA**: 설문·인터뷰 위주의 연 1회 분석에서 CMDB·관측성 데이터와 연계한 상시 갱신으로 전환
- **사이버 사고 시나리오**: 랜섬웨어처럼 데이터 무결성이 깨지는 상황의 복구 시점(RPO) 재검토
