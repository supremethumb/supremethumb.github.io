# 연산자 (Operator)

---

## I. 값을 계산하고 흐름을 가르는 기호, 연산자의 개요

### 가. 정의

- **피연산자(Operand)에 산술·비교·논리·비트 등의 연산을 적용해 결과값을 만드는 기호 또는 예약어**

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 데이터 처리 | 변수·상수를 계산·결합해 새 값 생성 |
| 흐름 제어 | 관계·논리 연산 결과로 조건문·반복문 분기 |
| 평가 규칙 | 우선순위(Precedence)와 결합성(Associativity)으로 계산 순서 결정 |
| 하드웨어 대응 | 대부분 [[CPU]]의 ALU·FPU 명령 하나로 번역 |

---

## II. 평가 과정 및 구성요소

### 가. 수식 평가 과정

```mermaid
flowchart LR
    SRC["수식<br/>a + b * c"] -- "구문 분석" --> AST["구문 트리<br/>+ (a, * (b, c))"]
    AST -- "코드 생성" --> ISA["기계어<br/>MUL → ADD"]
    ISA --> ALU["ALU / FPU 실행"] --> R["결과"]
```

- 곱셈이 덧셈보다 우선순위가 높아 b * c를 먼저 계산, 같은 우선순위는 결합성(대부분 왼쪽→오른쪽, 대입은 오른쪽→왼쪽)으로 결정

### 나. 구성요소 (연산자 분류)

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 산술 | + - * / % | 사칙연산·나머지, 정수 나눗셈의 몫 처리와 부동소수점 오차 주의 |
| 관계 | == != < > <= >= | 비교 결과를 [[Boolean Type\|Boolean]]으로 반환 |
| 논리 | && \|\| ! | AND·OR·NOT, 단축 평가 적용 |
| 비트 | & \| ^ ~ << >> | 비트 단위 AND·OR·XOR·NOT·시프트, 마스킹·플래그 처리 |
| 대입 | = += -= 등 | 값 저장, 복합 대입 |
| 조건 | 조건 ? 참 : 거짓 | 삼항 연산자, 간단한 if-else 대체 |
| 평가 방식 | 단축 평가 | A && B에서 A가 거짓이면 B 평가 생략 (A \|\| B는 A가 참이면 생략) |
| 객체 지향 | 연산자 오버로딩 | 사용자 정의 [[클래스]]에 연산자 의미 재정의 ([[다형성\|Polymorphism]]) |
| Null 안전 | ?? ?. ?: | 널 병합, 옵셔널 체이닝, 엘비스 연산자 |

## III. 비교 및 동향

### 가. 논리 연산자 vs 비트 연산자

| 비교 항목 | 논리 연산자 | 비트 연산자 |
| --- | --- | --- |
| 기호 | && \|\| ! | & \| ^ ~ |
| 평가 | 단축 평가 | 양쪽 모두 평가 |
| 연산 단위 | 참·거짓 값 | 정수의 각 비트 |
| 용도 | 조건 분기, 복합 조건 | 하드웨어 레지스터 제어, 마스킹, 해시·암호 연산 |

### 나. 동향

- **강도 경감 (Strength Reduction)**: 컴파일러가 2의 거듭제곱 곱셈·나눗셈을 시프트로, 반복문 내 곱셈을 덧셈으로 바꾸는 최적화
- **Null 안전 연산자 확산**: Kotlin(?:, ?.), Swift·C#·TypeScript(??, ?.) 등 널 참조 오류를 줄이는 연산자 기본 제공
