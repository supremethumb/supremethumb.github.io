# 거리 벡터 알고리즘 (Distance Vector Algorithm)

---

## I. 인접 라우터 간 정보 교환 기반 경로 결정, 거리 벡터 알고리즘의 개요

### 가. 정의

- 벨만-포드(Bellman-Ford) 알고리즘을 기반으로, 각 [[라우터]]가 목적지까지의 **거리(Distance)와 방향(Vector, Next Hop)** 을 담은 라우팅 테이블 전체를 **인접 라우터와 주기적으로 교환**하여 최적 경로를 결정하는 동적 [[라우팅 알고리즘]]

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 이웃 의존 | 전체 토폴로지를 모르고 인접 라우터의 정보에만 의존 ("소문에 의한 라우팅") |
| 주기적 갱신 | 변화와 무관하게 일정 주기(RIP 30초)마다 전체 테이블 전송 |
| 낮은 자원 소모 | 구현이 단순하고 메모리·[[CPU]] 사용량이 적음 |
| 느린 수렴 | 변화 전파가 느려 라우팅 루프와 Count-to-Infinity 문제 발생 가능 |

---

$$D_x(y) = \min_{v}\{\, c(x, v) + D_v(y) \,\}$$

- 라우터 $x$는 이웃 $v$가 알려준 목적지 $y$까지의 거리 $D_v(y)$에 자신과 $v$ 사이의 링크 비용 $c(x,v)$를 더해 최솟값으로 테이블을 갱신
- 예: A–B 비용 1, B가 알려준 B→C 비용 1 → A→C = 1 + 1 = 2, Next Hop = B (위 그림)

### 나. 핵심 기술 요소

| 분류 | 요소 | 설명 |
| --- | --- | --- |
| 수학적 기반 | Bellman-Ford | 이웃 정보로 최단 거리를 반복 갱신 |
| 메트릭 | Hop Count 등 | RIP는 홉 수(최대 15, 16 = 무한대), IGRP는 대역폭·지연 복합 |
| 루프 방지 | Split Horizon | 정보를 받은 인터페이스로는 같은 정보를 다시 보내지 않음 |
| | Route Poisoning | 장애 경로의 메트릭을 무한대(16)로 설정해 즉시 전파 |
| | Poison Reverse | 이웃에게서 배운 경로를 그 이웃에게 무한대 메트릭으로 되돌려 알려 루프 차단 (Split Horizon 강화형) |
| | Hold-down Timer | 장애 경로에 대해 일정 시간 다른 갱신 정보를 무시 |
| 수렴 개선 | Triggered Update | 변화 감지 시 주기를 기다리지 않고 즉시 전송 |
| 대표 [[프로토콜]] | RIP, IGRP | 거리 벡터 방식 IGP |

## III. 링크 상태 알고리즘과의 비교 및 동향

### 가. 거리 벡터 vs 링크 상태

| 비교 항목 | 거리 벡터 | [[링크 상태 알고리즘\|링크 상태]] |
| --- | --- | --- |
| 기반 알고리즘 | Bellman-Ford | [[다익스트라 알고리즘\|Dijkstra]] |
| 교환 대상 | 인접 라우터 | 모든 라우터 (Flooding) |
| 교환 정보 | 라우팅 테이블 전체 | 자신의 링크 상태 (LSA) |
| 갱신 시점 | 주기적 | 변화 발생 시 |
| 토폴로지 인지 | 부분적 (이웃만) | 전체 (LSDB) |
| 수렴·루프 | 느림, 루프 발생 가능 | 빠름, 루프 거의 없음 |
| 자원 소모 | 적음 | 많음 |
| 대표 프로토콜 | RIP, IGRP | OSPF, IS-IS |
| 적합 규모 | 소규모 | 중·대규모 (Area 분할) |

### 나. 동향

- 기업·통신사 내부망은 OSPF 등 링크 상태 방식이 주류이며, 거리 벡터는 소규모 망에 한정
- 거리 벡터의 개념은 혼합형 EIGRP(DUAL)와 경로 벡터 방식 [[BGP]]의 기반으로 계승
- [[SDN(Software Defined Network)|SDN]]에서는 컨트롤러가 경로를 중앙에서 계산하는 방식으로 진화
