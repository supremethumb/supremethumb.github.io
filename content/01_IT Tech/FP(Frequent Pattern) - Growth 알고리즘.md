# FP-Growth (Frequent Pattern Growth)

---

## I. 후보 생성 없는 빈발 패턴 탐색, FP-Growth의 개요

### 가. 정의

- 트랜잭션을 **FP-Tree로 압축 저장한 뒤 조건부 패턴 기저와 조건부 FP-Tree를 재귀적으로 만들어, 후보 생성 없이 빈발 항목 집합을 찾는 알고리즘** (Han·Pei·Yin, 2000)

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 후보 생성 없음 | Apriori의 후보 폭증 문제 제거 |
| DB 스캔 2회 | 1회: 항목 빈도 계산, 2회: FP-Tree 구축 |
| 압축 | 공통 접두 경로를 공유하는 Prefix Tree |
| 분할 정복 | 항목별 조건부 트리로 문제를 나눠 재귀 탐색 |

---

## II. 동작 원리 및 구성요소

### 가. 동작 절차

```mermaid
flowchart LR
    S1["1차 스캔<br/>항목 빈도 계산<br/>최소 지지도 미달 제거·빈도순 정렬"] --> S2["2차 스캔<br/>트랜잭션을 빈도순으로 정렬해<br/>FP-Tree에 삽입"]
    S2 --> S3["마이닝<br/>헤더 테이블 하위 항목부터<br/>조건부 패턴 기저 추출"]
    S3 --> S4["조건부 FP-Tree 구축<br/>→ 재귀적으로 빈발 패턴 생성"]
```

- 빈도가 낮은 항목부터 경로를 역추적해 접두 경로 집합을 만들고, 이를 작은 트리로 다시 탐색

### 나. 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 기준 | 최소 [[지지도]] | 빈발로 인정하는 최소 출현 빈도 |
| 자료구조 | 헤더 테이블 | 빈발 항목, 빈도, 트리 내 첫 노드 포인터 |
| | FP-Tree | 빈도순 정렬 트랜잭션을 공통 접두로 공유해 압축한 트리 (노드: 항목·카운트) |
| | 노드 링크 | 같은 항목의 노드들을 연결 리스트로 연결 |
| 마이닝 | 조건부 패턴 기저 | 특정 항목(접미)으로 끝나는 접두 경로와 카운트 집합 |
| | 조건부 FP-Tree | 조건부 패턴 기저 중 빈발 항목으로만 만든 작은 트리 |
| 원리 | 패턴 성장 | 접미 패턴에 조건부 트리의 빈발 항목을 붙여 패턴 확장 |

## III. 비교 및 동향

### 가. Apriori vs FP-Growth

| 비교 항목 | [[Apriori 알고리즘\|Apriori]] | FP-Growth |
| --- | --- | --- |
| 원리 | 후보 생성·검증 | 트리 압축·패턴 성장 |
| DB 스캔 | 최대 빈발 집합 크기만큼 반복 | 2회 |
| 메모리 | 후보 집합 | FP-Tree (데이터가 희소하면 커질 수 있음) |
| 속도 | 낮은 지지도에서 느림 | 일반적으로 빠름 |
| 적합 | 소규모, 교육용 | 대규모 트랜잭션 |

### 나. 동향

- **병렬 FP-Growth (PFP)**: 항목 그룹별로 조건부 트리를 분산 처리, Spark MLlib `FPGrowth`로 제공
- **스트림 마이닝**: FP-Stream 등 슬라이딩 윈도 단위로 트리를 점진 갱신
