# 고객여정지도 (Customer Journey Map)

---

## I. 고객 경험(CX) 혁신을 위한 시각화 도구, 고객여정지도의 개요

### 가. 고객여정지도의 정의

- 고객이 브랜드를 **인지하는 순간부터 고려·구매·유지·옹호에 이르는 전 과정**을 시간 순서로 시각화하여, 접점(Touchpoint)별 행동·감정·불편(Pain Point)을 분석하는 CX 전략 [[프레임워크]]

### 나. 작성 목적

| 목적 | 내용 |
| --- | --- |
| Pain Point 발견 | 고객이 겪는 불편·불만을 식별하여 개선 기회 포착 |
| WOW Point 도출 | 고객 감동을 만드는 핵심 경험 요소 발굴 |
| 조직 정렬 | 고객 관점으로 부서 간(Cross-Functional) 협업 기준 제공 |

### 나. 핵심 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 주체 | [[페르소나\|페르소나 (Persona)]] | 대표 고객의 가상 인물 (특성, 목표, 문제점) |
| 여정 흐름 | 단계 (Stages / Timeline) | 인지 → 고려 → 결정 → 유지 → 옹호 (이용 전·중·후) |
| | 터치포인트 | 고객과 브랜드가 상호작용하는 온·오프라인 접점 (SNS, 웹, CS 센터 등) |
| 고객 경험 | 감정 곡선 (Emotion Curve) | 단계별 만족·불만족 변화를 그래프로 표현 |
| | 결정적 순간 (MOT) | 만족도가 확정되는 진실의 순간, 집중 관리 대상 |
| 전략 도출 | Pain Point & 기회 | 불편 요인과 내부 [[프로세스]] 개선·비즈니스 기회 |
| | 행동 및 KPI | 단계별 고객 행동과 경험 품질 측정 지표 |

## III. 작성 절차, 유사 도구 비교 및 동향

### 가. 작성 절차

| 단계 | 활동 |
| --- | --- |
| 1. 조사 | 심층 인터뷰·관찰로 서비스 이용 과정 파악 |
| 2. 분석 | 대상자들의 공통 행동 패턴 도출, 페르소나 확정 |
| 3. 시각화 | 단계·터치포인트·감정 곡선을 하나의 지도로 도식화 |
| 4. 도출 | Pain Point와 WOW Point로 해결할 문제 정의 |

### 나. 유사 도구 비교

| 구분 | 공감지도 (Empathy Map) | 고객여정지도 | 서비스 블루프린트 |
| --- | --- | --- | --- |
| 관점 | 특정 시점의 고객 내면 | 시간 흐름에 따른 고객 경험 | 고객 경험 + 내부 운영 |
| 내용 | 말·생각·행동·감정 | 단계, 터치포인트, 감정, Pain Point | 고객 행동, 가시선 위아래 직원 활동, 지원 프로세스 |
| 활용 | [[디자인 씽킹]] 공감 단계 | 공감·문제 정의 단계 | 서비스 운영 설계·개선 |

### 다. 동향

- **VoC 기반 지속 갱신**: 리뷰·SNS·콜센터 녹취 등 비정형 VoC를 분석해 지도를 정기적으로 갱신
- **여정 분석 (Journey Analytics)**: 실제 행동 로그로 여정을 재구성하고 이탈 구간을 데이터로 검증
- **AI 초개인화**: 터치포인트별 맞춤 추천·대화형 AI 상담으로 Pain Point 구간 개선
