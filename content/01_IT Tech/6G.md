# 6G (IMT-2030)

---

## I. 초공간·초지능·초실감의 차세대 이동통신, 6G의 개요

### 가. 6G의 정의

- 최대 **1Tbps**(5G의 50배), 무선 지연 **0.1ms**, 지상·해상·공중을 아우르는 **3차원 커버리지**와 망 전반의 **AI 내재화(AI-Native)** 를 목표로 하는 6세대 이동통신 (ITU-R 명칭: IMT-2030)

### 나. 등장 배경 및 특징

| 구분 | 내용 |
| --- | --- |
| 등장 배경 | 몰입형 XR·홀로그램·고해상도 [[디지털 트윈]]의 초대용량 트래픽, [[UAM]] 등 3차원 이동체 연결 필요 |
| 초광대역 | 테라헤르츠(THz) 대역 활용 |
| 초공간 | [[비지상네트워크\|NTN]](저궤도 위성, HAPS) 통합 |
| 초지능 | 설계 단계부터 AI를 내장한 자율 운영 망 |
| 통신·센싱 융합 | ISAC으로 통신 신호를 센싱에 동시 활용 |

### 나. 6대 성능 비전 (대·성·공·정·지·신)

| 비전 | 성능 목표 | 핵심 기술 |
| --- | --- | --- |
| 초대역 | 최대 1Tbps | THz(100GHz~10THz), 초대규모 [[MIMO]] |
| 초성능 | 체감 1Gbps, 스펙트럼 효율 향상 | OAM [[다중화]], 전이중(In-band Full Duplex) |
| 초공간 | 지상 10km 상공, 시속 1,000km 이동성 | NTN([[저궤도 위성]]), HAPS |
| 초정밀 | 무선 지연 0.1ms, 지터 수 μs | 시간 확정형 네트워크, 초정밀 측위 |
| 초지능 | 네트워크 자율화, E2E 자동화 | AI-Native Air Interface, In-Network Computing |
| 초신뢰 | 신뢰도 $10^{-9}$, 보안 강화 | [[양자 암호]](QKD)·[[양자내성암호\|PQC]] 내재화 |

### 다. 주요 기술 요소

| 기술 | 설명 |
| --- | --- |
| RIS (지능형 반사표면) | 메타물질로 전파의 반사·투과 방향을 SW로 제어하여 THz의 직진성·음영 한계 극복 |
| ISAC (통신·센싱 결합) | 기지국·단말 전파를 레이더처럼 활용해 위치·움직임 정밀 센싱 |
| In-Network Computing | [[라우터]]·스위치 등 망 장비가 전달과 연산을 동시 수행 |
| 디지털 트윈 네트워크 | 실망과 동기화된 가상 망에서 정책·최적화를 사전 검증 ([[디지털 트윈 네트워크]]) |

## III. 5G와의 비교 및 전망

### 가. 5G vs 6G 비교

| 항목 | 5G (IMT-2020) | 6G (IMT-2030) | 비고 |
| --- | --- | --- | --- |
| 최대 전송속도 | 20 Gbps | 1 Tbps | 50배 |
| 체감 전송속도 | 100 Mbps | 1 Gbps | 10배 |
| 무선 지연 | 1 ms | 0.1 ms | 1/10 |
| 연결 밀도 | 10⁶ 대/km² | 10⁷ 대/km² | 10배 |
| 이동성 | 500 km/h | 1,000 km/h | 항공기 지원 |
| 주파수 | Sub-6GHz, mmWave | THz 추가 | 대역 확장 |
| 커버리지 | 지상 (2D) | 지상 + 해상 + 공중 (3D) | NTN 통합 |
| AI 적용 | 부가 연동 (Add-on) | 내재화 (AI-Native) | |

### 나. 과제 및 전망

- **기술 과제**: THz의 높은 경로 손실 극복을 위한 고효율 PA·RIS 상용화, 대규모 안테나로 인한 전력 소모 증가 → **에너지 효율이 핵심 KPI** (Green 6G)
- **표준화**: ITU-R IMT-2030 프레임워크 확정 이후 3GPP Release 20부터 6G 연구가 본격화되어 2030년 전후 상용화 목표
- **경쟁 요소**: 저궤도 위성 확보와 주파수 선점이 국가 경쟁력의 핵심 ([[5G]] 진화의 연장선)
