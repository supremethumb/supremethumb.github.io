# 서포트 벡터 머신 (SVM; Support Vector Machine)

---

## I. 마진을 최대화하는 분류기, 서포트 벡터 머신의 개요

### 가. 정의

- 클래스 사이 **마진(Margin)을 최대화하는 결정 초평면을 찾아 분류·회귀**하는 [[지도학습]] 모델

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 일반화 | 마진 최대화(구조적 위험 최소화)로 과적합 억제 |
| 비선형 처리 | 커널 트릭으로 고차원 사상 없이 비선형 경계 학습 |
| 희소성 | 결정 경계가 서포트 벡터에만 의존 |
| 한계 | 학습 비용이 표본 수에 대해 대략 $O(n^2)$~$O(n^3)$, 대규모 데이터에 부담, 확률 출력이 기본 제공되지 않음 |

---

## II. 동작 원리 및 구성요소

### 가. 개념도

```mermaid
flowchart LR
    D["입력 공간<br/>비선형 데이터"] --> K["커널 함수<br/>(선형, 다항, RBF)"]
    K --> F["특징 공간<br/>(암묵적 고차원)"]
    F --> SV["서포트 벡터 식별"]
    SV --> M["마진 최대화<br/>(라그랑주 쌍대 문제)"]
    M --> H["최적 초평면"]
    H --> O["분류·회귀 결과"]
```

- 커널로 계산한 고차원 내적 공간에서 마진을 최대화하는 선형 경계를 찾고, 원래 공간에서는 비선형 경계가 됨

### 나. 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 결정 경계 | 초평면 | $w^Tx + b = 0$, 2차원은 직선·3차원은 평면 |
| | 서포트 벡터 | 경계에 가장 가까운 표본, 경계를 결정 |
| | 마진 | 양쪽 서포트 벡터 사이 거리 $2/\lVert w \rVert$, 최대화 대상 |
| 오류 허용 | 하드 마진 | 오분류 불허, 선형 분리 가능할 때만 성립 |
| | 소프트 마진 | 슬랙 변수 $\xi$로 일부 오분류 허용, [[이상치]]에 강건 |
| 비선형 | 커널 트릭 | 사상 $\phi$ 없이 $K(x_i, x_j) = \phi(x_i)^T\phi(x_j)$로 내적 계산 |
| | RBF 커널 | $\exp(-\gamma\lVert x_i - x_j\rVert^2)$, 무한 차원 특징 공간에 대응 |
| 최적화 | 라그랑주 쌍대·KKT | 제약 최적화를 쌍대 문제로 풀어 커널 적용 (SMO 알고리즘) |
| 하이퍼파라미터 | C | 클수록 오분류 벌점↑(하드 마진에 가까움), 작을수록 마진 넓음 |
| | $\gamma$ | 클수록 각 표본의 영향 범위가 좁아 경계가 복잡 |

---

## III. 비교 및 동향

### 가. 주요 분류 모델 비교

| 비교 항목 | SVM | 인공신경망 | [[로지스틱회귀분석\|로지스틱 회귀]] |
| --- | --- | --- | --- |
| 학습 원리 | 마진 최대화 (힌지 손실) | [[역전파]]로 손실 최소화 | 최대우도 (로그 손실) |
| 적합 데이터 | 중소규모, 고차원 | 대규모, 비정형 | 선형 경계, 해석 필요 |
| 해석력 | 중간 (선형 커널은 가중치 해석 가능) | 낮음 ([[블랙박스 모델]]) | 높음 |
| 하이퍼파라미터 | C, $\gamma$, 커널 | 층·노드 수, 학습률 | 규제 강도 |
| 출력 | 결정 함수 값 (확률은 Platt Scaling으로 보정) | 확률 | 확률 |

### 나. 동향

- **고차원 소표본 분야의 기준 모델**: 텍스트 분류, 유전자 발현 데이터 등에서 여전히 강한 베이스라인
- **대규모 대응**: 선형 SVM(LIBLINEAR)·SGD 기반 학습, 커널 근사(Random Fourier Features)로 확장
- **양자 커널**: 양자 회로로 커널을 계산하는 QSVM 연구가 진행 중이나 실용적 우위는 아직 입증되지 않음
