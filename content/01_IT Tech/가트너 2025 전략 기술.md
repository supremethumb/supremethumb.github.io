# 가트너 2025 전략 기술 (Gartner Top 10 Strategic Technology Trends for 2025)

---

## I. 생성을 넘어 자율과 실행으로, 가트너 2025 전략 기술의 개요

### 가. 정의

- 생성형 AI를 넘어 스스로 계획·행동하는 [[에이전틱 AI]], 새로운 컴퓨팅 영역, 인간–기계 시너지를 중심으로 Gartner가 제시한 **2025년 기업이 주목해야 할 10대 기술 트렌드**

### 나. 3대 주제

| 주제 | 의미 |
| --- | --- |
| AI Imperatives & Risks | AI의 자율성 확대와 그에 따른 위험 관리 |
| New Frontiers of Computing | 보안·에너지·이종 컴퓨팅 등 컴퓨팅 한계 극복 |
| Human-Machine Synergy | 물리·디지털 융합을 통한 인간 능력 증강 |

### 나. 기술별 핵심 내용

| 주제 | 기술 | 핵심 내용 |
| --- | --- | --- |
| AI 필수·위험 | ① Agentic AI | 사용자 목표를 위해 스스로 계획하고 행동하는 AI |
| | ② [[AI 거버넌스\|AI Governance]] Platforms | AI의 [[신뢰성]]·투명성·책임성을 관리하는 플랫폼 ([[AI TRiSM]]) |
| | ③ Disinformation Security | [[딥페이크]] 등 허위 정보의 진위 확인·탐지 |
| 새로운 컴퓨팅 | ④ Post-Quantum Cryptography | 양자 컴퓨터 공격에 견디는 [[양자내성암호\|PQC]] (격자 기반 등) |
| | ⑤ Ambient Invisible Intelligence | 초저가 태그·센서로 사물을 눈에 띄지 않게 추적·감지 |
| | ⑥ Energy-Efficient Computing | 탄소 발자국을 줄이는 고효율 하드웨어·알고리즘 |
| | ⑦ Hybrid Computing | [[CPU]]·[[GPU]]·양자·[[뉴로모픽 칩\|뉴로모픽]] 등 이종 컴퓨팅 결합 |
| 인간–기계 시너지 | ⑧ Spatial Computing | AR/VR/XR로 물리·디지털 세계 융합 |
| | ⑨ Polyfunctional Robots | 여러 작업을 수행하며 사람과 협업하는 다목적 로봇 |
| | ⑩ Neurological Enhancement | BCI로 뇌 활동을 해독해 인지 능력 향상 |

## III. 2024·2025·2026 비교 및 대응 전략

### 가. 연도별 핵심 흐름 비교

| 구분 | 2024 | 2025 | 2026 |
| --- | --- | --- | --- |
| AI 축 | 생성형 AI 민주화, AI TRiSM | Agentic AI, AI 거버넌스 플랫폼 | 다중 에이전트 시스템, DSLM, 피지컬 AI |
| 보안 축 | CTEM(지속적 위협 노출 관리) | PQC, 허위정보 보안 | 선제적 사이버 보안, AI 보안 플랫폼 |
| 인프라 축 | 지속가능한 기술 | 에너지 효율·하이브리드 컴퓨팅 | AI 슈퍼컴퓨팅, 기밀 컴퓨팅, 지오패트리에이션 |

### 나. 대응 전략

- **AI 자율성 대비**: 행동하는 AI의 권한 범위·감사 추적을 정하는 AI 거버넌스 체계 선제 확립
- **보안 전환**: PQC 전환 로드맵(암호 자산 목록화 → 하이브리드 적용)과 딥페이크 탐지 도입
- **지속가능성**: 에너지 효율 컴퓨팅으로 AI 확산에 따른 전력·탄소 부담 관리 (후속 트렌드는 [[가트너 2026 전략 기술]])
