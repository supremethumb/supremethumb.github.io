# 소프트웨어 난독화 (Software Obfuscation)

---

## I. 역공학 방지 및 지적재산권 보호를 위한 보안 설계 기술, SW 난독화의 개요

* **정의**: 소프트웨어의 원래 기능과 동작을 유지하면서, 소스코드나 바이너리를 사람이 이해하거나 분석하기 어렵도록 변환하여 역공학(Reverse Engineering) 및 무단 유출을 방지하는 보안 공학 기술
* 모바일 앱 및 임베디드 기기의 소스 유출 방지, 리버싱(Reversing) 공격 지연 및 [[무결성]](Tamper Resistance) 확보 목적
* 특징: 기능 동등성(Function Preservation), 복잡성 증대(Resilience), 역공학 저항성(Stealth)

---

## II. SW 난독화의 아키텍처 및 핵심 구성요소

### 가. SW 난독화 프로세스 및 동작 원리

```mermaid
flowchart TB
    subgraph Process["Software Obfuscation Process"]
        direction LR
        SRC["원본 소스코드 /<br/>바이너리"] --> ENG["난독화 엔진<br/>(Obfuscator)"]
        ENG --> CF["제어 흐름 변환<br/>(Flattening / Opaque)"]
        CF --> DT["데이터 난독화<br/>(Encoding / Renaming)"]
        DT --> VM["가상화 및 안티 분석<br/>(Virtualization / Anti-Debug)"]
        VM --> OUT["배포용 난독화 바이너리<br/>(App Guarding)"]
    end

```

* 원본 코드를 [[난독화]] 엔진에 입력하여 제어 흐름, 식별자, 데이터를 변환하고 [[가상화]] 및 안티 디버깅 기법을 적용하여 최종 분석 방어 코드를 생성하는 [[프로세스]]

### 나. SW 난독화의 핵심 기술 및 구성 요소

| 분류 | 요소기술(키워드) | 세부 설명 |
| --- | --- | --- |
| 제어 흐름 | 제어 흐름 평탄화 (Control Flow Flattening) | 기본 블록 구조를 단일 스위치문 루프로 변환하여 코드 흐름 분석 방해 |
| 제어 흐름 | 불투명 술어 (Opaque Predicate) | 참/거짓이 이미 결정된 조건문을 삽입하여 분석가의 판단 혼란 유도 |
| 데이터 | 데이터 인코딩 / [[암호화]] | 상수나 민감 문자열을 암호화 또는 인코딩하여 정적 분석 시 노출 차단 |
| 레이아웃 | 식별자 난독화 (Identifier Renaming) | 변수명, 함수명을 의미 없는 문자열(a, b, c 등)로 변경하여 가독성 저하 |
| 코드 보호 | 가상화 기반 난독화 (Virtualization) | 자체 바이트코드와 커스텀 VM 인터프리터를 생성하여 실행 분석 난이도 극대화 |
| 안티 분석 | 안티 디버깅 (Anti-[[Debugging]]) | 디버거 부착 여부를 탐지하여 프로세스 강제 종료 또는 비정상 동작 유도 |
| 안티 분석 | 안티 탐지·위조 (Anti-Tampering) | 코드 체크섬([[CRC]]) 검증을 통해 바이너리 변조 여부를 상시 감지 및 차단 |
| 최신 트렌드 | AI 기반 동적 난독화 | [[초거대 언어 모델|LLM]] 기반 자동 역공학에 대응하기 위한 [[다형성]]·변성 코드 동적 생성 |

## III. SW 난독화의 한계점 및 최신 트렌드

| 비교/구분 | 전통적 정적 난독화 | 최신 지능형 난독화 및 앱 가드 (App Shielding) |
| --- | --- | --- |
| **적용 방식** | 빌드 시 일회성 식별자 변경 및 코드 난독화 적용 | 런타임 코드 무결성 검증, 동적 변성 및 가상화 복합 적용 |
| **방어 수준** | 디컴파일러 및 단순 정적 분석 도구에 쉽게 우회됨 | AI 기반 자동 역공학 및 디버깅 공격에 대응 가능한 다중 방어 |
| **성능 영향** | 오버헤드가 상대적으로 낮음 | 가상화 및 실시간 검증으로 인한 성능 저하(Performance Overhead) 발생 |

* 최근 생성형 AI를 활용한 자동 역공학(De-obfuscation) 기술이 발전함에 따라, 단순 식별자 변경을 넘어 가상화 기반 난독화, 런타임 무결성 검증, 그리고 제로 트러스트 기반의 앱 실딩(App Shielding) 기술을 결합하는 방향으로 진화 중
