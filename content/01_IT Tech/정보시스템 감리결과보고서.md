# 정보시스템 감리결과보고서

---

## I. 감리 판단을 공식 문서로, 감리결과보고서의 개요

### 가. 정의

- 감리법인이 **현장 감리에서 확인한 사업 수행 현황·문제점·개선 권고를 정리해 발주기관에 제출하는** 공식 감리 산출물 (「정보시스템 감리기준」에 따른 감리수행결과보고서)

### 나. 필요성 및 특징

| 구분 | 내용 |
| --- | --- |
| 객관적 진단 | 단계별 사업 품질 수준을 제3자 관점에서 제시 |
| 시정조치 근거 | 사업자가 이행할 개선 사항과 기준 제시 |
| 의사결정 지원 | 발주기관의 단계 진행·검사 판단 자료 |
| 이력 관리 | 요구정의·설계·종료 단계별 품질 통제 이력 보존 |

---

## II. 작성 흐름 및 구성요소

### 가. 작성·후속 조치 흐름

```mermaid
flowchart LR
    A["현장 감리<br/>(산출물 검토 · 인터뷰 · 시험)"] --> B["문제점 식별 · 판단"]
    B --> C["감리수행결과보고서 작성 · 제출"]
    C --> D["발주기관 통보"]
    D --> E["사업자 시정조치 계획 · 이행"]
    E --> F["시정조치 확인 (감리법인)"]
```

- 현장 감리 결과를 근거와 함께 문서화해 발주기관에 제출하고, 사업자의 시정조치를 감리법인이 확인하는 순환 구조

### 나. 구성요소 (예)

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 개요 | 감리 개요 | 사업명, 감리 단계·기간, 적용 기준, 감리원 편성 |
| 종합 | 종합 의견 | 사업 전반의 수준 평가와 핵심 위험 요약 |
| 상세 | 영역별 점검 결과 | 사업관리·응용시스템·DB·시스템구조 및 보안 영역별 결과 |
| | 문제점 · 개선 권고 | 현황, 영향, 구체적 개선 방향과 조치 시기 |
| 부록 | 점검 항목별 결과 | 점검 항목별 판단과 확인 방법·근거 |
| 작성 원칙 | 객관성 · 추적성 | 사실과 증적에 근거, 해당 산출물 위치 명시 |
| | 실행 가능성 | 사업자가 기한 내 조치할 수 있는 구체적 권고 |

---

## III. 비교 및 동향

### 가. 감리수행결과보고서 vs 시정조치 확인 결과

| 비교 항목 | 감리수행결과보고서 | 시정조치 확인 결과 |
| --- | --- | --- |
| 시점 | 현장 감리 종료 후 | 사업자 시정조치 완료 후 |
| 목적 | 문제점 식별·개선 권고 | 권고 사항 이행 여부 확인 |
| 주요 내용 | 영역별 점검 결과, 개선 권고 | 권고 항목별 조치 내용과 확인 결과 |
| 활용 | 단계별 품질 현황 진단 | 다음 단계 진행·검사 판단 근거 |

### 나. 동향

- 감리 증적을 입력해 개선 권고 초안을 생성하는 LLM 기반 작성 지원
- 애자일·클라우드 사업에서 CI/CD 품질 지표를 연계한 상시 감리 대시보드 시도
