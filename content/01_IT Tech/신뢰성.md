# 신뢰성 (Reliability)

---

## I. 정해진 조건에서 고장 없이, 신뢰성의 개요

### 가. 정의

- 시스템이 **명시된 조건에서 명시된 기간 동안 요구 기능을 고장 없이 수행하는 정도** ([[ISO IEC 25010 2023|ISO/IEC 25010]] 품질 특성)

### 나. 필요성

| 구분 | 내용 |
| --- | --- |
| 사업 연속성 | 장애로 인한 손실·신뢰도 하락 방지 ([[BCP]]) |
| 분산 환경 | [[MSA (Micro Service Architecture)\|MSA]]에서 일부 장애의 전체 전파 차단 필요 |
| 관점 변화 | 장애 예방 중심에서 장애 수용·신속 복구(Resilience)로 확장 |
| 측정 근거 | MTTF·MTTR 등 지표로 목표 설정·검증 |

---

## II. 측정 지표 및 구성요소

### 가. 고장·복구 시간 구조

```mermaid
flowchart LR
    S(("가동")) -- "MTTF (평균 무고장 시간)" --> F["고장"]
    F -- "MTTR (평균 수리 시간)" --> R(("복구"))
    R -- "MTTF" --> F2["다음 고장"]
```

- 고장 간 평균 간격 MTBF = MTTF + MTTR, 가용성 A = MTTF / (MTTF + MTTR)

### 나. 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 부특성 (25010) | 무결함성 (Faultlessness) | 정상 운영 시 결함 없이 동작 (2011판 성숙성 대체) |
| | [[HA(High Availability)\|가용성]] | 필요할 때 사용 가능한 정도 |
| | 결함 허용성 | 결함이 있어도 기능 유지 |
| | 복구성 | 장애 후 데이터·상태 회복 |
| 지표 | 신뢰도 R(t) | 지수 분포 가정 시 R(t) = e^(−λt) (λ: 고장률) |
| | MTTF · MTTR · MTBF | 무고장 시간, 수리 시간, 고장 간격 |
| 설계 기법 | 이중화 · 페일오버 | Active-Standby·Active-Active, 데이터 복제로 SPOF 제거 |
| | 회복성 패턴 | [[서킷브레이커]]·[[Timeout]]·재시도·Bulkhead |
| 검증 · 운영 | [[카오스 엔지니어링]] | 장애 주입으로 복원력 검증 |
| | [[SRE (Site Reliability Engineering)\|SRE]] | SLO·오류 예산으로 신뢰성과 출시 속도 균형 |

---

## III. 비교 및 동향

### 가. 신뢰성 vs 가용성

| 비교 항목 | 신뢰성 | 가용성 |
| --- | --- | --- |
| 개념 | 일정 기간 고장 없이 동작할 확률 | 임의 시점에 사용 가능한 확률 |
| 산식 | R(t) = e^(−λt), MTTF | A = MTTF / (MTTF + MTTR) |
| 개선 방향 | 고장 발생 감소 (MTTF 증가) | 고장 발생 감소 + 복구 단축 (MTTR 감소) |
| 예 | 1년 무고장 동작 확률 | 99.99% 가동률 |

### 나. 동향

- 로그·메트릭 분석으로 장애 징후를 미리 탐지하는 AIOps
- 외부 의존 장애 시 Fallback과 Graceful Degradation 설계 강조
- 멀티 리전 Active-Active로 재해 시 RTO·RPO 단축
