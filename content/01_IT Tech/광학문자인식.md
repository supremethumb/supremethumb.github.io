# 광학문자인식(OCR)

---

## I. 비정형 문서의 디지털 자산화, 광학문자인식(OCR)의 개요

### 가. OCR의 정의
- 인쇄물이나 사진, 스캔 문서 내의 아날로그 시각적 문자 기호를 컴퓨터 비전 및 딥러닝 신경망으로 식별하여 기계 판독이 가능한 디지털 텍스트 데이터로 변환하는 기술이다.

### 나. OCR의 등장 배경 및 주요 특징

| 구분 | 주요 내용 |
| --- | --- |
| 폰트 한계 극복 | 기존 템플릿/패턴 매칭의 정형 폰트 의존성을 탈피하고 악필 필기체 및 회전·노이즈 환경 적응력 확보 |
| 딥러닝 기술 융합 | CNN의 특징 추출, RNN의 시퀀스 인식, TrOCR의 비전 트랜스포머 패치 어텐션 결합으로 인식률 극대화 |
| Document AI 진화 | 단순 평면적 텍스트 추출을 넘어 다단 문서, 표(Table), 서식 구조를 분석하는 구조화 파이프라인 정착 |
| 멀티모달 RAG 기반 | 기업 비정형 문서(PDF, 계약서 등)를 벡터 DB화하여 LLM 프롬프트 맥락으로 주입하는 핵심 전처리 엔진 |

## II. OCR의 아키텍처 및 핵심 구성요소

### 가. OCR의 개념도 및 동작 원리

```mermaid
flowchart TB
    Input["비정형 이미지 데이터<br/>(스캔 문서, 영수증, 신분증)"]

    subgraph OCR_Pipeline["AI 기반 지능형 OCR 파이프라인"]
        direction TB
        
        subgraph Pre["1. 영상 전처리 (Preprocessing)"]
            P1["이진화 (Binarization)"]
            P2["기울기 보정 (Skew Correction)"]
            P3["노이즈 제거 (Denoising)"]
            P1 ~~~ P2 ~~~ P3
        end

        subgraph Detect["2. 텍스트 탐지 (Text Detection)"]
            D1["CRAFT, EAST 모델 적용"]
            D2["단어/문장 단위 Bounding Box 추출"]
            D1 --> D2
        end

        subgraph Recog["3. 텍스트 인식 (Text Recognition)"]
            R1["CRNN (CNN + RNN)"]
            R2["Vision Transformer (TrOCR)"]
            R3["이미지 패치 기반 시계열 문자 매핑"]
            R1 ~~~ R2 --> R3
        end

        subgraph Post["4. 후처리 및 구조화 (Post-processing)"]
            O1["NLP/LLM 기반 문맥 오탈자 교정"]
            O2["Layout Analysis (단락, 표 분리)"]
            O3["KIE (Key-Value 정보 추출)"]
            O1 ~~~ O2 ~~~ O3
        end
        
        Pre --> Detect
        Detect --> Recog
        Recog --> Post
    end

    Output["정형화된 디지털 텍스트<br/>(JSON, XML, DB 저장)"]

    Input --> OCR_Pipeline
    OCR_Pipeline --> Output

```

* 이미지 입력 후 전처리를 거쳐 텍스트 영역을 찾고(Detection), 해당 영역의 글자를 해독(Recognition)한 뒤, NLP 모델을 통해 맥락 기반 정제를 수행하는 4단계 파이프라인 구조

### 나. OCR의 핵심 기술 요소

| 구분 | 핵심 기술 | 세부 설명 |
| --- | --- | --- |
| **영상 전처리** | Binarization (이진화) | 이미지의 픽셀 값을 0(흑)과 1(백)로 변환하여 글자와 배경의 대비를 극대화 |
| **영상 전처리** | Skew Correction | Hough 변환 등을 활용하여 틀어진 문서 이미지의 수평/수직 정렬 수행 |
| **문자 탐지** | CRAFT / EAST | 딥러닝 기반으로 문자의 중심점과 영역을 유연한 형태의 Bounding Box로 탐지 |
| **문자 인식** | CRNN [[알고리즘]] | CNN(특징 추출)과 RNN(시계열 패턴 인식)을 결합하여 가변 길이 문자열 인식 |
| **문자 인식** | TrOCR / ViT | Vision Transformer를 활용해 이미지 패치 간의 Attention 메커니즘으로 인식 고도화 |
| **구조 분석** | Layout Analysis | 문서 내 텍스트, 표(Table), 그림, 다단 구조 등을 논리적인 블록으로 분할 인식 |
| **의미 추출** | KIE (Key Info. Ext.) | 영수증, 신분증 등에서 이름, 금액 등 필요 항목(Key-Value Pair)을 자동 추출 |
| **후처리 보정** | LLM 기반 정제 | 단순 사전(Dictionary) 매칭을 넘어 앞뒤 문맥(Context)을 파악하여 오탈자 자동 교정 |

## III. OCR 기술의 발전 양상 (Rule-based vs AI-based) 및 향후 전망

### 가. 전통적 OCR과 AI 기반 지능형 OCR 비교

| 비교 항목 | 전통적 OCR (Rule-based) | AI 기반 지능형 OCR (Document AI) |
| --- | --- | --- |
| **핵심 기술** | 패턴 매칭, 템플릿 매칭, 외곽선 추적 | Deep Learning (CNN, RNN, Transformer) |
| **인식 대상** | 폰트가 명확한 정형 문서, 고품질 스캔본 | 비정형 문서, 악필 필기체, 노이즈/훼손 이미지 |
| **구조 이해** | 텍스트의 단순 평면적(Flat) 추출 | 문서 레이아웃 구조 인식 및 Key-Value 매핑 |
| **후처리 방식** | 정적 사전(Dictionary) 기반 단순 교정 | NLP, LLM 활용 맥락(Context) 기반 추론 보정 |
| **주요 엔진** | Tesseract (초기 버전), ABBYY FineReader | Naver CLOVA OCR, Google Document AI |

### 나. 최근 동향 및 향후 전망
- **End-to-End 멀티모달 모델 통합**: 문자 탐지와 인식을 별개 모듈로 나누지 않고 Vision-Language 대형 모델(VLM)이 이미지 전체를 즉각 구조화된 텍스트/마크다운으로 일괄 변환하는 엔드투엔드 체계로 발전
- **엔터프라이즈 RAG 전처리 파이프라인 결합**: 기업의 방대한 비정형 스캔 문서, 설계 도면, 법률 계약서를 고품질 텍스트 및 벡터 임베딩 데이터로 변환하는 RAG 지식베이스 구축의 핵심 필수 도구로 안착
- **온디바이스 엣지 OCR 보안 강화**: 신분증, 결제 카드 등 민감 개인정보 유출을 방지하기 위해 스마트폰 및 IoT 단말 내부의 경량 NPU를 활용하는 온디바이스 로컬 OCR 수요 가속화
