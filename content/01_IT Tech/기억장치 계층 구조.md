# 기억장치 계층 구조 (Memory Hierarchy)

---

## I. 빠르고 작은 것부터 느리고 큰 것까지, 기억장치 계층 구조의 개요

### 가. 정의

- 속도·용량·비용이 다른 기억장치를 **계층으로 쌓아, 자주 쓰는 데이터는 빠른 상위 계층에 두고 전체 비용은 하위 계층 수준으로 낮추는** 구조

### 나. 특징 및 필요성

| 구분 | 내용 |
| --- | --- |
| 메모리 장벽 (Memory Wall) | [[CPU]] 속도 향상을 메모리 지연 개선이 따라가지 못해 생긴 격차 완화 |
| 계층 특성 | 위로 갈수록 빠르고 비싸고 작음, 아래로 갈수록 느리고 싸고 큼 |
| 동작 근거 | 참조 [[지역성]] 덕분에 작은 상위 계층으로도 높은 적중률 |
| 포함 관계 | 상위 계층 데이터는 보통 하위 계층에도 사본 존재 |

---

### 나. 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| CPU 내부 | 레지스터 | 연산 중인 값 보관, 플립플롭 기반 레지스터 파일 (1 사이클 이내) |
| | L1·L2·L3 캐시 | SRAM, 코어 전용(L1·L2)과 공유(L3), 수 ns~수십 ns |
| 주기억장치 | DRAM | 실행 중인 프로그램·데이터, DDR5 등 (예: 약 100ns) |
| | [[HBM]] | DRAM 다이를 TSV로 적층해 대역폭을 높인 메모리, AI 가속기에 사용 |
| 확장 계층 | [[CXL]] 메모리 | PCIe 물리 계층 위 CXL.mem으로 연결한 메모리, DRAM보다 느리고 SSD보다 빠른 계층 |
| 보조기억장치 | NVMe SSD | 비휘발성 저장 (예: 수십 µs), 가상 메모리 스왑 영역 |
| | HDD·테이프 | 대용량 저비용 (ms 단위), 백업·아카이브 |
| 원리 | 지역성 | 시간적·공간적 지역성 |
| 지표 | 평균 접근 시간 | 적중률 × 상위 접근 시간 + 미스율 × 미스 처리 시간 |

## III. 비교 및 동향

### 가. 계층별 비교

| 비교 항목 | 레지스터·캐시 | 주기억장치 | 보조기억장치 |
| --- | --- | --- | --- |
| 소자 | 플립플롭, SRAM | DRAM | NAND 플래시, 자기 디스크 |
| 휘발성 | 휘발 | 휘발 | 비휘발 |
| 관리 주체 | 하드웨어 (컴파일러가 레지스터 할당) | OS ([[가상 메모리]]) | OS (파일시스템, 스왑) |
| 전송 단위 | 워드, 캐시 라인 (예: 64B) | 페이지 (예: 4KB) | 블록 |

### 나. 동향

- **메모리 중심 컴퓨팅**: [[PIM]]·PNM으로 메모리 안이나 근처에서 연산해 데이터 이동 비용 감소
- **CXL 계층화 메모리**: DRAM과 CXL 메모리 사이에 Hot·Cold 페이지를 OS가 옮기는 Tiering (Linux NUMA 메모리 티어링)
- **이기종 메모리**: [[GPU]]·NPU가 HBM을 쓰면서 CPU 메모리와 통합 주소 공간을 공유하는 구조 확대 (예: NVIDIA Grace Hopper)
