# 기억장치 계층 구조 (Memory Hierarchy)

---

## I. 폰 노이만 병목현상 극복을 위한 아키텍처, 기억장치 계층 구조의 개요

### 가. 기억장치 계층 구조(Memory Hierarchy)의 정의

- 용량, 접근 속도, 비용이 서로 다른 다양한 기억장치를 성능에 따라 계층화하여, 전체 시스템의 메모리 성능을 [[CPU]] 속도에 맞추고 구축 비용을 최적화하는 하드웨어 아키텍처임.
### 나. 등장배경 및 주요 특징

- **등장배경:** 무어의 법칙에 따른 CPU 연산 속도의 기하급수적 발전 대비, 메모리 접근 속도 향상의 지체로 인한 심각한 성능 병목(Memory Wall) 현상 발생.
- **주요특징:** 참조 [[지역성]](Locality)의 원리 활용, 상위 계층일수록 고속/고가/저용량의 특성을 가지며, 하위 계층일수록 저속/저가/대용량의 특성을 가짐.

- **동작원리:** CPU가 데이터를 요청하면 최상위 계층(Cache)부터 순차적으로 탐색하며, 적중(Hit) 시 즉시 데이터를 반환하고, 실패(Miss) 시 하위 계층으로 접근하여 데이터를 상위로 복사(블록 단위)한 후 CPU에 전달함.
### 나. 기억장치 계층의 핵심 구성 및 최신 기술 요소

| **분류** | **요소기술(키워드)** | **세부 설명 및 최신 동향** |
| --- | --- | --- |
| **CPU 내부** | **Registers** | CPU 내부에 위치하며 연산에 필요한 데이터와 명령어를 저장하는 최고속 기억장치 (SRAM) |
|  | **L1, L2, L3 Cache** | CPU와 메인 메모리 간의 속도 차이를 완화하기 위해 자주 사용하는 데이터를 임시 저장 |
| **주기억장치** | **DRAM (Main Memory)** | 현재 실행 중인 프로그램과 데이터를 저장. 최근 DDR5로 대역폭 및 용량 확장 |
|  | **[[HBM]] (High Bandwidth)** | 3D TSV(실리콘 관통 전극) 기술로 여러 개의 DRAM을 수직 적층하여 대역폭을 극대화한 초고속 메모리 (AI 가속기 필수 요소) |
| **확장 계층** | **[[CXL]] Memory** | PCIe 5.0/6.0 기반으로 CPU-메모리-가속기 간 캐시 일관성을 유지하며 메모리를 풀링(Pooling)하고 확장하는 차세대 인터커넥트 |
| **보조기억장치** | **NVMe SSD** | 비휘발성 플래시 메모리 기반으로 OS, 대용량 파일 등을 영구 저장하는 스토리지 |
| **기반 원리** | **Locality (지역성)** | 시간적(최근 접근 데이터 재참조), 공간적(접근 데이터 주변 재참조) 데이터 접근 특성 |

## III. 전통적 계층 구조의 한계와 초거대 AI 시대의 최신 동향

### 가. Memory Wall 한계 극복을 위한 차세대 메모리 기술 동향 (2025~2026 기준)

- **메모리 중심 컴퓨팅([[PIM]]/PNM):** 데이터를 CPU로 불러와 연산하는 기존 계층 구조의 데이터 이동 지연(Latency)과 전력 소모를 줄이기 위해, 메모리 내부(PIM: Processing-In-Memory) 또는 근처(PNM: Processing-Near-Memory)에 연산 유닛을 통합하여 병목현상을 근본적으로 해소.
- **티어드 메모리(Tiered Memory) 아키텍처:** CXL(Compute Express Link)의 도입으로 'DRAM - CXL 확장 메모리 - SSD'로 이어지는 새로운 계층이 형성됨. 클라우드 및 하이퍼스케일 데이터센터에서 사용 빈도(Hot/Cold Data)에 따라 동적으로 메모리 풀을 할당하여 TCO(총소유비용)를 획기적으로 절감함.
- **이기종 메모리 통합 시스템:** CPU 중심의 단일 계층에서 벗어나, CPU, [[GPU]], DPU 등이 각자의 로컬 메모리(HBM, GDDR)를 가지면서 동시에 거대한 공유 메모리 풀에 접근하는 3차원적 네트워크 메모리 토폴로지로 진화 중임.
