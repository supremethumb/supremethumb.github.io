# OLAP (Online Analytical Processing)

---

## I. 다차원 대화형 분석, OLAP의 개요

### 가. 정의

- 사용자가 **다차원 데이터를 여러 관점에서 대화식으로 조회·분석해 의사결정에 활용하는 분석 처리 기술** (E. F. Codd, 1993)

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 다차원 | 차원(시간·지역·상품)과 측정값(매출)으로 큐브 구성 |
| 대화형 | 사용자가 직접 Drill-down·Pivot 수행 |
| 이력 데이터 | DW·데이터 마트의 주제 중심 이력 데이터 활용 |
| 읽기 중심 | 대량 집계 질의 위주, 갱신은 배치 적재 |

---

## II. 아키텍처 및 구성요소

### 가. OLAP 구조

```mermaid
flowchart LR
    S[("OLTP·외부 소스")] --> E["ETL"] --> DW[("DW·데이터 마트<br/>Star·Snowflake 스키마")]
    DW --> C["OLAP 엔진<br/>(큐브)"]
    C --> B["BI·리포트·Ad-hoc 질의"]
```

- 원천 데이터를 ETL로 DW에 적재하고, OLAP 엔진이 큐브 연산으로 다차원 분석을 제공

### 나. 유형과 연산

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 저장 유형 | ROLAP | 관계형 DB(스타 스키마)에 저장, 대용량에 유리, 질의가 느릴 수 있음 |
| | MOLAP | 다차원 배열에 사전 집계 저장, 응답 빠름, 용량·적재 부담 |
| | HOLAP | 요약은 MOLAP, 상세는 ROLAP |
| 분석 연산 | Roll-up | 상위 계층으로 요약 (일 → 월) 또는 차원 축소 |
| | Drill-down | 하위 계층 상세로 이동 (월 → 일) |
| | Slice | 한 차원을 특정 값으로 고정해 부분 큐브 추출 (예: 2026년) |
| | Dice | 두 개 이상 차원에 조건을 걸어 하위 큐브 추출 |
| | Pivot | 행·열 축을 바꿔 관점 전환 |
| | Drill-across·through | 다른 팩트로 이동, 원천 상세 데이터 조회 |

## III. 비교 및 동향

### 가. OLAP vs OLTP

| 비교 항목 | OLAP | [[OLTP]] |
| --- | --- | --- |
| 목적 | 의사결정 지원, 분석 | 일상 업무 [[트랜잭션]] 처리 |
| 데이터 | 이력·요약 데이터 | 현재·상세 데이터 |
| 접근 | 복잡한 집계, 주로 읽기 | 단순 질의, 빈번한 읽기·쓰기 |
| 설계 | 반정규화, Star·Snowflake 스키마 | 정규화 |
| 성능 지표 | 질의 응답 시간 | TPS, 응답 시간 (ms) |

### 나. 동향

- **HTAP**: 하나의 엔진에서 OLTP와 OLAP을 함께 처리 (TiDB, SingleStore, Oracle In-Memory)
- **클라우드 DW**: MPP·스토리지–컴퓨팅 분리 구조의 Snowflake, BigQuery, Redshift
- **실시간 OLAP**: ClickHouse, Apache Druid, Apache Pinot으로 스트리밍 데이터를 초 단위 집계
