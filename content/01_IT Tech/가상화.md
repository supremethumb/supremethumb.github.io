# 가상화 (Virtualization)

---

## I. 물리 자원의 논리적 추상화, 가상화의 개요

### 가. 정의

- [[CPU]]·메모리·스토리지·네트워크 등 물리 자원을 [[추상화]]하여 **논리적으로 분할(Partitioning)하거나 통합(Aggregation)** 하고, 하나의 물리 서버에서 여러 독립 환경(Guest OS, 애플리케이션)을 실행하는 기술

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 공유 (Sharing) | 하나의 물리 자원을 여러 사용자에게 분할 제공 |
| 단일화 (Aggregation) | 여러 물리 자원을 하나의 논리 자원으로 통합 |
| 에뮬레이션 (Emulation) | 물리 장치와 동일한 기능을 소프트웨어로 제공 |
| 절연 (Insulation) | 자원 교체·장애가 상위 서비스에 영향을 주지 않도록 분리 |
| 도입 효과 | 서버 이용률 향상, 통합(Consolidation)으로 TCO 절감, 클라우드 인프라의 기반 |

- 전통적 구조는 [[Hypervisor (VMM)\|하이퍼바이저]] 위에 Guest OS별 VM을 올리고, 최근에는 쿠버네티스 위에서 컨테이너와 VM(KubeVirt)을 함께 운영

### 나. 대상 자원별 기술

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 서버 | 전가상화 / 반가상화 | 하드웨어 지원(Intel VT-x, AMD-V)으로 Guest OS 무수정 실행 / Guest OS 수정 후 Hypercall 사용 (Xen) |
| | Live Migration | 실행 중 VM을 다른 호스트로 무중단 이동 |
| OS | [[컨테이너]] | cgroups(자원 제한)·namespaces(격리) 기반 경량 가상화 ([[도커\|Docker]]) |
| 네트워크 | [[SDN(Software Defined Network)\|SDN]] / [[NFV]] | 제어·전달 평면 분리, 스위치·방화벽 기능의 SW화 |
| 스토리지 | SDS | 이기종 저장장치를 논리 풀로 통합 관리 (예: vSAN, Ceph) |
| 데스크톱 | VDI | 중앙 서버의 가상 데스크톱에 원격 접속 |
| 가속기 | [[GPU]] 가상화 (vGPU, MIG) | 물리 GPU를 분할하여 여러 VM·컨테이너에 할당 |

## III. 비교 및 동향

### 가. 하이퍼바이저 유형

| 비교 항목 | Type 1 (Bare-metal) | Type 2 (Hosted) |
| --- | --- | --- |
| 구조 | 하드웨어 위에 하이퍼바이저가 직접 설치 | Host OS 위에 애플리케이션 형태로 설치 |
| 특징 | 오버헤드가 적고 안정적, 서버 환경에 적합 | 설치가 쉬우나 Host OS 경유로 성능 손실 |
| 예시 | VMware ESXi, Hyper-V, KVM, Xen | VMware Workstation, VirtualBox |

### 나. 가상머신 vs 컨테이너

| 비교 항목 | 가상머신 (VM) | 컨테이너 |
| --- | --- | --- |
| 가상화 수준 | 하드웨어 수준 (Hypervisor) | OS 수준 (Container Engine) |
| Guest OS | 있음 (무겁고 부팅 느림) | 없음 (Host 커널 공유) |
| 격리성 | 하드웨어 수준 격리 (보안 우수) | [[프로세스]] 수준 격리 |
| 성능 | 오버헤드 큼 | 네이티브에 근접 |
| 예시 | VMware, Xen, KVM | Docker, LXC, [[쿠버네티스\|Kubernetes]] |

### 다. 동향

- **KubeVirt**: Broadcom의 VMware 인수(2023) 후 라이선스 정책 변화로, 쿠버네티스에서 VM을 Pod처럼 관리하는 방식 확산 (OpenShift Virtualization)
- **GPU 가상화**: [[초거대 언어 모델\|LLM]] 수요로 MIG·vGPU 기반 GPU 분할 활용 증가
- **MicroVM · Wasm**: Firecracker, Kata Containers 등 빠르게 기동되며 하드웨어 수준 격리를 제공하는 경량 VM이 서버리스 기반으로 사용, [[EDGE\|엣지]]에서는 WebAssembly 런타임 도입
