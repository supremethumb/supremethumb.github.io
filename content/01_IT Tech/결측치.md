# 결측치
---
## I. 결측치와 이상치의 개요

정의: * 결측치(Missing Values): 데이터 수집 과정의 오류나 누락으로 인해 관측되어야 할 값이 비어있는 상태(Null, NaN 등)를 의미합니다.
- [[이상치]](Outliers): 전체 데이터의 일반적인 분포 형태에서 유달리 멀리 떨어져 있는 극단적인(Extreme) 값을 의미합니다.
두 요소 모두 데이터의 품질을 훼손하여 통계 분석을 왜곡시키고 머신러닝 모델의 성능(정확도)을 급격히 저하시키는 "GIGO(Garbage In, Garbage Out)"의 주원인이므로, 본격적인 분석 전 탐색적 데이터 분석([[EDA]]) 및 정제(Cleansing) 단계에서 반드시 식별하고 적절히 처리해야 합니다.

## II. 핵심 식별 및 처리 기법

| 구분 | 주요 기법 및 개념 | 세부 설명 및 특징 |
| --- | --- | --- |
| 결측치 메커니즘 | MCAR / MAR / MNAR | MCAR (완전 무작위 결측): 누락된 변수나 다른 변수와 아무런 상관없이 무작위로 발생 (예: 시스템 오류로 무작위 누락).<br>MAR (무작위 결측): 누락 확률이 다른 관측된 변수에 의존 (예: '나이' 변수는 '성별'에 따라 응답률이 다름).<br>MNAR (비무작위 결측): 누락 확률이 누락된 변수 자체의 값에 의존 (예: 소득이 매우 높은 사람이 소득 응답을 회피). |
| 결측치 처리 | 제거 (Deletion) | - Listwise Deletion: 결측치가 하나라도 포함된 행(Record) 전체를 삭제. 빠르고 간단하나, 데이터 손실이 큼.<br>- Pairwise Deletion: 분석에 필요한 두 변수 쌍에 모두 값이 있는 경우만 분석에 활용. |
|  | 대치 (Imputation) | - 단순 대치: 연속형 변수는 평균(Mean)이나 중앙값(Median)으로, 범주형 변수는 최빈값(Mode)으로 일괄 대체.<br>- 예측/다중 대치: KNN, [[회귀분석]] 등을 이용해 나머지 변수들로 결측값을 예측하여 채움. MICE(Multiple Imputation by Chained Equations) 알고리즘이 대표적. |
| 이상치 탐지 | 통계적 기법 | - Z-Score (표준점수): 데이터가 정규분포를 따른다고 가정할 때, 평균으로부터 ±3 표준편차 범위를 벗어나는 값을 이상치로 판별.<br>- IQR (사분위수 범위): Box Plot 기법. Q1(1사분위) - 1.5 * IQR 보다 작거나, Q3(3사분위) + 1.5 * IQR 보다 큰 값을 이상치로 규정 (정규분포를 따르지 않아도 사용 가능). |
|  | 머신러닝 기법 | - Isolation Forest: [[의사결정나무]] 기반으로, 적은 횟수의 공간 분할만으로 고립되는 관측치를 이상치로 판별.<br>- [[DBSCAN(밀도 기반 클러스터링)|DBSCAN]] / LOF: 데이터 밀도 기반 클러스터링으로 주변 데이터와 뚝 떨어져 밀도가 낮은 데이터를 탐지. |
| 이상치 처리 | 제거 및 변환 | - 제거: 명백한 입력 오류(에러)인 경우 삭제.<br>- 변환 (Transformation): 데이터 단위가 너무 클 경우 자연로그(Log)를 취해 스케일을 줄임.<br>- 윈저라이징 (Winsorization): 극단값을 백분위 기준 상/하한값(예: 상위 99%, 하위 1%)으로 강제 대체(대치)하여 극단값의 영향을 줄임. |

## III. 실무적 적용 전략 및 발전 방향

비즈니스 도메인 지식의 중요성:

데이터를 분석할 때, 이상치가 단순한 '입력 오류(Error)'인지 아니면 실제로 발생한 '의미 있는 블랙스완(예: 신용카드 부정사용, 희귀 질병, 블랙프라이데이 폭증 데이터)'인지 판단하는 것은 알고리즘이 아닌 업무 전문가(Domain Expert)의 몫입니다. 이상치를 무조건 제거하면 사기 탐지(Fraud Detection) 모델의 경우 아예 학습의 목적(Target) 자체가 사라지는 오류를 범할 수 있습니다.

기술적 발전 방향 (자동화 및 [[딥러닝]]):

과거에는 통계적 기반의 수동 대치가 주를 이루었으나, 최근 DataOps 및 [[MLOps]] 파이프라인에서는 데이터 유입 시 결측치와 이상치를 실시간으로 탐지하는 오토 클렌징(Auto-Cleansing) 도구가 확산되고 있습니다. 특히 시계열 데이터나 이미지/텍스트와 같은 비정형 데이터에서는 오토인코더(Autoencoder) 기반의 딥러닝 이상 탐지([[Anomaly(이상현상)|Anomaly]] Detection) 기법과 생성적 적대 신경망([[GAN (Generative Adversarial Network)|GAN]])을 활용한 결측치 합성(Synthetic Data Imputation) 기술이 활발히 연구 및 적용되고 있습니다.

# 결측치(Missing Value), 이상치(Outlier)

---

## I. 데이터 품질 및 분석 모델 신뢰성 저하 요인, 결측치와 이상치의 개요

### 가. 결측치와 이상치의 정의

- 결측치(Missing Value): 데이터 수집 오류, 누락 등으로 인해 관측되어야 할 값이 비어 있는 상태 (NaN, Null).
- 이상치(Outlier): 정상적인 데이터 분포 범위에서 크게 벗어나 평균과 표준편차에 영향을 주는 관측값.
### 나. 처리의 필요성

- GIGO(Garbage In Garbage Out) 방지, 분석 모델의 정확도(Accuracy) 및 [[신뢰성]] 확보.

### 나. 결측치(Missing Value)의 유형 및 처리 기법 (소스 1075 기반)

| 구분 | 유형/기법 | 설명 및 핵심 키워드 |
| --- | --- | --- |
| 발생 유형 | MCAR | - 완전 무작위 결측 (변수 간 상관관계 없음). |
|  | MAR | - 무작위 결측 (다른 변수에 의해 결측 여부 설명 가능). |
|  | MNAR | - 비무작위 결측 (결측된 값 자체가 원인이 됨). |
| 처리 기법 | 삭제(Deletion) | - 행 삭제(Listwise), 열 삭제(Pairwise) (데이터 손실 위험). |
|  | 대체(Imputation) | - 단순 대치: 평균(Mean), 중앙값(Median), 최빈값(Mode).<br>- 고급 대치: 회귀(Regression), MICE, K-NN, Hot-deck. |

### 다. 이상치(Outlier)의 탐지 및 처리 기법 (소스 165 기반)

| 구분 | 기법 | 설명 및 핵심 키워드 |
| --- | --- | --- |
| 탐지 기법 | 통계적 기법 | - Z-Score: 표준화 점수 ±3_σ_ 벗어나는 값.<br>- IQR (Box Plot): _Q_3+1.5∗_I__QR_ 초과, _Q_1−1.5∗_I__QR_ 미만. |
|  | ML 기법 | - LoF (Local Outlier Factor): 밀도 기반 국소적 이상치 탐지.<br>- iForest (Isolation Forest): 의사결정나무 기반 격리 탐지. |
| 처리 기법 | 변환/조정 | - Log 변환: 데이터 스케일 줄임.<br>- Binning: 구간화하여 범주형으로 변환.<br>- Caping/Flooring: 상한/하한값으로 대체. |

## III. 결측치와 이상치의 비교 및 고려사항

### 가. 비교표

| 비교 항목 | 결측치 (Missing Value) | 이상치 (Outlier) |
| --- | --- | --- |
| 발생 원인 | 기록 누락, 시스템 오류, 무응답 | 측정 오류, 실험 오류, 특이 현상 |
| 주요 영향 | 분석 불가능, [[편향]](Bias) 발생 | 평균/분산 왜곡, 모델 과적합 |
| 핵심 조치 | 합리적 대체 (Imputation) | 탐지 후 제거/조정 (Detection) |

### 나. 고려사항

- 도메인 지식: 무조건적인 제거/대체보다는 해당 도메인의 특성을 고려하여 의미 있는 이상치(Fraud Detection 등)는 보존해야 함.
- 전처리 자동화: 데이터 품질 관리(DQM) [[프로세스]] 내에서 자동화된 프로파일링 도구 활용 필요.
