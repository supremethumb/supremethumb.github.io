# 결측치 (Missing Value)와 이상치 (Outlier)

---

## I. 데이터 품질 저하의 주요 원인, 결측치와 이상치의 개요

### 가. 정의

- **결측치(Missing Value)**: 수집 오류·누락·무응답 등으로 관측되어야 할 값이 비어 있는 상태 (Null, NaN)
- **[[이상치]](Outlier)**: 전체 분포에서 크게 벗어나 평균·분산을 왜곡하는 극단적 관측값

### 나. 처리의 필요성

| 구분 | 내용 |
| --- | --- |
| 품질 | 통계 분석 왜곡·모델 성능 저하를 부르는 GIGO(Garbage In, Garbage Out)의 주원인 |
| 시점 | 분석 전 [[EDA]]·[[데이터 클렌징]] 단계에서 식별·처리 |
| 판단 | 결측은 발생 메커니즘, 이상치는 오류인지 실제 신호인지에 따라 처리 방법 결정 |

---

### 나. 결측치 발생 메커니즘

| 유형 | 의미 | 예시 |
| --- | --- | --- |
| MCAR (완전 무작위 결측) | 어떤 변수와도 무관하게 무작위 발생 | 시스템 오류로 무작위 누락 |
| MAR (무작위 결측) | 결측 여부가 **다른 관측 변수**로 설명됨 | 성별에 따라 나이 응답률이 다름 |
| MNAR (비무작위 결측) | 결측 여부가 **결측된 값 자체**에 의존 | 고소득자가 소득 응답 회피 |

### 다. 결측치 처리 기법

| 구분 | 기법 | 설명 |
| --- | --- | --- |
| 삭제 | Listwise Deletion | 결측이 하나라도 있는 행 전체 삭제, 간단하나 데이터 손실 큼 |
| | Pairwise Deletion | 분석에 쓰는 변수 쌍에 값이 있는 경우만 활용 |
| 단순 대치 | 평균·중앙값·최빈값 | 연속형은 평균·중앙값, 범주형은 최빈값으로 대체 |
| | Hot-deck | 유사한 다른 레코드의 값으로 대체 |
| 고급 대치 | 회귀·KNN 대치 | 나머지 변수로 결측값을 예측 ([[회귀분석]], [[KNN 알고리즘\|KNN]]) |
| | 다중 대치 (MICE) | 여러 번 대치한 결과를 결합해 불확실성까지 반영 |

### 라. 이상치 탐지 및 처리 기법

| 구분 | 기법 | 설명 |
| --- | --- | --- |
| 통계적 탐지 | Z-Score | 정규분포 가정 시 평균에서 ±3σ를 벗어나는 값 |
| | IQR (Box Plot) | $Q_1 - 1.5 \times IQR$ 미만 또는 $Q_3 + 1.5 \times IQR$ 초과 (분포 가정 불필요) |
| ML 탐지 | Isolation Forest | 적은 분할만으로 고립되는 관측치를 이상치로 판별 ([[의사결정나무]] 기반) |
| | LOF / [[DBSCAN(밀도 기반 클러스터링)\|DBSCAN]] | 주변보다 밀도가 낮은 데이터 탐지 |
| 처리 | 제거 | 명백한 입력 오류인 경우 삭제 |
| | 변환 | 로그 변환으로 스케일 축소, Binning으로 구간화 |
| | 윈저라이징 (Capping/Flooring) | 극단값을 상·하위 백분위 값(예: 1%, 99%)으로 대체 |

## III. 비교 및 실무 고려사항

### 가. 결측치 vs 이상치

| 비교 항목 | 결측치 | 이상치 |
| --- | --- | --- |
| 발생 원인 | 기록 누락, 시스템 오류, 무응답 | 측정·입력 오류, 실제 특이 현상 |
| 주요 영향 | 분석 불가, 표본 [[편향]] | 평균·분산 왜곡, 모델 과적합 |
| 핵심 조치 | 메커니즘에 맞는 대치 | 탐지 후 원인 판단, 제거·조정 |

### 나. 실무 고려사항 및 동향

- **도메인 지식**: 이상치가 단순 오류인지, 카드 부정사용·희귀 질병처럼 **의미 있는 신호**인지는 업무 전문가가 판단해야 하며, 사기 탐지 모델에서 무조건 제거하면 학습 대상 자체가 사라짐 ([[이상 감지]])
- **자동화**: DataOps·[[MLOps]] 파이프라인에서 유입 데이터의 결측·이상을 실시간 탐지하는 [[데이터 프로파일링]]·자동 클렌징 도구 활용
- **딥러닝 기법**: 오토인코더 기반 이상 탐지, [[GAN (Generative Adversarial Network)\|GAN]] 기반 결측치 생성 대치 등이 시계열·비정형 데이터에 적용
