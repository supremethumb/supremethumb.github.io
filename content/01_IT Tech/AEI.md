# 인공감성지능 (AEI, Artificial Emotional Intelligence)

---

## I. 인간 중심 교감을 위한, 인공감성지능(AEI)의 개요

### 가. 정의

- 인공지능이 인간의 표정, 음성 톤, 텍스트, 생체 신호 등을 통해 감정을 인식하고 심리 상태를 해석하여, 인간과 정서적 유대를 형성할 수 있도록 적절한 감정 반응과 공감형 응답을 생성하는 지능형 기술

### 나. 주요 특징

| 구분 | 주요 내용 |
| --- | --- |
| 멀티모달 감정 인식 | 컴퓨터 비전(표정), 오디오 분석(음성 톤), 생체 센서([[EDA]], 심박수)를 융합한 정밀 감정 파악 |
| 심리학적 감정 모델 | 러셀(Russell)의 원형 모델, 플루칙(Plutchik) 감정 바퀴 등 수학적 감정 좌표계 기반 모델링 |
| 공감형 상호작용 | 단순 정보 전달을 넘어 정서적 지지, 억양 조절 음성 합성(TTS), 아바타 표정 동기화 구현 |
| 윤리적 책임성 | 감정 데이터 수집에 따른 사생활 침해 및 취약 사용자 대상 정서적 조작(Manipulation) 방지 필수 |

## II. AEI의 개념도 및 핵심 기술 요소

### 가. AEI의 동작 프로세스 및 아키텍처

```mermaid
flowchart TD
    subgraph "인공감성지능 (AEI) 처리 파이프라인"
        direction LR
        A["사용자 입력<br/>표정/음성/텍스트/생체신호"] --> B["멀티모달 감정 인식<br/>Multimodal Perception"]
        
        B --> C["감정 분석 및 모델링<br/>Emotion Analysis / Classification"]
        
        C --> D["공감형 응답 생성<br/>Empathic Response Generation"]
        
        D --> E["감성적 표현 출력<br/>음성 톤 조절 / 아바타 표정 / 텍스트 공감"]
    end


```

* 사용자의 다양한 비언어적·언어적 신호를 멀티모달 센서로 수집하고, 감정 분류 모델을 통해 내면의 감정 상태를 파악한 뒤, 맥락에 맞는 공감형 반응을 음성과 시각 정보로 출력함

### 나. AEI의 핵심 기술 요소

| 구분 | 요소기술(키워드) | 세부 설명 |
| --- | --- | --- |
| 인식 기술 | **시각적 감정 인식 (Vision)** | 컴퓨터 비전([[CNN]] 등)을 활용해 미세 표정(Micro-expression), 시선, 제스처 분석 |
| 인식 기술 | **음성 감정 인식 (Audio)** | 음성의 톤, 피치(Pitch), 발화 속도, 강세 등을 분석하여 분노, 기쁨, 슬픔 등 식별 |
| 인식 기술 | **생체 신호 인식 (Bio-signal)** | 심박변이도(HRV), 뇌파(EEG), 피부전도도([[EDA]]) 등을 통해 생리적 각성 상태 측정 |
| 분석 모델 | **감정 모델링 (Circumplex)** | 러셀(Russell)의 원형 모델이나 플루칙(Plutchik)의 감정 바퀴 등 심리학적 모델 적용 |
| 분석 모델 | **감성 분석 (Sentiment Analysis)** | 텍스트 및 대화 로그 기반으로 긍정/부정 및 세부 감정 극성 분류 |
| 표현 기술 | **음성 합성 감정 제어 (TTS)** | 기계적인 음성이 아닌 감정이 실린 억양, 호흡, 톤을 반영하는 음성 생성 기술 |
| 표현 기술 | **디지털 아바타 / 로봇** | 가상 인간(Digital Human)이나 소셜 로봇의 표정근 및 제스처 동기화 |
| 응용 기술 | **공감형 [[초거대 언어 모델\|LLM]] 대화 에이전트** | 거대언어모델(LLM)에 감성 페르소나를 부여하여 정서적 지지 대화 수행 |

## III. 전통적 인지 AI와 인공감성지능(AEI) 비교 및 최신 동향

### 가. 전통적 인지 AI와 인공감성지능(AEI) 비교

| 비교 항목 | 전통적 인지 AI (Cognitive AI) | 인공감성지능 (AEI, Emotional AI) |
| --- | --- | --- |
| **핵심 목표** | 논리적 문제 해결, 지식 검색, 정답 도출 | 인간의 감정 이해, 공감, 정서적 유대 형성 |
| **처리 데이터** | 텍스트, 수치, 정형 데이터 중심 | 표정, 음성 톤, 생체 신호 등 비정형 멀티모달 데이터 |
| **상호작용 방식** | 명령어 입력 및 기능적 결과 반환 | 자연스러운 대화, 분위기 파악 및 맞춤형 공감 반응 |
| **주요 활용 분야** | 검색 엔진, 데이터 분석, 자동화 시스템 | 정신 건강 상담, 소셜 로봇, 에듀테크, AI 컴패니언 |

### 나. AEI의 최신 트렌드 및 실무 활용 전략

- **멀티모달 LLM(MLLM) 기반 정서 지능 통합**: 텍스트 위주 분석에서 탈피하여 비전·음성·텍스트를 실시간 동시 처리하는 MLLM을 결합해 사용자의 미세 감정 변화를 포착하는 AI 컴패니언 서비스 확산
- **디지털 헬스케어 및 멘탈케어 상용화**: 고령자 독거노인 돌봄, 우울증 조기 스크리닝 및 심리 상담 분야에서 감정 상태 추적 기반의 맞춤형 멘탈 헬스케어 에이전트 도입 본격화
- **감정 데이터 프라이버시 및 윤리 규제 대응**: 생체 신호와 표정 영상 등 민감 개인정보 수집에 따른 EU AI Act의 고위험 감정 인식 규제 준수와 투명성(XAI) 확보 필수화
