# 랜섬웨어 (Ransomware)

---

## I. 데이터를 인질로 잡는 공격, 랜섬웨어의 개요

### 가. 정의

- 시스템에 침투해 **데이터를 암호화하거나 탈취한 뒤 복구·비공개를 조건으로 금전(주로 가상자산)을 요구**하는 악성코드와 그 공격 행위

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 서비스화 | [[RaaS(Ransomware as a Service)\|RaaS]] 생태계로 개발자와 유포자(제휴자) 분업 |
| 다중 협박 | 암호화 + 데이터 유출 공개 + [[DDOS\|DDoS]] + 고객·협력사 협박 |
| 표적형 | 기업망 장악 후 백업까지 무력화하는 수동 운영형 공격 |
| 탐지 회피 | 취약 드라이버 악용(BYOVD), 정상 도구 악용(LotL), 간헐적 암호화 |

---

## II. 공격 단계 및 기법

### 가. 공격 단계

```mermaid
flowchart LR
    A["초기 침투<br/>피싱 · VPN · RDP"] --> B["거점 확보<br/>C2 통신"]
    B --> C["권한 상승 · 방어 무력화<br/>BYOVD로 EDR 종료"]
    C --> D["내부 확산<br/>AD 장악 · LotL"]
    D --> E["데이터 유출<br/>Rclone 등"]
    E --> F["백업 삭제 · 암호화<br/>vssadmin · 간헐적 암호화"]
    F -.-> G["다중 협박"]
```

- 침투 후 보안 솔루션을 무력화하고 내부를 장악한 뒤, 데이터를 먼저 빼내고 백업을 지운 다음 암호화

### 나. 핵심 기법

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 초기 침투 | 피싱·원격 접속 악용 | 스피어 피싱, RDP 무차별 대입, VPN 장비 취약점 |
| 방어 무력화 | BYOVD | 서명된 취약 커널 드라이버를 로드해 [[EDR(Endpoint Detection and Response)\|EDR]] 종료 |
| 정상 도구 악용 | LotL | PowerShell·WMI·PsExec 등 내장 도구 사용 |
| 데이터 유출 | 동기화 도구 | Rclone·MEGA 등으로 대량 반출 |
| 복구 방해 | 섀도 복사본 삭제 | vssadmin·wbadmin으로 복원 지점 삭제 |
| 암호화 | 하이브리드 암호 | 파일은 대칭키(AES·ChaCha20), 키는 공격자 공개키로 보호 |
| | 간헐적 암호화 | 파일 일부만 암호화해 속도↑·탐지 회피 |
| 협박 | 다중 협박 | 유출 사이트 공개, 규제기관 신고 위협 |

---

## III. 비교 및 동향

### 가. 단계별 방어 체계

| 비교 항목 | 대응 | 설명 |
| --- | --- | --- |
| 예방 | 패치·MFA·노출 최소화 | VPN·RDP 취약점 패치, 피싱 저항 MFA |
| 확산 차단 | [[제로 트러스트 보안모델\|제로 트러스트]]·세그멘테이션 | 횡적 이동 차단, 특권 계정 관리 |
| 탐지 | [[EDR(Endpoint Detection and Response)\|EDR]]·[[XDR]] | 대량 파일 변경·유출 행위 탐지 |
| 드라이버 통제 | 취약 드라이버 차단 목록 | Microsoft 취약 드라이버 차단 목록, WDAC |
| 복구 | 불변 백업 | 3-2-1-1 백업(오프라인·불변 사본 1개 추가), 복구 훈련 |

### 나. 동향

- **암호화 없는 협박**: 데이터 유출만으로 협박하는 Data Extortion 증가
- **가상화 플랫폼 표적화**: ESXi 하이퍼바이저를 직접 암호화하는 변종 증가
- **국제 공조**: 국제 랜섬웨어 대응 이니셔티브(CRI), 몸값 지불 신고 의무화 논의
