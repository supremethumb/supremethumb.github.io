# 개방형 연결 데이터 (LOD, Linked Open Data)

---

## I. 데이터의 웹을 실현하는 기반, LOD의 개요

### 가. 정의

- 웹상의 개방 데이터를 **URI로 식별하고 RDF로 의미·관계를 표현하여 서로 링크**함으로써, 기계가 자동으로 이해·처리할 수 있게 만든 전 세계적 데이터 웹(Web of Data)
- 시맨틱 웹을 실현하는 응용 기술이며, 최근에는 생성형 AI가 참조하는 [[지식그래프]] 구축 규격으로 재조명

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 개방 (Open) | 라이선스를 명시하여 누구나 재사용 가능 |
| 연결 (Linked) | 외부 데이터의 URI를 링크하여 데이터 간 문맥 제공 |
| 기계 가독성 | 표준(RDF, OWL)으로 의미를 기술하여 자동 추론 가능 |

- 식별(URI) → 서술(RDF) → 지식화(Ontology) → 질의(SPARQL) 순으로 데이터가 정보·지식으로 발전하는 계층 구조

### 나. 핵심 기술 요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 식별 | URI / IRI | 자원의 고유 식별자 (IRI는 다국어 확장) |
| 직렬화 | RDF/[[XML]] · Turtle · [[JSON]]-LD | RDF 그래프를 기록·교환하는 형식 |
| 서술 | RDF | 주어–서술어–목적어 트리플(Triple)로 자원의 속성·관계 표현 |
| 지식 | 온톨로지 (OWL) | 개념 간 계층·속성·관계를 정의하여 추론 지원 |
| 질의 | SPARQL | RDF 그래프를 검색하는 W3C 표준 질의어 (SPARQL Endpoint로 공개) |
| 연결 | owl:sameAs | 서로 다른 데이터셋의 동일 대상을 연결 (예: DBpedia ↔ Wikidata) |

## III. LOD 발행 원칙, 개방 단계 및 동향

### 가. 팀 버너스리의 Linked Data 4대 원칙

| 원칙 | 내용 | 기술 |
| --- | --- | --- |
| 1. 식별 | 모든 사물·개념에 이름(URI) 부여 | URI |
| 2. 접근 | 누구나 조회할 수 있도록 HTTP URI 사용 | HTTP URI |
| 3. 표준 표현 | URI 조회 시 표준 형식의 유용한 정보 제공 | RDF, SPARQL |
| 4. 연결 | 다른 데이터의 URI 링크 포함 | 외부 URI 링크 |

### 나. 개방 데이터 5-Star 모델

| 등급 | 조건 | 예시 |
| --- | --- | --- |
| ★ | 개방 라이선스로 웹에 공개 (형식 무관) | PDF, 이미지 |
| ★★ | 기계가 읽을 수 있는 구조화 데이터 | XLS |
| ★★★ | 비독점 개방 포맷 | CSV, JSON |
| ★★★★ | URI·RDF로 사물을 식별 | RDF |
| ★★★★★ | 다른 데이터와 링크하여 문맥 제공 | LOD |

### 다. 활용 및 동향

- **[[GraphRAG (Graph Retrieval-Augmented Generation)\|GraphRAG]]**: 검증된 LOD·지식 그래프를 RAG 지식원으로 활용해 [[할루시네이션]] 억제
- **데이터 스페이스**: Gaia-X 등 산업 간 데이터 공유 플랫폼에서 상호운용 메타데이터 표준으로 채택
- **Solid 프로젝트**: 개인 데이터 저장소(Pod) 간 연동에 Linked Data를 사용하여 데이터 주권 강화
- **[[공공데이터]]**: 공공 데이터 포털·지식 그래프 연계로 데이터 사일로 해소
