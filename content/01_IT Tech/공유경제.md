# 공유경제 (Sharing Economy)

---

## I. 소유에서 이용으로, 공유경제의 개요

### 가. 정의

- 개인·기업이 가진 **유휴 자산(공간, 차량, 물건, 시간, 재능)을 플랫폼으로 연결해 빌려 쓰는** 협력적 소비(Collaborative Consumption) 기반 경제 모델 (L. Lessig 2008 용어 대중화, R. Botsman 2010 협력적 소비)

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 자원 효율 | 사용률 낮은 자산을 활용해 추가 생산 없이 가치 창출 |
| 플랫폼 매개 | 매칭·결제·평판을 플랫폼이 제공해 거래 비용 감소 |
| 신뢰 시스템 | 양방향 리뷰·본인 인증으로 낯선 사람 간 거래 위험 완화 |
| 쟁점 | 기존 업계와 갈등(택시·숙박), 플랫폼 노동자 지위, 안전·세금 규제 |

### 나. 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 주체 | 자원 제공자 / 수요자 | 개인 간(P2P) 또는 기업–개인(B2C) 간 유휴 자산 공급·이용 |
| 자산 | 유형 자산 | 숙박, 차량·킥보드, 공간(공유 오피스) |
| | 무형 자산 | 시간, 재능, 지식 (긱 경제로 확장) |
| 플랫폼 기술 | 매칭 [[알고리즘]] | 위치·선호·가용성 기반 수요–공급 연결 |
| | 신뢰·평판 시스템 | 양방향 리뷰, 별점, 본인 인증 |
| | 동적 가격 책정 | 수급 불균형·시간대에 따라 가격 조정 (예: 승차 공유 탄력 요금) |
| | 간편결제·에스크로 | [[FIDO]] 인증, 결제 토큰화, 거래 완료 후 정산 |

## III. 유사 모델 비교 및 동향

### 가. 공유경제 vs 구독경제 vs 긱 경제

| 구분 | 공유경제 | [[구독경제]] | 긱 경제 |
| --- | --- | --- | --- |
| 공유 대상 | 유휴 자산 | 기업 제공 상품·서비스 | 개인의 노동·시간 |
| 거래 구조 | P2P, 플랫폼 중개 | 기업–고객 정기 계약 | 플랫폼 중개 단기 계약 |
| 수익 모델 | 거래 수수료 | 정기 구독료 | 건별 수수료 |
| 대표 사례 | 에어비앤비, 카셰어링 | OTT, SaaS | 배달 대행, 프리랜서 플랫폼 |

### 나. 동향

- **긱 경제·플랫폼 노동 규제**: 유형 자산 공유에서 노동 중개로 확장되며 플랫폼 노동자 보호 논의 확대 (EU 플랫폼 노동 지침, 2024 채택)
- **기업형 공유로 전환**: 순수 P2P보다 기업이 자산을 보유·운영하는 B2C 모델(카셰어링, 공유 오피스) 비중 확대, 수익성 검증 과제
- **순환 경제 연계**: 제품을 판매 대신 서비스로 제공(Product-as-a-Service, [[서비타이제이션]])하거나 [[프로토콜 경제]]로 플랫폼 수익을 참여자에게 배분하는 모델 실험
