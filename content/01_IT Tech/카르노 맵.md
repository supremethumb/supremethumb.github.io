# 카르노 맵 (Karnaugh Map)

---

## I. 논리식을 그림으로 줄이는 도구, 카르노 맵의 개요

### 가. 정의

- 진리표를 **그레이 코드 순서의 2차원 격자로 배치해 인접한 1을 묶음으로써 불 대수식을 최소화**하는 도식적 간소화 기법 (M. Karnaugh, 1953)

### 나. 특징

| 구분 | 내용 |
| --- | --- |
| 목적 | 게이트·입력 수를 줄여 회로 비용·지연·전력 절감 |
| 인접성 | 이웃 칸은 1비트만 다르며, 맵의 양 끝도 인접 |
| 직관성 | 대수 정리 없이 패턴으로 간소화 |
| 한계 | 수작업은 4~5변수 정도까지 실용적 |

---

## II. 절차 및 구성요소

### 가. 간소화 절차

```mermaid
flowchart LR
    S1["진리표 작성"] --> S2["그레이 코드 격자에<br/>1·0·X 배치"]
    S2 --> S3["인접한 1을 2ⁿ개 단위로<br/>최대한 크게 묶기"]
    S3 --> S4["주항 · 필수 주항 선택"]
    S4 --> S5["최소 SOP / POS 도출"]
```

- 2ⁿ개 칸을 묶으면 n개 변수가 소거됨 (예: 4칸 묶음 → 변수 2개 소거)

### 나. 구성요소

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| 배열 | 그레이 코드 | 00, 01, 11, 10 순서로 이웃 칸이 1비트만 차이 |
| 묶음 | 2ⁿ 그룹 | 1·2·4·8·16칸 직사각형 묶음, 겹침 허용 |
| | 무관항 (Don't Care, X) | 결과가 상관없는 입력, 묶음을 키우는 데 1로 활용 가능 |
| 항 | 주항 (PI, Prime Implicant) | 더 크게 묶을 수 없는 최대 묶음 |
| | 필수 주항 (EPI) | 다른 주항으로 덮이지 않는 1을 포함하는 주항, 반드시 선택 |
| 표현 | SOP (곱의 합) | 1을 묶어 최소항 기반 표현, AND-OR (NAND-NAND) 구현 |
| | POS (합의 곱) | 0을 묶어 최대항 기반 표현, OR-AND (NOR-NOR) 구현 |
| 대안 | Quine-McCluskey | 표 기반 정확한 최소화, 변수 많을 때 계산 폭증 |
| | Espresso | 대규모 논리용 휴리스틱 최소화 (최적해 보장 아님) |

---

## III. 비교 및 동향

### 가. 간소화 방법 비교

| 비교 항목 | 카르노 맵 | Quine-McCluskey | Espresso / EDA 논리 합성 |
| --- | --- | --- | --- |
| 방식 | 도식, 수작업 | 표 기반 체계적 알고리즘 | 휴리스틱 알고리즘 |
| 규모 | 4~5변수 | 수~십여 변수 | 대규모 다중 출력 |
| 최적성 | 최소해 가능 (숙련 필요) | 정확한 최소해 | 근사 최적 |
| 용도 | 교육, 소규모 설계 | 알고리즘 학습, 중규모 | FPGA·ASIC 실무 설계 |

### 나. 동향

- **실무는 자동 합성**: 실제 설계는 HDL로 기술하고 EDA 도구가 다단 논리 최적화·기술 매핑 수행, K-Map은 원리 학습용
- **AI 활용 EDA**: 강화학습 기반 배치·합성 최적화 등 [[인공지능]]을 적용한 설계 자동화 확대
