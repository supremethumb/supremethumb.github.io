### 나. 세부 기술 사항

| **구분** | **유형 / 기술**  | **상세 설명**               |
| ------ | ------------ | ----------------------- |
| **유형** | **EASM**     | 인터넷 노출 자산, IP, Domain 등 |
|        | **CAASM**    | 모든 사이버 자산 관리            |
|        | **TPRM**     | 공급망 (3rd Party) 자산 관리   |
|        | **DRPS**     | 다크웹 및 사칭관련 관리           |
| **기능** | **지속적 모니터링** | 실시간 자산 탐지 및 관리          |
|        | **위험 스코어링**  | [[CVSS]] + 비즈니스 중요도 결합      |
## III. ASM과 기존 취약점 점검 방식 비교 및 발전방향
### 가. ASM vs 기존 취약점 점검 비교

| **구분** | **ASM**          | **VM (기존)**  |
| ------ | ---------------- | ------------ |
| **관점** | **공격자** 관점       | 방어자, 관리자 관점  |
| **대상** | Shadow IT, 미식별자산 | 등록된 / 식별된 자산 |
| **주기** | 지속적 / 실시간        | 정기성 / 일회성    |
| **범위** | 잠재적 공격경로 노출정보    | [[CVE]], 알려진 취약점 |
### 나. 발전방향 CTEM
- **[[지속적인 위협 노출 관리|CTEM]] (Continuous Threat Exposure Management)** 체계로 발전하여 **적응형 보안 아키텍처 진화**
- 추가 연계 발전 방향:
    - CSPM ([[CWPP & CSPM|Cloud Security Posture Management]])
    - [[SIEM]] / [[SOAR (Security Orchestration, Automation and Response)|SOAR]]
    - [[제로 트러스트 보안모델|Zero Trust]] 연계
