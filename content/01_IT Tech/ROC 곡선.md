# ROC 곡선 (Receiver Operating Characteristic Curve)

---

## I. 모든 임계값에서 분류 능력을 보는, ROC 곡선의 개요

### 가. 정의

- 이진 분류기의 **판정 임계값을 바꿔가며 TPR(재현율)과 FPR(위양성률)을 그린 곡선**, 곡선 아래 면적(AUC)으로 분류 성능을 요약

### 나. 필요성 및 특징

| 구분 | 내용 |
| --- | --- |
| 정확도의 함정 | 불균형 데이터에서는 다수 클래스로만 예측해도 정확도가 높음 |
| 임계값 독립 | 특정 임계값이 아닌 모든 임계값의 성능을 한 번에 평가 |
| AUC 해석 | 무작위로 고른 양성 표본의 점수가 음성 표본보다 높을 확률 |
| 기준선 | 대각선(AUC 0.5)은 무작위 예측, 1.0은 완벽 분리 |

---

## II. 구성 원리 및 지표

### 가. 곡선 생성 원리

```mermaid
flowchart LR
    S["모델 예측 점수<br/>(양성 확률)"] --> T["임계값을 1 → 0으로 이동"]
    T --> CM["임계값별 혼동행렬<br/>TP, FP, TN, FN"]
    CM --> P["(FPR, TPR) 점 계산"]
    P --> R["점을 이어 ROC 곡선<br/>(0,0) → (1,1)"]
    R --> A["곡선 아래 면적 AUC"]
```

- 임계값을 낮출수록 TPR과 FPR이 함께 증가, 곡선이 좌상단에 가까울수록 좋은 모델

### 나. 핵심 지표

| 구분 | 요소 | 설명 |
| --- | --- | --- |
| Y축 | TPR (재현율, 민감도) | $TP/(TP+FN)$, 실제 양성 중 양성으로 맞춘 비율 |
| X축 | FPR (위양성률) | $FP/(FP+TN)$ = 1 − 특이도, 실제 음성 중 양성으로 잘못 판정한 비율 |
| 요약 | AUC | 0.5 무작위, 0.7~0.8 양호, 0.9 이상 우수 (분야별 기준 상이) |
| 결정 변수 | 임계값 | 양성 판정 기준, 업무 비용(오탐 vs 미탐)에 맞춰 선택 |
| 최적점 | Youden's J | $TPR - FPR$이 최대인 임계값 |
| 기초 | [[혼동행렬]] | 모든 지표의 원천 |

---

## III. 비교 및 동향

### 가. ROC 곡선 vs PR 곡선

| 비교 항목 | ROC 곡선 | PR 곡선 |
| --- | --- | --- |
| 축 | X: FPR, Y: TPR | X: 재현율, Y: 정밀도 |
| 클래스 비율 영향 | 적음 (TN이 분모에 포함) | 큼 (정밀도가 양성 비율에 의존) |
| 기준선 | 0.5 대각선 | 양성 비율 (예: 1%면 0.01) |
| 적합 상황 | 비교적 균형 데이터, 전체 순위 성능 | 양성이 매우 드문 탐지 문제 |
| 요약값 | ROC-AUC | PR-AUC (Average Precision) |

### 나. 동향

- **불균형 데이터의 낙관적 AUC**: 음성이 매우 많으면 FP가 늘어도 FPR 변화가 작아 ROC-AUC가 높게 보일 수 있어, 사기·이상 탐지에서는 PR-AUC·재현율@정밀도 기준을 함께 보고 ([[클래스 불균형]])
- **확률 보정 병행**: AUC는 순위만 평가하므로 실제 확률 신뢰도는 보정 곡선·Brier Score·ECE로 별도 확인
