- 알아야하는 이유
    - 사용자들이 겪는 고충을 찾아서 해결합니다.
    - 사용자들이 서비스 이용 시 갖는 니즈를 발견해 충족시킨다.
    - 사용자들의 동기를 파악해 그것이 만족스럽게 전개되는지 확인하고 새로운 동기를 부여한다.
    - 사용자들이 서비스 이용 시 보이는 구체적인 행동을 고려해 UX/UI 를 설계한다.
    - 사용자들이 서비스에 대해서 갖는 현재의 태도를 더 긍정적으로 변화시킨다.
    - 사용자들이 서비스를 이용하는 맥락을 이해하고, UX/UI 설계 시 맥락을 고려한다.
- 동기
    -
        - Motive
    - 서비스를 이용하는 이유
    - 동기를 파악해야 행동을 이해할 수 있고, 행동을 분석해야 고충이나 니즈가 보인다.
    - 모든 동기는 행동으로 이어진다.
    - 동기는 맥락에 영향을 받는다.
    - 맥락(Context)은 UX 구성요소 중에서 동기와 행동에 큰 영향을 미친다.
    - 동기 유형
        - 목적의식적 동기
            - 맥락 영향
                - 적음
            - 경험  진행
                - 즉시 또는 거의 즉시 반드시 진행됨
            - 경험 의 성격
                - 단선적.
                - 방해나 요청을 싫어함
                - 효율성 중시 고충
                - 니즈가 중요
        - 외부 자극 → 수동적 동기
            - 맥락 영향
                - 높음
            - 경험 진행
                - 자극의 크기
                - 준비 상태
                - 태도
                - 이전(최근) 경험
                - 필연성에 결부됨
            - 경험의 성격
                - 직접적 해결 방법 중시 → 그게 안 될 때 포기 또는 간접적 대안
- 행동
    -
        - Behaivor
    - 행동 = 연속된 이동 단계 + 단계별 구체적 행위
    - 행동 유형
        - 목적의식적 동기
        - 외부 자극 → 수동적 동기
        - 내부 자극 → 수동적 동기
        - 습관적 동기
        - 이벤트 → 반응적 동기
        - 복합 작용 → 우연적 동기
- 고충
    - 사용자들은 서비스를 이용하는 과정에서 고충을 느끼거나 고충은 아니지만 이런 게 있으면 더 좋겠다라는 니즈를 갖게 된다. 일반인들은 UX 라고 하면 사람들의 고충을 해결하는 일이라고 알 고 있을 것이다. 그래서 더 편리하기, 쉽게, 즐겁게 만들어 달라고 말한것이다.
- 니즈
    - 니즈
- 태도
- 맥락
