# 디자인씽킹

디자인씽킹(Design Thinking)은 사용자에 대한 *공감*에서 출발해 *문제를 재정의*하고, 빠른 프로토타입과 실험을 통해 *해결책을 발견해 나가는* 창의적 문제 해결 방법론이다. 원래는 디자이너의 사고 방식이었지만, 지금은 스타트업부터 대기업 혁신팀까지 널리 차용된다.

## 5단계 프로세스

| 단계 | 핵심 질문 |
| --- | --- |
| Empathize (공감) | 사용자는 *무엇을* 경험하는가 |
| Define (정의) | 진짜 문제는 *무엇인가* |
| Ideate (발상) | 어떤 *해결책이 가능한가* |
| Prototype (프로토타입) | 가장 빠르게 어떻게 *만들어볼* 것인가 |
| Test (테스트) | 사용자는 이 해결책에 *어떻게 반응*하는가 |

이 단계는 선형이 아니라 *반복적*이다. 테스트 결과가 공감·정의 단계로 되돌아오는 것이 정상이다.

## 전통적 접근과의 차이

| 전통적 접근 | 디자인씽킹 |
| --- | --- |
| 정답을 찾는다 | 좋은 질문을 찾는다 |
| 분석으로 축소한다 | 확장 후 수렴한다 |
| 실패를 피한다 | 빨리·싸게 실패한다 |
| 사용자는 검증 대상 | 사용자는 *동반자* |

## 핵심 자세

- **사용자 중심(Human-Centered)**: 기술/비즈니스보다 *사람*이 출발점
- **발산과 수렴**: 아이디어를 넓히고, 기준으로 좁힌다
- **행동 우선**: 길게 회의하기보다 *빠르게 만들어* 본다
- **다학제 협업**: 한 직군의 시각을 넘어선 팀워크

## 한계

- 리서치 품질이 낮으면 전체가 무너진다
- 프로세스만 모방하고 문화를 바꾸지 않으면 형식에 그친다
- 완전히 새로운 기술이 필요한 근본 혁신에는 부족할 수 있다
