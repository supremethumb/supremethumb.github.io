카드 정렬은 사이트의 정보 아키텍처를 설계하거나 평가하는 데 사용되는 방법입니다. 카드 정렬 세션에서 참가자는 주제를 이해하기 쉬운 범주로 구성하고 이러한 그룹에 레이블을 지정하는 데 도움이 될 수도 있습니다. 카드 분류를 수행하려면 실제 카드, 종이 조각 또는 여로 온라인 카드 분류 소프트웨어 도구 중 하나를 사용할 수 있습니다.

## 카드 소팅의 장점
카드 정렬은 사용자의 기대와 주제에 대한 이해를 이해하는 데 도움이 됩니다. 사용자에 대해 알아보고 콘텐츠를 이해하기 위해 몇 가지 숙제를 마친 후에는 종종 가장 유용합니다. 사용자 그룹 정보가 어떻게 도움이 되는지 알면:
- 웹사이트를 위한 구조 구축
- 홈페이지에 무엇을 올릴지 결정
- 라벨 카테고리 및 탐색
## 개방형 및 폐쇄형 카드 정렬
필요에 따라 개방형 또는 패쇄형 카드 정렬을 선택할 수 있습니다. 다음과 같이 다릅니다.
- 오픈 카드 정렬
	- 참가자는 웹사이트 내 콘텐츠를 정확하게 설명하는 방식으로 생성한 각 그룹의 이름을 지정해야 합니다. 개방형 카드 정렬을 사용하여 사용자가 콘텐츠를 그룹화하는 방법과 각 카테고리에 부여하는 용어 또는 레이블을 알아보세요.
- 패쇄형 카드 정렬
	- 참가자는 웹사이트 내 콘텐츠에서 주제를 미리 정의된 범주로 정렬해야 합니다. 닫힌 카드 정렬은 미리 정의된 범주 집합으로 작업하고 사용자가 콘텐츠 항목을 각 범주로 정렬하는 방법을 알고 싶을 때 가장 잘 작동합니다.
두 가지를 조합하여 시도해 볼 수도 있습니다. 먼저 개방하여 카드 정렬을 수행하여 콘텐츠 범주를 식별한 다음 패쇄형 카드 정렬을 사용하여 범주 레이블이 얼마나 잘 작동하지는지 확인할 수 있습니다.

## 카드 소팅 모범 사례
- 카드 수를 제한합니다. 참가자가 콘텐츠의 '전체'를 정렬하기를 원하지만 참가자의 피로를 염두에 두십시오. 특히 개방형 정렬의 경우 절대 외부에서 30 ~ 40 을 권장합니다.
- 가능하면 각 콘텐츠가 세션 초반에 정렬될 수 있도록 플젠테이션 순서를 무작위로 지정합니다.
- 참가자들에게 필요한 시간과 노력을 더 잘 측정할 수 있도록 세션을 시작하기 전에 카드 정렬에 걸리는 예상 시간을 제공합니다.
- 참가자에게 정렬을 완료하도록 요구하는 이점을 고려하십시오. 공개 정렬의 경우 가능하면 카드를 정렬하도록 요구하지만 레이블을 지정하지 않을 수도 있습니다.
	- 항목에서 제안한 대로 항목을 제한한 경우 작업의 더 어려운 부분일 수 있기 때문입니다.
- 프로세스의 파트 1 로 열린 정렬과 파트 2 로 닫힌 정렬을 고려하십시오. 하나는 함께 사용하는 것이 무엇인지 배울 수 있게, 2 는 레이블을 실제로 테스트하여 참가자에게 직관적인지 확인할 수 있습니다.
## 카드 정렬 수행법
### 카드 준비
1. 콘텐츠 주제 목록을 만드십시오. 주제는 구 또는 단어가 될 수 있으며 매우 구체적이거나 보다 일반적입니다. 제안으로 50 ~ 60 개 이하의 주제로 자신을 제한하십시오. 즉, 사이트의 모든 페이지에 대해 정렬할 카드가 없을 수 있습니다.
	- 새 사이트의 경우 사이트에 있을 가능성이 높은 정보 유형의 콘텐츠 주제를 나열합니다.
	- 기존 사이트의 경우 가장 중요하거나 인기 있는 콘텐츠 유형을 나열합니다.
	- 이 목록을 만드려면
		- 콘텐츠 인벤토리에 나열된 콘텐츠를 검토합니다.
		- 가장 중요하거나 가장 자주 사용하는 콘텐츠 식별
2. 실제 카드 분류를 할 것인지 온라인 카드 분류 소프트웨어를 사용할 것인지 결정하십시오.
	- 온라인 카드 분류 소프트웨어를 사용하는 경우 소프트웨어 지침을 참조하십시오.
	- 실제 카드를 사용하여 카드 정렬을 수행할 경우 각 항목을 별도의 색인 카드에 씁니다.
		- 접착식 라벨과 워드 프로세서를 사용하십시오. 카드는 깔끔하고 읽기 쉽고 일관성이 있습니다. 나중에 분석할 수 있도록 컴퓨터에 주제 목록이 있습니다.
		- 하단 모서리나 뒷면에 있는 카드에 번호를 매깁니다. 이것은 카드 분석을 시작할 때 도움이 됩니다.
		- 참가자가 주제를 추가하고 카드를 정렬할 때 만드는 그룹의 이름을 지정할 수 있도록 빈 카드를 준비합니다.
		- 참가자들이 그룹의 이름을 지정하게 하려면 다른 색상의 카드를 사용하는 것이 좋습니다.
### 세션 설정
1.  각 세션에 대해 약 1 시간을 계획하고 카드가 많으면 더 길게 계획하십시오.
2.  공간을 마련합니다.
    -   종이 카드 정렬의 경우 참가자가 카드를 테이블에 펼치거나 벽에 압정/테이프로 붙일 수 있는 충분한 공간이 있는지 확인합니다. 회의실은 잘 작동합니다.
    -   온라인 카드 분류의 경우 참가자와 진행자가 편안하게 앉을 수 있는 공간뿐만 아니라 인터넷에 연결된 컴퓨터가 있는지 확인하십시오.
3.  참가자가 작업하고 큰 소리로 생각하는 동안 진행자 또는 다른 사용성 팀 구성원이 메모를 하도록 계획하십시오.
4.  다른 기술과 마찬가지로 시간과 노력을 들여 도움을 준 참가자에게 감사를 표하기 위해 지불이나 기타 인센티브를 준비하십시오.
### 세션을 리드하다.
1.  참가자에게 카드 세트를 보여줍니다. 사이트 홈페이지에 있어야 하는 정보 범주와 해당 범주의 이름을 찾는 데 도움이 필요하다고 설명합니다.
    -   공개 카드 정렬에서 참가자에게 어떤 카드 그룹이 의미가 있는지 확인하고 참가자가 카드를 그룹화하면 각 카드 그룹의 이름을 물어볼 것이라고 설명합니다.  
        폐쇄형 카드 정렬을 수행하는 경우 참가자가 카드가 정의된 그룹에 적합하다고 생각하는지 확인하고 싶다고 설명합니다.
2.  참가자에게 작업하는 동안 큰 소리로 말하도록 요청합니다. 참가자의 생각, 근거, 좌절감을 이해하고 싶습니다.
3.  참가자가 일하게하십시오. 방해를 최소화하되 참가자가 큰 소리로 생각하도록 권장합니다. 참가자가 다음을 수행할 수 있도록 허용합니다.
    -   예를 들어 측면 하이퍼링크 또는 추가 주제를 나타내기 위해 카드를 추가합니다.
    -   참가자가 사이트에서 원하지 않는 주제를 나타내기 위해 카드를 옆에 두십시오.
4.  마지막에 참가자가 홈페이지에 사용할 그룹이 너무 많으면 일부 그룹을 결합할 수 있는지 물어보십시오.
5.  참가자에게 각 범주의 이름을 지정하도록 요청합니다.
    -   열린 카드 정렬에서 참가자에게 다양한 색상의 카드 더미를 제공합니다. 참가자에게 색상 카드를 사용하여 각 그룹의 이름을 지정하도록 요청합니다. 참가자가 특정 콘텐츠 항목 그룹으로 참가자를 안내할 홈페이지 또는 두 번째 수준 페이지에서 어떤 단어를 볼 것으로 예상하는지 묻습니다.
    -   폐쇄형 카드 정렬에서 단어 기대치, 최종 카드 구성 및 기타 후속 질문에 대해 묻는 것은 연구에 대한 귀중한 통찰력과 관찰을 제공할 수 있습니다.
6.  마지막으로 참가자에게 감사의 인사를 전하고, 약속이 있으면 대가 또는 기타 선물을 제공합니다.
### 원격 정렬 세션
1.  콘텐츠 주제 목록을 만드십시오. 주제는 구, 단어 등이 될 수 있으며 매우 구체적이거나 보다 일반적일 수 있습니다. 사이트의 모든 주제에 대한 카드를 갖고 싶은 마음이 들 수도 있지만 이 경우 더 많은 것이 더 좋지 않을 수 있습니다. 참가자의 인지 부하를 고려하십시오. 당신은 그들이 당신의 마지막 카드로서 당신의 첫 번째 카드에 대한 작업이 되기를 원합니다. 제안으로 50-60 개 이하의 주제로 자신을 제한하십시오.
2.  소프트웨어 지침에 따라 카드를 준비합니다.
3.  참가자에게 연구 링크를 이메일로 보냅니다. 정렬에 대한 지침(개방 또는 폐쇄 여부)을 제공하고 세션을 완료하는 데 걸리는 대략적인 시간을 알려주십시오.
4.  의견 상자를 사용할 수 있는 경우 참가자에게 필드를 사용하여 관찰이나 질문을 기록하도록 촉구합니다. 참가자를 위해 실시간으로 답변할 수는 없지만 이러한 의견은 분석에 유용할 수 있습니다.
5.  참가자에게 시간을 내준 것에 대해 감사를 표하고 지불 또는 기타 선물(약속된 경우)을 받기 위한 지침을 제공합니다.
## 데이터 분석
1.  분석을 위해 데이터를 준비합니다.
    -   온라인 카드 분류 소프트웨어를 사용한 경우 소프트웨어 지침을 참조하십시오. 소프트웨어는 다양한 방법으로 참가자 데이터를 분석합니다.
    -   테스트에 실제 카드를 사용한 경우 정렬된 사진을 찍거나 카드의 숫자를 사용하여 참가자가 수행한 작업을 빠르게 기록합니다. 참가자가 각 그룹에 부여한 이름과 참가자가 해당 이름 아래에 포함된 카드 번호를 사진에 찍거나 기록합니다. 그런 다음 다음 세션을 위해 카드를 다시 섞을 수 있습니다.
        -   각 세션에 대한 컴퓨터 파일을 만들어 각 사용자가 생성하는 상세한 사이트 맵의 전체 그림을 수집합니다.
        -   원래 주제 목록에서 작업하고 주제를 이동하여 각 참가자의 그룹을 다시 만들고 그룹에 해당 참가자의 이름을 입력합니다.
        -   실물 카드분류를 이용했다면 나중에 참고할 수 있도록 완성된 카드분류를 사진으로 찍어두셔도 됩니다.
2.  사용자 의견을 기반으로 정성적 정보를 분석합니다.
3.  다음을 기반으로 정량적 정보를 분석합니다.
    -   가장 자주 함께 등장한 카드
    -   특정 카테고리에 카드가 표시되는 빈도
4.  결과에 대한 덜 자세한 분석을 위해 참가자의 이름과 각 사람 이름 아래의 카드 번호에 대한 메모와 녹음을 사용하여 다른 세션에서 공통점을 찾습니다.
5.  더 자세한 분석을 위해 Excel 스프레드시트를 사용하여 카드 간의 관계를 표시하거나 사용 가능한 소프트웨어 프로그램 중 하나를 사용하여 데이터를 분석하는 것을 고려하십시오.
6.  팀 및 이해 관계자와 공유하기 위해 [보고서](https://www.usability.gov/how-to-and-tools/resources/templates/card-sort-report-template.html) 에서 결과를 수집합니다.

카드 정렬에서 데이터를 분석한 후에는 사이트의 정보 아키텍처를 구성하는 데 유용한 정보가 있어야 합니다. 사이트 탐색을 정의하는 데 도움이 되도록 카드 정렬 결과를 사용해야 합니다.
## 카드 정렬 모범 사례
-   카드 수를 제한합니다. 참가자가 콘텐츠의 "전체"를 정렬하기를 원하지만 참가자의 피로를 염두에 두십시오. 특히 개방형 정렬의 경우 절대 외부에서 30~40 을 권장합니다.
-   가능하면 각 콘텐츠가 세션 초반에 정렬될 수 있도록 프레젠테이션 순서를 무작위로 지정합니다.
-   참가자들에게 필요한 시간과 노력을 더 잘 측정할 수 있도록 세션을 시작하기 전에 카드 정렬에 걸리는 예상 시간을 제공합니다.
-   참가자에게 정렬을 완료하도록 요구하는 이점을 고려하십시오. 공개 정렬의 경우 가능하면 카드를 정렬하도록 요구하지만 레이블을 지정하지 않을 수도 있습니다. 제안된 대로 항목을 제한한 경우 작업의 더 어려운 부분일 수 있기 때문입니다.
-   프로세스의 파트 1 로 열린 정렬과 파트 2 로 닫힌 정렬을 고려하십시오. 하나는 함께 사용하는 것이 무엇인지 배울 수 있게 하고, 2 는 레이블을 실제로 테스트하여 참가자에게 직관적인지 확인할 수 있습니다.
