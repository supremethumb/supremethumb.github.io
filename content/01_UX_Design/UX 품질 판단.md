# UX 품질 판단

- 기준
    - 상식적 판단
        - 무조건 이게 더 낫다
            - 예시가 적절하지 않은 듯...
    - 맥락 고려
        - 맥락을 고려했을 때 이게 더 낫다.
            - 두 개의 상태를 서로 오가는 경우에는 두 상태에 대한 버튼을 각각 놓기보다는 하나로 합쳐놓는 게 실제 사용한 데 더 쉽게 느껴지기 때문이다.
            - 토글버튼
                - 하나의 행위로 상태만 바꾸는 것
    - 명확성
        - 결과의 명확성 측면에서 이게 더 낫다.
    - 조건별 취사 선택
        - 조건에 따라서 판단이 달라진다.
    - 충돌하는 두 가지 중 더 나은 선택
        - 트레이드 오프(Trade-off)를 어느 게 더 맞게 했는가?
        - 서로 가치가 상충하는 상황에서 어느 하나를 선택하는 것을 희생과 선택이라고 부른다.
    - 대상이 누구인가
        - 누구를 대상으로 했는가에 따라서 평가가 달라진다.
