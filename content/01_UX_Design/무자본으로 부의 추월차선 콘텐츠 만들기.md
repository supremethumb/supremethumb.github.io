# 무자본으로 부의 추월차선 콘텐츠 만들기

## 책 소개

투자금 0원으로 시작하는 1인 콘텐츠 사업의 실전 가이드. 엠제이 드마코의 '부의 추월차선'에서 제시한 5가지 돈나무 중 유일하게 투자금이 필요 없는 **콘텐츠 시스템**에 주목하고, 경험을 지식으로, 지식을 콘텐츠로, 콘텐츠를 현금으로 전환하는 체계적 프로세스를 제시한다.

## 핵심 인사이트

### 1. 정크 콘텐츠 vs. 캐시 콘텐츠

| 구분 | 정크 콘텐츠 | 캐시 콘텐츠 |
|---|---|---|
| 목적 | 채우기용 | 판매용 |
| 성격 | 짜깁기, 신변잡기 | 오리지널, 문제 해결 |
| 고객 투자 | 좋아요(일시적) | ATM — 관심·시간·돈 |
| 구글 기준 | E-A-T 미충족 | **전문성·권위·신뢰성** 충족 |

**C.A.S.H 유전자 테스트**: Cashable(ATM을 투자받는) × Audience(고객이 원하는) × Strength(내가 남다르게 잘하는) × Hooky(문제를 해결하는)

### 2. 경험을 현금으로 바꾸는 4단계

1. **절정 경험 발굴** — 하고 싶고, 하고 있으며, 하게 되는 일을 찾아라
2. **경험의 지식화** — 왜, 어떻게 잘했는지 분석해 노하우로 정리
3. **콘텐츠화** — 누구의 어떤 문제를 해결하는 콘텐츠로 블로그에 무료 제공
4. **현금화** — 강연, 출판, 교육, 조언의 4가지 파이프라인으로 판매

수익 파이프라인: **강출교조**(강연하기 → 출판하기 → 교육하기 → 조언하기)

### 3. 원형 콘텐츠 — 지·덕·체

- **지**: 생업에서 마련한 지식과 지혜 (잘하는 일)
- **덕**: 덕후 생활에서 얻은 지혜 (좋아하는 일)
- **체**: 생활 속에서 체득한 기술 (능숙한 일)

원형 콘텐츠는 에스프레소와 같다. 하나의 원두에서 다양한 음료를 만들듯, 원형 콘텐츠 하나로 강연·책·교육·컨설팅이라는 다양한 형태의 캐시 콘텐츠를 생산한다.

### 4. 레어템 공식 — 경쟁 없이 이기는 법

> **콘텐츠거리 × 차별 포인트 = 레어템(독점적 경쟁력)**

차별 포인트를 만드는 5가지 결정타:
- × 다른 관점: "○○에 있어서 X를 빼고 생각할 수 없다"
- × 다른 분야
- × 다른 대상
- × 새로운 결핍
- × 주제 쪼개기

### 5. 검증: 21일 매일 쓰기 테스트

주제를 정하고 21일 동안 매일 쓰는 것이 유일한 조건. 21일 동안 지속할 수 없다면 주제를 바꿔 재시도한다. 성공한 주제가 곧 당신의 콘텐츠거리다.

최종 확인 7가지: 직접 경험했는가? → 돈이 될 만한가? → 성장 가능성이 있는가? → 무엇에 관한 것인가? → 누구를 고객으로 하는가? → 어떤 가치를 제공하는가? → 이걸로 사업하고 싶은가?

### 6. 캐시 콘텐츠 글쓰기 공식

**OREO 공식**: Opinion(해결책 제시) → Reasons(이유·근거) → Example(예시) → Opinion(구체적 방법 제안)

**PSPS 공식**: Problem(문제 제기) → Solution(해결책 언급) → Point(어려움 강조) → Solution(내 제품이 최적임을 강조)

**123 규칙**: 1번에 하나씩(하나의 메시지) + 2W1H(Why·What·How) + 3분 이내(1,500자, 3~4단락)

### 7. 시그니처 솔루션 개발

> 시그니처 솔루션 = C.A.S.H 콘텐츠 × 해결책 × 고유성 × 대표성

최종 점검 기준 **ROI**: Relevance(문제 해결 가능?) × Originality(고유한 해결책?) × Impact(해결 보장?)

## 내 생각

이 책의 핵심 가치는 **콘텐츠 사업의 전체 파이프라인을 하나로 꿰는 프레임워크**다. C.A.S.H 유전자 → 원형 콘텐츠 → 레어템 공식 → OREO/PSPS 글쓰기 → 시그니처 솔루션이라는 흐름이 명확해서, 당장 내일부터 블로그를 시작할 수 있을 정도로 실행 가능하다.

특히 "열정을 따르지 말고, 잘해온 일에서 금맥을 찾으라"는 조언과 "21일 매일 쓰기 테스트"는 콘텐츠 사업의 가장 흔한 실패 원인(주제 선정 오류, 지속 불가)에 대한 실전적 해법이다.
