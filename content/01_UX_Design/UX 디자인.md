#정의 
사용자 경험 디자인은 사람과 컴퓨터의 상호작용에 관한 주제를 연구하는 인간 컴퓨터 상호작용 분야에서 사용자 중심 디자인을 설명할 때 종종 사용되는 단어였다. 이 단어가 전문 용어로 자리를 잡은 것은 인지 심리학자 도널드 노먼 덕분이다. #오래가는 UX 디자인
사용자 경험(UX: User eXperience)란 사용자가 기업, 서비스, 기업의 제품과 상호작용하면서 얻는 모든 측면의 경험을 의미한다. 훌륭한 사용자 경험을 만드는 첫 번쨰 조건은 고객의 요구를 정확하게 만족시키는 것이다. 하지만 고객의 만족을 위해서 그들을 귀찮게 하거나 혼란스럽게 해서는 안된다. 그 다음으로 중요한 것은 단순함과 우아함인데, 이런 특징은 사람들이 가지고 싶어하는 제품을 만드는 바탕이 된다. 정말 훌륭한 사용자 경험을 제공하려면 고객이 직접 필요하다고 말하는 것 이상을 제공해야 하며, 체크리스트에 나열된 기능을 제공한느 수준을 넘어서야 한다. 훌륭한 사용자 경험을 제공하려는 기업은 공학, 마케팅, 그래픽 디자인과 제품 디자인, 인터페이스 디자인 같은 분야의 서비스를 매끄럽게 통합해야 한다. #오래가는 UX 디자인 

---

사용자 경험은 최종 사용자가 회사, 서비스 및 제품과의 상호 작용의 모든 측면을 포괄합니다.
모법적인 사용자 경험에 대한 첫 번재 요구 사항은 소란이나 귀찮게하지 않고 고객의 정확한 요구를 충족하는 것입니다. 다음은 소유의 기쁨, 사용하는 기쁨 제품을 생산하는 단순함과 우아함이 제공됩니다. 진정한 사용자 환경은 고객에게 원하는 것을 제공하거나 체크리스트 기능을 제공하는 것 이상입니다. 회사의 제품에서 고품질 사용자 경험을 달성하기 위해서는 엔지니어링, 마케팅, 그래픽 및 산업 설계 및 인터페이스 디자인을 포함한 여러 분야의 서비스를 원활하게 병합해야 합니다.
UI 가 디자인의 매우 중요한 부분이더라도 총 사용자 환경을 사용자 인터페이스와 구별하는 것이 중요합니다. 예를 들어 영화 리뷰가 있는 웹 사이트를 고려하십시오. 영화를 찾는 UI 가 완벽하더라도 기본 데이터베이스에 주요 스튜디오의 영화만 포함되어 있는 경우 작은 독립 릴리스에 대한 정볼르 원하는 사용자에게 UX 가 좋지 않습니다.
우리는 또한 UX 와 유용성을 구별해야 한다. 유용성의 정의에 따르면, 시스템이 배우기 쉽고, 효율적으로 사용할 수 있는지, 쾌적함 등 UI 의 품질 속성입니다. 다시 말하지만 이것은 매우 중요하며, 다시 전체 사용자 환경은 더 넓은 개념입니다.

사람과 컴퓨터의 상호작용에 관한 주제를 연구하는 인간 컴퓨터 상호작용 분양서 사용자 중심 디자인을 설명할 때 종종 사용되는 용어 #오래가는 UX 디자인(작성중) 
    - 특정 서비스를 이용할 때 사용자들이 보이는 생각, 감정, 행동 #이것이 UX 디자인이다(작성중) 
    - 사용자들이 서비스 이용 시 겪는 고충, 서비스에 대해 갖는 니즈 #이것이 UX 디자인이다(작성중) 
    - 은행: 디지털 뱅킹을 통한 조회/거래/상담, 금융상품 이용, 사용자 상호 간 금전 거래 #이것이 UX 디자인이다(작성중) 
    - 통신: 통신 상품과 관련된 가입/조회/관리 활동, 멤버십 서비스, 미디어/엔터테인먼트 이용 #이것이 UX 디자인이다(작성중) 
    - 쇼핑: 채널 내에서의 접근/탐색/조회/구매/이벤트/관리 활동, 외부 채널에서의 유입/프로모션 #이것이 UX 디자인이다(작성중) 
    - Social Media: 가입/조회/등록/관리/커뮤니케이션 활동, 카메라/미디어 등과의 연 #이것이 UX 디자인이다(작성중) 
    - 제품을 디자인할 때 제품과 함께 사용자에게 전달되는 기업의 이미지, 고객 지원 방식, 광고와 마케팅 문구 같은 유무형의 메시지를 함꼐 고민해야 전체적으로 사용자 경험을 고려한 제품 UX
    - 디자인의 요소로 사용자 만족, 단순한, 우하함을 꼽고 있다. 여기서 단순함은 제품의 사용성 과 관련이 있다. 좋은 제품은 우선 사용하기 쉽고 배우기 쉬우며 원하는 작업을 효율적으로 처리할 수 있어야 한다. 우아함 은 사용자의 감성  요소와 관련이 있다. 제품의 매력적인 외형, 좋은 촉감, 세련되고 우아한 피드백 효과 같은 것이 우아함 과 관련된 요소다. UX
- UX 의 영역 #이것이 UX 디자인이다(작성중) 
    - 소프트웨어나 PC 웹, 모바일 앱에서의 UX 디자인
    - UI 이외에 암묵적으로 IA, 이용흐름, 인터랙션, GUI 등이 포함되어 있음
    - 최근 들어 시각적인 UI 이외에 음성이나 텍스트 UI 까지 영역이 넓어졌음
    - 한 마디로 UI 중심의 UX 디자인 접근 방법
    - 서비스가 아닌 사용자 관점에서 새로운 경험을 제시하는 프로젝트 수행 절차 - 방법론
    - UX 품질 판단
