    - 유지보수성
        - 개선 확장 용이한 특성 분석성, 변경성, 안정성, 시험성
    - 이식성
        - 다른 플랫폼 적용 가능 적용성, 설치성, 대체성
- UI 는 우리가 만든 경험을 사용자에게 전달하는 방법이다. #이것이 UX 디자인이다(작성중) 
- [UX](UX.md) 방법론 #이것이 UX 디자인이다(작성중) 
- UI 는 설계 디자인 #이것이 UX 디자인이다(작성중) 
- 실제 사용자 들이 겪는 고충과 니즈, 행위를 반영해서 서비스를 설계하겠다는 의미다. #이것이 UX 디자인이다(작성중) 
- 서비스가 구체적으로 보여지는 형태, 정보의 배치 및 구성 - 디자인 대상 #이것이 UX 디자인이다(작성중) 
- 사용자들이 원하는 것은 좋은 UI 보다는 '정보를 잘 탐색하고 이용할 수 있는 좋은 UX' #이것이 UX 디자인이다(작성중) 
- UI 는 화면 내 노출될 정보를 구성하고 위아래 및 좌우로 배치하고 각 정보나 기능의 형태를 디자인 하는 작업이다.
- UI 에서 제일 처음하는 작업은 정보를 구성하는 것이다. 어떤 정보를 제공하지 정의하고, 정보를 묶거나 쪼개면서 연관 관계를 설계한다. 그 다음 앞서 구성된 정보를 상하좌우로 배치한다. 배치는 UI 설계에서 매우 중요한 작업인데, 잘 만들어진 배치는 시각적인 계층구조가 뛰어나서 사용자들이 자연스럽게 정보를 이용할 수 있게 돕는다. 사용자가 무의식적으로 디자이너가 의도한 UX 대로 정보를 이용하게 하기 위해서 강조, 대비, 균형, 요약을 하기도 한다. 마지막으로 배친된 정보의 형태를 결정한다. 텍스트로 할지, 이미지로 할지, 밀도 있게 표현할지, 여유 있게 표현할지 등을 UI 에 반영한다. #이것이 UX 디자인이다(작성중) 
- 프로토타입 발표 자리를 가보면 UX 가 없는 UI 를 만나는 경우가 적지 않다. 왜 그렇게 정보를 구성, 배치하고 그런 형태를 만들었는지에 대해서 아무도 고민을 하지 않는 것이다. 다시 말해 사용자들이 겪는 문제가 무엇이고, UI 를 통해 그것을 어떻게 해결하겠다는 UX 적인 의도가 없다. #이것이 UX 디자인이다(작성중)
