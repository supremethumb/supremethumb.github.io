쉐브론(Chevron)은 *V 자 모양* 또는 이를 90 도 회전한 `>` 같은 꺾쇠 모양을 뜻한다. 원래는 군 계급장이나 건축 장식에서 쓰이던 기호지만, UI 에서는 *방향 지시*와 *확장 가능*이라는 의미를 전달하는 핵심 아이콘으로 자리 잡았다.

## 의미와 방향

| 방향 | 의미 |
| --- | --- |
| `>` (오른쪽) | "더 있음", 다음 화면으로 이동, 세부 보기 |
| `<` (왼쪽) | 뒤로 가기, 이전 단계 |
| `∨` (아래) | 접혀 있는 내용 펼치기, 드롭다운 |
| `∧` (위) | 펼쳐진 내용 접기 |

## 어디에 쓰이는가

- **리스트 행**: 아이템 오른쪽에 `>` → 탭하면 상세 화면
- **아코디언**: 섹션 제목 옆 `∨`/`∧` → 내용 펼침/접힘
- **드롭다운**: 선택 가능한 옵션이 더 있음을 암시
- **슬라이더/캐러셀**: 좌우 이동
- **빵부스러기(Breadcrumb)**: `Home > Category > Item`

## 화살표와의 차이

쉐브론은 *더 있음을 암시하는 가벼운 신호*라면, 화살표(→)는 *명시적인 이동 지시*에 가깝다.

- 쉐브론: 행의 끝에 작게, 시각적 방해가 적음
- 화살표: 주목도 있음, 버튼 안에 많이 쓰임

## 디자인 주의점

- *너무 미세한 각도*는 탭 영역에서 인식 어려움
- *방향이 직관적이어야* 한다 — 펼침/접힘이 뒤집혀 있으면 혼란
- 접근성([[ARIA]]) — 스크린 리더를 위한 라벨이 필요
