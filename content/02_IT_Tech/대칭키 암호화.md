# 대칭키 암호화

- 암호화와 복호화에 같은 암호키를 쓰는 알고리즘
- 평문→암호화→암호문→복호화→평문
    - 암호화, 복호화 같은 키 사용
- 블록 암호 방식
    - 긴 평문을 암호화 하기 위해 고정 길이의 블록을 암호화하는 블록 알고리즘을 반혹하는 방법
    - DES, AES, SEED
- 스크림 암호 방식
    - 매우 긴 주기의 난수열을 발생시켜 평문과 더불어 암호문을 생성하는 방식
    - RC4
- 키 분배 및 관리의 어려움
- 기밀성만 보장
