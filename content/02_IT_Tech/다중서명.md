# 다중서명

---
## I. 자산보호와 권한 분산의 핵심, 다중서명의 개요
- **정의**: 하나의 거래를 승인하기 위해 미리 지정된 여러 개의 키 중 정해진 수 이상의 서명이 필요한 기술
- **필요성 및 특징**:
  - 보안성 강화 / 권한 분산 및 거버넌스
  - M of N 서명 / 가용성 확보

- **m of n 구조**: 특정 수(m) 이상이 합의되어야 인증 및 실행되는 구조

### 나. 다중서명의 핵심 기술요소

| 구분 | 핵심 기술 | 설명 |
| :--- | :--- | :--- |
| **합의 구조** | M of N 방식 | n개 중 m개의 서명 필요 |
| **알고리즘** | Schnorr 서명 | 결합(Aggregation)을 통한 서명 크기 및 검증 축소 |
| | ECDSA | 타원곡선 암호 기반 디지털 서명 |
| **운영 방식** | On-Chain Multisig | 스마트 컨트랙트 기반, 투명도 높은 온체인 검증 |
| | Off-Chain MPC | 다자간 컴퓨팅(MPC) 기반 연산 처리로 효율성 증대 |
| **보안 모델** | 가용성 | 임계치 만족 시 정상 거래 기록/실행 보장 |
| | 기밀성 | 사설키 분산 보관을 통한 단일 실패점(SPOF) 방지 |
| **표준/응용** | ERC-4337 | 계정 추상화(Account Abstraction)를 통한 유연한 다중서명 구현 |

- 분산된 키를 통한 **가용성**, **기밀성** 확보가 핵심 항목

## III. 다중서명과 임계치 서명 비교 및 향후 전망

### 가. 다중서명과 임계치 서명의 비교

| 비교 항목 | 다중서명 (Multisig) | 임계치 서명 (Threshold Signature) |
| :--- | :--- | :--- |
| **처리 위치** | 온체인 (On-Chain) | 오프체인 (Off-Chain) |
| **데이터 크기** | 서명 수에 비례하여 증가 | 단일 서명과 동일 크기 유지 |
| **프라이버시** | 서명 참여 주체 노출 | 서명 참여자 은닉 가능 (익명성) |
| **유연성** | 특정 체인 종속적 (스마트 컨트랙트) | 블록체인 프로토콜 무관 (범용적) |

### 나. 다중서명의 향후 전망
- **기관용 커스터디 서비스**: 가상자산 수탁 및 대규모 자산 관리를 위한 엔터프라이즈 보안의 핵심 채택
- **계정 추상화(ERC-4337) 결합**: 사용자 편의성 증대 및 스마트 월렛(소셜 복구 등) 환경으로 진화
- **컴플라이언스 준수**: 내부 통제 및 규제 준수를 위한 다중서명 감사 로그 법제화 추세
