# MAC

- Mandatory Access Control
    - 강제적 접근 통제
    - Message Authentication Code
- Mandatory Access Control
    - 시스템 정보의 허용 등급을 기준으로 사용자가 갖는 접근 허가 권한에 근거하여 시스템에 대한 접근을 제한하는 방법
    - 보안 등급
- Message Authentication Code
    - 키를 사용하는 메시지 인증 코드로 메시지의 무결성과 송신자의 인증 보장
    - HMAC, NMAC
    - 묶어서 같이 보냄
