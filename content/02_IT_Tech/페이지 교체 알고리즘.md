## II. 주요 페이지 교체 알고리즘의 유형 및 특징

### 가. 알고리즘별 메커니즘 및 비교

| 분류     | 알고리즘                                     | 설명                                     |
| :----- | :--------------------------------------- | :------------------------------------- |
| **기본** | **[[FIFO]]**<br>*(First In First Out)*   | 선입선출 기법으로 구현이 간단함                      |
| **최적** | **[[Optimal]]**<br>*(Belady)*            | 이론적 최저 부재율, 앞으로 가장 오랫동안 사용되지 않을 페이지 교체 |
| **시간** | **[[LRU]]**<br>*(Least Recently Used)*   | 가장 오래 참조되지 않은 페이지를 교체                  |
| **시간** | **[[NUR]]**<br>*(Not Used Recently)*     | 비트를 사용하여 교체 우선순위 결정                    |
| **빈도** | **[[LFU]]**<br>*(Least Frequently Used)* | 참조 횟수가 가장 적은 페이지 교체                    |
| **빈도** | **[[MFU]]**<br>*(Most Frequently Used)*  | 참조 횟수가 가장 많은 페이지 교체                    |
| **개선** | **Second Chance**                        | [[FIFO]]의 단점 보완                            |
