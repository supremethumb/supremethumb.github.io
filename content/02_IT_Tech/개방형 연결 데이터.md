# 개방형 연결 데이터 (LOD Linked Open Data)
---
## I. 데이터의 웹(Web of Data) 실현을 위한 핵심, LOD의 개요

### 가. LOD(Linked Open Data)의 정의

- 웹 상에 존재하는 데이터를 개별 [[URI]](Uniform Resource Identifier)로 식별하고, 각 URI에 링크 정보를 부여하여 상호 연결된 웹을 지향하는 기술 및 방법론.
- 시맨틱 웹(Semantic Web)을 실현하기 위한 응용 기술로, 웹상의 모든 데이터가 링크로 연결되어 기계가 자동으로 처리할 수 있는 데이터 환경.
### 나. 핵심 키워드

- URI, RDF, SPARQL, 온톨로지(Ontology), 개방(Open), 연결(Link).

### 나. LOD의 핵심 기술요소 상세

| 구분 | 기술요소 | 설명 및 역할 |
| --- | --- | --- |
| 식별 | URI | - 인터넷상의 자원(Resource)을 식별하기 위한 고유한 주소 체계. |
| 구조 | [[XML]] | - 데이터의 구조를 정의하는 메타 언어, 기계 가독성 제공. |
| 서술 | RDF | - 자원의 속성 및 관계를 Triple(Subject-Predicate-Object) 구조로 표현하는 [[프레임워크]]. |
| 지식 | 온톨로지<br>(Ontology) | - 단어와 단어 사이의 관계, 개념을 정의하는 사전(Dictionary) 역할 (예: OWL). |
| 질의 | SPARQL | - RDF 형태로 저장된 데이터를 검색하고 질의하기 위한 표준 언어. |

## III. LOD 발행을 위한 4대 원칙 및 개방 5단계 (5 Star)

### 가. Berners-Lee의 LOD 4대 원칙

1. URI 사용: 모든 사물(Things)에 URI를 부여하여 식별.

2. HTTP URI: 누구나 참조할 수 있도록 HTTP [[프로토콜]] 사용.

3. 표준 제공: RDF, SPARQL 등 표준 기술을 사용하여 유용한 정보 제공.

4. 링크 포함: 다른 데이터와 연결될 수 있도록 링크 정보 포함.

### 나. 공공데이터 개방 5단계 (Open Data 5 Star)

| 등급 | 포맷 예시 | 특징 및 LOD와의 관계 |
| --- | --- | --- |
| ★ | PDF, JPG | - 육안 식별 가능, 데이터 가공 어려움. |
| ★★ | XLS | - 구조화된 데이터이나 독점 포맷 사용. |
| ★★★ | CSV, XML | - 오픈 포맷. 비독점적이며 기계 판독 가능. |
| ★★★★ | RDF | - URI를 사용하여 데이터의 의미와 관계를 기술. |
| ★★★★★ | LOD | - 데이터 간 연결(Linked Data). 웹상의 다른 데이터와 연결됨. |

---

## IV. LOD의 활용 및 기대효과

- 활용: [[공공데이터]] 포털(CKAN), 지식 그래프(Knowledge Graph) 구축, AI 학습용 데이터셋 연계 등에 활용됨.
- 기대효과: 데이터의 사일로(Silo) 현상을 제거하고, 데이터 간의 의미적 연결을 통해 웹 3.0(지능형 웹) 환경을 구현함.

## I. 글로벌 지식 융합의 인프라, 개방형 연결 데이터(LOD)의 개요

정의: 웹상에 존재하는 개방형 데이터들을 식별 가능한 URI로 식별하고, 각 데이터의 의미와 관계를 기계가 이해할 수 있는 형태(RDF)로 표현하여 서로 연결해 놓은 거대한 글로벌 데이터 웹(Web of Data).

## II. 팀 버너스리의 LOD 4대 원칙 및 5스타(Star) 모델

LOD 생태계를 구축하기 위해 W3C 창시자 팀 버너스리(Tim Berners-Lee)가 제안한 핵심 원칙과 데이터 개방 수준 지표입니다.

### 1. LOD 발행 4대 핵심 원칙

| 원칙 | 설명 | 핵심 기술 |
| --- | --- | --- |
| 1. 식별 (Identify) | 웹상의 모든 개체(사물, 개념)에 고유한 이름을 부여함 | URI (Uniform Resource Identifier) |
| 2. 접근 (Access) | 사람들이 해당 식별자를 찾아볼 수 있도록 HTTP 프로토콜 사용 | HTTP URI |
| 3. 표준 표현 (Format) | URI를 통해 접근했을 때 기계가 읽을 수 있는 유용한 표준 데이터 제공 | RDF, SPARQL |
| 4. 연결 (Link) | 다른 정보도 탐색할 수 있도록 다른 데이터의 URI 링크를 포함 | Linked Data (External URI) |

### 2. 개방형 데이터의 5-Star 모델

- ★ (1성): 라이선스를 명시하여 웹에 공개 (예: PDF, 이미지 형태)
- ★★ (2성): 기계가 읽을 수 있는 구조화된 데이터로 공개 (예: Excel)
- ★★★ (3성): 특정 기업에 종속되지 않은 비독점적 포맷으로 공개 (예: CSV, [[JSON]])
- ★★★★ (4성): 데이터 내 사물을 가리킬 때 W3C 표준인 URI와 RDF 사용
- ★★★★★ (5성): 내 데이터를 다른 사람의 데이터(LOD)와 링크(Link)하여 문맥 제공

## III. LOD 구현을 위한 핵심 요소 기술 체계

| 구분 | 요소 기술 | 역할 및 특징 |
| --- | --- | --- |
| 식별 체계 | URI / IRI | 인터넷상 자원의 고유한 식별자 (IRI는 다국어 지원 확장에 사용) |
| 데이터 표현 | RDF<br>(Resource Description Framework) | 데이터를 주어(Subject), 서술어(Predicate), 목적어(Object)의 트리플(Triple) 구조로 표현하는 W3C 표준 포맷 |
| 의미 규칙 | OWL<br>(Ontology Web Language) | 개체 간의 계층 구조, 속성, 관계(Ontology)를 정의하여 기계가 추론(Reasoning)할 수 있게 하는 언어 |
| 질의 언어 | SPARQL | RDF 기반의 그래프 데이터 모델에서 원하는 정보를 검색하고 추출하기 위한 W3C 표준 쿼리 언어 |

---

## IV. 최신 기술 동향 (2025-2026) 및 발전 전망

- [[초거대 언어 모델|LLM]]과 지식 그래프의 결합 ([[GraphRAG (Graph Retrieval-Augmented Generation)|GraphRAG]]): 생성형 AI의 치명적 단점인 [[할루시네이션|환각 현상]](Hallucination)을 제어하기 위해, 사실 기반으로 검증되고 의미적으로 연결된 LOD(지식 그래프)를 벡터 DB와 함께 검색 증강 생성(RAG)의 정보원(Knowledge Base)으로 활용하는 사례가 급증하고 있습니다.
- 데이터 스페이스(Data Spaces) 생태계 핵심 요소: 유럽의 Gaia-X를 비롯한 글로벌 데이터 공유 플랫폼들이 서로 다른 도메인(의료, 금융, 제조 등)의 데이터를 상호운용(Interoperability)하기 위해 메타데이터 표준으로 LOD 원칙을 적극 채택하고 있습니다.
- 솔리드(Solid) 프로젝트와 데이터 주권: 데이터 독점을 막고 사용자 개인에게 데이터 통제권을 돌려주는 웹 3.0 프로젝트인 'Solid(팀 버너스리 주도)' 시스템에서, 개인의 파드(Pod) 간 데이터 연동을 위한 필수 프로토콜로 Linked Data가 사용되고 있습니다.
