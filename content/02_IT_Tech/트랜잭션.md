- 특징
    - 원자성
            - Atomicity
        - 분해가 불가능한 작업의 최소 단위
        - 연산 전체가 성공 또는 실패
    - 일관성
            - Consistency
        - 트랜잭션이 실행 성공 후 향상 일관된 데이터베이스 상태 보전
        - 무결성 제약조건
        - 동시성제어
    - 격리성
            - Isolation
        - 트랜잭션 실행 중 생성하는 연산의 중간 결과를 다른 트랜잭션이 접근 불가
    - 영속성

            - Durability
        - 성공이 완료된 트랜잭션의 결과를 영속적으로 데이터베이스에 저장
- 상태 변화
    - 활성 → 부분완료 → 완료 → 실패 → 철회
