## I. 고우선순위 태스크의 무한대기, 우선순위 역전 개요

| :--- | :--- |
| **정의** | 동기화로 인해 우선순위가 높은 프로세스가 낮은 프로세스보다 실행이 지연되는 현상 |

### 나. 우선순위 역전 해결을 위한 핵심 기술요소

| 분류 | 기술 | 설명 |
| :--- | :--- | :--- |
| **상속 기법** | **PIP**<br>*(Priority Inheritance Protocol)* | 점유한 저순위 태스크를 고순위까지 **우선순위 상향** |
| **상한 기법** | **PCP**<br>*(Priority Ceiling Protocol)* | **최고 우선순위 상한값** 설정 |
| **기본 제어** | **Priority Ceiling** | 자원 점유 즉시 **상한치로 올리는 방식** |
| **기타 전략** | **Interrupt Disabling** | 임계구역 진입 시 **선점 자체 차단** |
| | **Priority Queuing** | 세마포어 대기큐를 **우선순위 순으로 관리** |

* PIP와 PCP를 통한 해결이 가장 중요함.

---

## III. 해결 프로토콜 (PIP vs PCP) 비교

| 비교 항목 | 우선순위 상속 (PIP) | 우선순위 상한 (PCP) |
| :--- | :--- | :--- |
| **상향 시점** | 고순위 태스크 요청 시 | 저순위 태스크 점유 시 |
| **교착 상태** | 방지 불가 | 방지 가능 |
| **구현 복잡도** | 상대적 단순함 | 다소 복잡 |
| **주요 특징** | 상속의 연쇄 | 블로킹 횟수 제한 |

* 멀티코어 환경의 확장, eBPF 기반 실시간 모니터링.
