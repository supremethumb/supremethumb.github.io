- 산술 연산자
    - +, - 일반적 사용
- 시프트 연산자
    - 비트를 이동시키는 연산자
- 관계 연산자
    - 두 피연산자 사이의 크기 비교
- 논리 연산자
    - 두 피연산자 사이의 논리적인 관계 정의
- 대입 연산자
    - 변수에 값을 대입할 때 사용하는 연산자
    - 오른쪽에 있는 값을 이용해 왼쪽의 변수에 대입해 값을 대입하는 연산자
- 증감 연산자
    - 피연산자 1 씩 증가 or 1 씩 감소
- 상향 연산자
    - If / Else 와 동일하게 사용이 가능함
