# DCL

- 기능
    - 데이터 보안
    - 무결성 유지
    - 병행제어
    - 회복
- DCL/TCL
    - COMMIT
        - 트랜잭션 확정
        - 데이터베이스 트랜잭션의 내용 업데이트를 영구적으로 확정하는 명령어
    - ROLLBACK
        - 트랜잭션 취소
        - 데이터베이스에서 업데이트 오류가 발생할 때, 이런 상태로 되돌리는 명령어
    - SAVEPOINT = CHECKPOINT
        - 트랜잭션 취소
            - 데이터 베이스에서 업데이트 오류가 발생할 때, 이런 상태로
        - 저장시기 설정
            - 트랜잭션의 특정 지점에 이름을 지정하고, 그 시점 이전에 수행한 작업에 영향을 주지 않고 그 지점 이후에 수행한 작업 롤백할 수 있는 명령어
- GRANT 명령어
    - 데이터 베이스 관리자가 사용자에게 데이터 베이스에 대한 권한을 부여하는 명령어
    - ```sql
GRANT ...
ON ...
TO ...;
```
- REVOKE 명령어
    - 데이터 베이스 관리자가 사용자에게 부여했던 권한을 회수하기 위한 명령어
    - ```sql
REVOKE ...
ON ...
FROM ...;
```
