네트워크(Network)는 *원하는 정보를 원하는 수신자에게 정확하게 전송*하기 위한 기반 인프라다. 두 대 이상의 컴퓨팅 장치가 *물리적·논리적*으로 연결되어, 데이터·자원·서비스를 주고받을 수 있도록 해 준다. 인터넷이라는 거대한 네트워크 위에서 거의 모든 현대 서비스가 작동한다.

## 구성 요소

- **노드(Node)**: 단말 기기, 서버, [[라우터]], [[스위치]] 등
- **링크(Link)**: 노드를 연결하는 매체 (구리선, 광케이블, 무선)
- **[[프로토콜]](Protocol)**: 통신 규약 ([[TCP]]/IP, HTTP 등)
- **주소 체계**: [[IP]], MAC 주소

## 분류

### 범위 기준

| 종류 | 범위 | 예시 |
| --- | --- | --- |
| LAN | 같은 건물·집 | 사무실 와이파이 |
| MAN | 도시 단위 | 지자체 광역망 |
| WAN | 국가/대륙 | 인터넷 |
| PAN | 개인 주변 | 블루투스 |

### 토폴로지

- 버스 / 링 / 스타 / 메시 / 트리

## 통신 모델

- [[OSI 7 Layer]]: 7 계층 참조 모델
- TCP/IP: 4 계층 실제 구현 모델

## 네트워크 장비

- [[라우터]]: 서로 다른 네트워크를 연결, 경로 결정
- [[스위치]]: 같은 네트워크 안에서 데이터 전달
- [[방화벽]]: 트래픽을 검사·차단해 보안 강화
- [[백본망]]: 네트워크의 핵심 간선

## 네트워크 품질

- [[QOS]]: 트래픽 우선순위와 자원 보장
- [[가용성]] · [[신뢰성]]: 서비스 품질의 토대
