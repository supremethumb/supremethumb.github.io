# 가상물리시스템
소프트웨어로 만들어지 간상세계와 물리적인 실제의 시스템을 통합한 시스템의 시스템을 말하는 것으로, 가상 공간의 컴퓨터가 네트워크를 통해서 실제의 물리환경의 데이터에 접근하여 실시간 제어하는 기술임. 최근 디지털트윈과 같은 시스템 기술과 유사한 기술 용어임.[^1]

[^1]: 쉽게 활용하는 인공지능 비즈니스
