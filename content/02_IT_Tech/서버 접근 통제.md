# 서버 접근 통제

- 유형
    - DAC
    - MAC
    - RBAC
- 접근 통제 보호 모델
    - 벨라파둘라 모델
        - 미국방부 자원 보안 모델로 보안 요소 중 기밀성을 강조하여 강제적 정책에 의해 접근 통제하는 모델
    - 비바모델
        - 벨라파둘라 모델의 단점을 보완한 무결성을 보장하는 최초의 모델
