- 데이터베이스를 접근하고 조작하는데 필요한 표준 언어를 활용할 수 있게 해주는 규칙
- 종류
    - 데이터 정의
        -
            - DDL
        - 데이터를 정의하는 언어
        - 데이블이나 관계의 구조로 생성하는데 사용
        - CREATE, ALTER, DROP, TRUNCATE
    - 데이터 조작
        -
            - DML
        - 데이터 베이스에 저장된 자료들을 입력, 수정, 삭제, 조회하는 언어
        - SELECT, INSERT, UPDATE, DELETE
        - SELECT 문은 특별히 질의어(QUERY)라고 부름
    - 데이터 제어
        -
            - DCL
        - 데이터 베이스 관리자가 데이터 보안, 무결성 유지, 병행제어, 회복을 위해 DBA 가 사용하는 제어용 언어
        - GRANTE, REVOKE 문이 있음
