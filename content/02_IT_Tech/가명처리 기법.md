# 가명처리(Pseudonymization) 기법

---
## I. 안전한 데이터 경제 활성화의 핵심, 가명처리(Pseudonymization)의 개요

### 가. 가명처리의 정의

- 개인정보의 일부를 삭제하거나 일부 또는 전부를 대체하여, 추가 정보(매핑 테이블, 복호화 키 등)의 사용 없이는 특정 개인을 알아볼 수 없도록 처리하는 프라이버시 보호 기술
### 나. 등장배경 및 주요 특징

- 등장배경: 빅데이터 및 AI 시대 도래로 데이터 활용 가치 급증, 원본 데이터 사용에 따른 프라이버시 침해 위협 증가, [[데이터 3법]] 개정에 따른 합법적 활용(통계, 과학적 연구 등) 근거 마련
- 주요 특징: 
	- 재식별 가능성 내재: 익명정보와 달리 추가 정보와 결합 시 원본 정보로 복원 가능
	- 목적 지향적: 정보 주체의 동의 없이 통계 작성, 과학적 연구, 공익적 기록 보존 목적으로만 활용
	- 분리 보관 원칙: 재식별 방지를 위해 가명처리된 데이터와 추가 정보를 물리적/논리적으로 분리 보관 필수

### 나. 가명처리 핵심 기술 요소 (기법)

| 분류 | 요소기술(키워드) | 세부 설명 |
| --- | --- | --- |
| 휴리스틱 | 부분 삭제 (Masking) | - 주민등록번호, 전화번호 등의 특정 위치 문자를 '*' 또는 다른 문자로 대체하여 식별성 제거 |
| 휴리스틱 | 총계 처리 (Aggregation) | - 개별 데이터 값을 보여주지 않고 집단의 전체 합, 평균, 최대/최솟값 등으로 변환하여 제공 |
| 휴리스틱 | 라운딩 (Rounding) | - 나이, 소득 등의 수치 데이터를 올림, 반올림, 내림하여 세부 정보를 범주화 (예: 23세 → 20대) |
| 휴리스틱 | 데이터 교환 (Swapping) | - 사전에 정해진 규칙에 따라 다른 레코드 간의 속성값을 서로 교환하여 레코드와 속성의 연결성 파괴 |
| 암호화 | 일방향 암호화 (Hash) | - SHA-256 등의 해시 함수를 사용하여 값을 변환하되, 레인보우 테이블 공격 방지를 위해 솔트(Salt) 추가 적용 필수 |
| 암호화 | 양방향 암호화 (Symmetric) | - [[AES]] [[알고리즘]] 등을 사용하여 데이터 암호화, 키(Key)를 가진 자만 복호화(재식별) 가능하도록 통제 |
| 암호화 | 형태보존 암호화 (FPE) | - 원본 데이터의 길이와 포맷(문자형태 등)을 그대로 유지한 채 암호화하여 DB [[스키마]] 및 애플리케이션 변경 최소화 |
| 암호화 | 순서보존 암호화 (OPE) | - 데이터의 크기 순서를 보존하여 암호화함으로써, 암호문 상태에서도 범위 검색(Range Query) 및 정렬 지원 |

## III. 익명처리와의 비교 및 가명처리의 향후 전망

### 가. 가명처리와 익명처리 비교

| 구분 | 가명처리 (Pseudonymization) | 익명처리 (Anonymization) |
| --- | --- | --- |
| 개념 | 추가 정보 결합 시 재식별 가능 | 어떠한 방법으로도 재식별 불가능 |
| 보호법 적용 | [[개인정보보호법]] 적용 대상 (안전조치 의무) | 개인정보보호법 적용 배제 (통제 불필요) |
| 데이터 유용성 | 비교적 높음 (분석 및 예측 모델에 적합) | 낮음 (데이터 왜곡 및 손실 발생) |
| 활용 범위 | 통계, 과학적 연구, 공익적 기록 보존 | 제한 없음 (자유롭게 상업적 활용 및 배포) |

### 나. 향후 전망 및 동향

- AI/[[초거대 언어 모델|LLM]]을 위한 비정형 데이터 가명처리: 기존 정형 데이터(DB) 위주의 가명처리에서 나아가, 텍스트(문서, 메신저 대화), 음성, 영상 등 비정형 데이터 내의 식별 정보를 AI 모델을 이용해 자동 탐지하고 마스킹하는 기술이 핵심으로 부상함.
- 차세대 PET(프라이버시 강화 기술) 융합: 단일 가명처리 기법의 한계(재식별 공격)를 극복하기 위해 재현 데이터(Synthetic Data), [[차분 프라이버시]](Differential Privacy), 동형 암호([[동형 암호|Homomorphic Encryption]]) 등 차세대 PET 기술과 결합하여 데이터의 프라이버시 보장과 유용성을 동시에 극대화하는 방향으로 진화 중임.

## I. 데이터 3법 개정에 따른 데이터 활용의 핵심, 가명·익명화의 개요

### 가. 가명·익명화의 정의

- 가명화 (Pseudonymization): 개인정보의 일부를 삭제하거나 대체하여 추가 정보 없이는 특정 개인을 알아볼 수 없도록 처리하는 기술 (재식별 가능성 존재).
- 익명화 (Anonymization): 시간, 비용, 기술 등을 합리적으로 고려할 때 다른 정보를 사용하여도 더 이상 개인을 알아볼 수 없도록 정보를 처리하는 기술 (재식별 불가).
### 나. 필요성 (데이터 3법 기반)

- 데이터 활용: 통계 작성, 과학적 연구, 공익적 기록 보존 등을 위해 정보주체의 동의 없이 가명정보 활용 가능.
- 프라이버시 보호: 빅데이터 분석 시 개인정보 유출 및 오남용 방지.

## III. 가명·익명화의 비교 및 프라이버시 보호 모델

### 가. 가명정보와 익명정보 비교

| 비교 항목 | 가명정보 (Pseudonymized Data) | 익명정보 (Anonymized Data) |
| --- | --- | --- |
| 식별 가능성 | 추가 정보 결합 시 재식별 가능 | 다른 정보와 결합해도 재식별 불가 |
| 법적 적용 | 개인정보보호법 적용 대상 | 개인정보보호법 적용 배제 |
| 활용 범위 | 통계, 연구, 공익 기록 보존 (동의 X) | 제한 없이 활용 가능 |
| 복원성 | 복원 가능 (추가 정보 필요) | 복원 불가능 |

### 나. 재식별 방지를 위한 프라이버시 보호 모델 (핵심 키워드: 케.엘.티)

- K-익명성 (K-anonymity): 동일한 준식별자 속성값을 가진 레코드를 K개 이상 존재하도록 함 (연결 공격 방어).
- L-다양성 (L-diversity): 동질 집합 내 민감 정보가 최소 L개 이상 다양하게 분포하도록 함 (동질성 공격 방어).
- T-근접성 (T-closeness): 전체 데이터의 민감 정보 분포와 특정 집합의 분포 차이를 T 이하로 줄임 (쏠림/유사성 공격 방어).

## II. 가명·익명처리 핵심 기법 및 비교

| 구분 | 항목 | 설명 |
| --- | --- | --- |
| 가명처리 기법 | 가명화(Pseudonymization) | 성명·주민번호 등 식별자를 가명(토큰·해시값)으로 대체, 매핑테이블 별도 관리 |
|  | 총계처리(Aggregation) | 개별 값을 합계·평균 등 통계값으로 대체, 데이터 집합 수준 활용 |
|  | 데이터 범주화(Generalization) | 상세값을 범위·범주로 변환(25세→20대, 강남구→서울), 세밀도 축소 |
|  | 데이터 마스킹(Masking) | 식별요소 일부를 *(별표)·공백으로 치환(홍*동, 930101-1) |
|  | 데이터 교환(Swapping) | 레코드 간 속성값 교환으로 개인-속성 연결 관계 해체 |
| 익명처리 기법 | k-익명성(k-Anonymity) | 동일 준식별자 조합이 최소 k명 이상 존재하도록 [[일반화]]·삭제, 동질성 공격에 취약 |
|  | l-다양성(l-Diversity) | k-익명성 보완, 동일 등가 [[클래스]] 내 민감속성이 최소 l개 이상 다양하도록 보장 |
|  | t-근접성(t-Closeness) | l-다양성 보완, 등가 클래스 내 민감속성 분포와 전체 분포의 차이를 t 이하로 제한 |
|  | 차분 프라이버시(DP) | 쿼리 결과에 통계적 노이즈 추가, 개별 레코드 포함 여부 추론 수학적으로 불가능(ε-DP) |
| 법적 구분 | 가명정보 | 개인정보보호법 적용(안전조치 의무), 통계·과학연구·공익적 기록보존 목적 한정 활용, 제3자 제공 시 결합전문기관 경유 의무 |
|  | 익명정보 | 개인정보보호법 적용 제외, 자유로운 활용 가능, 단 재식별 위험성 평가(적정성 검토) 필수 |
| 처리 절차 | [[PMBOK 프로세스 그룹 (5단계)|5단계]] [[프로세스]] | ① 사전 검토(목적·필요성) → ② 위험도 측정(재식별 위험 평가) → ③ 비식별 기법 적용 → ④ 적정성 평가(k-익명성 등 프라이버시 모델 검증) → ⑤ 사후 관리(반복 재식별 모니터링) |

## III. 활용 및 발전 방향

기술적 발전: 연합학습(Federated Learning)+차분 프라이버시 결합으로 원본 데이터 이동 없는 프라이버시 보존 AI 학습 확산, 동형암호(HE) 기반 암호화 상태 데이터 분석으로 가명처리 없이도 개인정보 보호 분석 가능, 합성데이터(Synthetic Data) 생성을 통한 원본 대체 활용 기법 부상

제도적 적용: 개인정보보호법 개정('23.3)으로 가명정보 활용 범위 확대 및 결합전문기관 지정 운영, 마이데이터·데이터댐 사업에서 가명처리가 데이터 유통 핵심 인프라로 작동, EU GDPR Article 89 연구 목적 가명처리 면책 규정과의 글로벌 정합성 확보 과제

끝.
