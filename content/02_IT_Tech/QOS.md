# QoS

QoS(Quality of Service, 서비스 품질)는 한정된 네트워크 자원 안에서 *어떤 트래픽에 더 많은 대역폭과 우선순위를 줄지* 결정하여, 중요한 서비스의 품질을 일정 수준 이상으로 보장하는 기술이다. 모든 패킷을 동등하게 처리하는 베스트 에포트(best-effort) 방식의 한계를 보완한다.

## 측정 기준

| 지표 | 의미 |
| --- | --- |
| 대역폭(Bandwidth) | 단위 시간당 전송 가능한 데이터 양 |
| 지연(Latency) | 패킷이 도착하는 데 걸리는 시간 |
| 지터(Jitter) | 패킷 간 도착 간격의 변동 |
| 손실률(Packet Loss) | 전송된 패킷 중 손실되는 비율 |

음성 통화, 영상 회의, 게임 같은 실시간 트래픽은 지연·지터에 매우 민감하다.

## 주요 기법

- **트래픽 분류·표시**: DSCP, IP precedence 등으로 패킷 우선순위 마킹
- **큐잉**: 우선순위 큐, WFQ(Weighted Fair Queuing) 등으로 처리 순서 제어
- **트래픽 셰이핑/폴리싱**: 대역폭을 정해진 한계 내로 제한
- **혼잡 제어**: WRED 등으로 혼잡 시 적절한 패킷 드롭

## 활용 시나리오

- 화상 회의, VoIP 등 실시간 트래픽 우선
- 핵심 업무 시스템(ERP, 결제) 트래픽 보장
- 모바일 통신사·ISP의 대역폭 정책
