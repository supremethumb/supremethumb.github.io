### 나. 캐시 메모리의 핵심 기술요소

| **구분**      | **기술**                        | **설명**                |
| ----------- | ----------------------------- | --------------------- |
| **적중률 향상**  | - 참조의 지역성                     | - 시간적, 공간적 지역성        |
| **사상 방식**   | - [[직접 사상]]                   | - 정해진 하나에 적재          |
|             | - [[연관 사상]]                   | - 자유롭게 적재             |
|             | - 집합 연관 사상                    | - 절충형으로 관리            |
| **쓰기 정책**   | - Write-Through               | - 동시 쓰기               |
|             | - Write-Back                  | - 나중 쓰기               |
| **교체 알고리즘** | - [[LRU]]                     | - Least Recently Used |
|             | - [[LFU]] / [[FIFO]] / Random | - 각자 최적화된 방식으로 자원 점유  |
- 한정된 자원 분배에 중점을 두어 메모리 관리.
