# 명령문

- 조건문
    - if 문
        - 조건이 참인진 거짓인지에 따라 경로를 선택
    - Case/Switch
        - 조건에 따라 여러개의 경로 등 하나를 취하고자할 때 사용하며 프로그래밍 언어에 따라 Case 또는 Switch를 명령문으로 사용
- 반복문
    - While 문
        - 수식이 거짓이 될 때까지 해당 문장을 반복해서 실행
    - For문
        - 초깃값, 최종값, 증감값을 지정하여 반복 실행
