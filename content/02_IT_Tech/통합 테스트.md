# 통합 테스트

- intergration test
- 소프트웨어 각 모듈간의 인터페이스 관련 오류 및 결함을 찾아내기 위한 체계적인 테스트 기법
- 프로그램 단위 통합 테스트
- 오류 결함 Finding
- 빅뱅, 상향식, 하향식, 샌드위치방식
- 인터페이스 관련 오류 및 결함을 찾아내기 위한 체계적인 테스트 기법
- 빅뱅테스트
    - 모든 모듈을 동시에 통합 후 수행하는 테스트 방식
- 상향식 통합
    - Bottom Up
    - Driver
    - 최하위 레벨의 모듈 또는 컴포넌트로 부터 위쪽 방향으로 제어의 경로를 따라 이동하면 구축하는 테스트 방식
    - 클러스터
- 하향식 통합
    - 메인 제어 모듈의 아래 방향을 제어의 경로에 따라 이동하면서 하향식으로 통합하는 테스트 방식
