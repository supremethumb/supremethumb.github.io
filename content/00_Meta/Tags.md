# 🏷️ 지식 그래프 태그 체계

Supreme Note의 7대 도메인 및 메타 분류별 핵심 태그 체계입니다. 태그를 클릭하여 연관 노트를 탐색할 수 있습니다.

---

## 📌 도메인별 주요 태그

### 1. UX & UI 디자인 (, , )
-  /  : 사용자 경험 및 인터페이스 설계, 디자인 시스템
-  : 인터랙션, 비주얼 디자인, 디자인 원칙 및 심리학
-  : 서비스 기획, 요구사항 정의, IA, User Flow, 스토리보드
-  : 정성/정량 사용자 조사, 사용성 테스트, 페르소나, CJM

### 2. IT & 테크 (, , )
-  : 소프트웨어 공학, 아키텍처 패턴(DDD, MSA, Clean), 객체지향
-  : OSI 7계층, TCP/IP, 라우팅 프로토콜, 5G/6G X-Haul, 백홀
-  : 대칭/비대칭 암호화, 공개키/ECC, 시큐어 코딩, Zero Trust, ISMS-P
-  /  : 운영체제 커널, 메모리 관리, 컨테이너 가상화, 시스템 튜닝
-  : 정보관리기술사 기출 분석, 서술형/단답형 답안 복기

### 3. AI & 머신러닝 (, , )
-  : Transformer, CNN, 어텐션 메커니즘, 모델 최적화
-  : 거대언어모델, 프롬프트 엔지니어링, 파인튜닝(LoRA/QLoRA)
-  : 검색 증강 생성, Vector DB, 임베딩, 지식 그래프
-  : 멀티에이전트, 강화학습, 추론 파이프라인

### 4. 마케팅 & 비즈니스 (, , )
-  : 그로스 해킹, AARRR, 퍼널 분석, CAC/LTV, 인바운드 마케팅
-  : 비즈니스 모델(BM), 플랫폼 전략, 네트워크 효과, MVP
-  : 브랜딩 전략, 브랜드 커뮤니케이션, 팬슈머

### 5. 철학 & 인문학 (, , )
-  : 서양/동양 철학사, 인식론, 존재론, 현대 비판이론
-  : 문학, 역사, 사회학, 예술 비평
-  : 인지심리학, 인간 본성, 무의식

### 6. 경제 & 금융 (, , )
-  : 가치투자, 재무제표 분석(PER/PBR/EBITDA), 포트폴리오 전략
-  : 거시경제, 기준금리, 채권/주식/배당, 통화 정책
-  : 자산 배분, 연금/절세 전략, 금융 지식

### 7. 인사이트 & 자기개발 (, )
-  : 시간 관리, 습관 형성, 사고 프레임워크
-  : 설득, 리더십, 협업 기술, 글쓰기

### 8. 메타 및 템플릿 (, )
-  : 1교시 단답형 및 2~4교시 서술형 노트 템플릿
-  : 지식 관리 원칙(제텔카스텐), 강의 노트, 독서 기록
