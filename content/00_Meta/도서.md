| 도서명 | 핵심 한 줄 |
|--------|-----------|

| 서비스 기획 스쿨 | 화면을 그리기 전에, 데이터가 어디서 오고 어디로 가는지 먼저 생각하라 |
| 사용자를 끌어들이는 UX/UI 의 비밀 | 심리학 법칙을 활용한 사용자 중심 인터페이스 설계 실전서 |

| 감성 디자인 (도널드 노먼) | 본능적·행동적·반성적 세 단계로 디자인의 감성적 영향력을 분석 |
| USER RESEARCH | 사용자 리서치 방법론의 기초부터 실전 적용까지 |
| 마이크로카피 | 버튼 텍스트 한 줄이 전환율을 바꾼다 — UX 라이팅의 힘 |
| 마음을 생각하는 디자인 | 인간의 인지 한계를 이해하고 배려하는 인터페이스 설계 |
| Data Driven UX | 데이터 기반 의사결정으로 UX 를 개선하는 방법론 |
| UX 기획의 기술 | 실무 기획자가 알아야 할 IA, 플로우, 와이어프레임 작성 기술 |
| 모바일 결제 사례 리서치 | 국내외 모바일 결제 서비스의 UX 비교 분석 |
| 서비스 디자인 교과서 | 서비스 디자인의 학문적 토대와 실무 프로세스 |
| 마법의 디자인 | 디자인 원칙의 실전 적용 사례 모음 |
| IT 좀 아는 사람 | 기획자와 디자이너를 위한 IT 기초 지식 |
| 디자이너가 묻고 개발자가 답하는 웹 이야기 | 디자이너-개발자 소통을 위한 웹 기술 가이드 |
| 오늘도 개발자가 안된다고 했다 | 기획자의 제안이 개발 관점에서 왜 어려운지를 설명하는 커뮤니케이션 가이드 |
| UX 디자인 7 가지 비밀 | UX 실무에서 자주 놓치는 7 가지 핵심 포인트 |
