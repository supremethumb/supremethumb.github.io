# 비지도 학습
데이터가 어떻게 구성되었는지를 알아내는 문제를 해결하기 위한 방법으로, 입력과 출력 목푯 값으로 구성된 훈련 데이터 없이 정답을 따로 알려주지 않고 학습하는 방법으로, 비슷한 입력 데이터들을 군집화하는 방식으로 학습이 진행됨.[^1]

[^1]: 쉽게 활용하는 인공지능 비즈니스
