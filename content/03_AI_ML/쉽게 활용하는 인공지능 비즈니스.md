# 쉽게 활용하는 인공지능 비즈니스

## 책 소개

인공지능 기술의 기초 개념부터 실제 비즈니스 적용 사례까지 체계적으로 정리한 실무 가이드. 기계가 입력 데이터의 패턴과 연관성을 스스로 학습하는 과정(특징 추출 → 분석 기법 결정 → 코드 작성 → 지능형 결과 출력)을 알기 쉽게 풀어쓰고, **해외 50개 기업 + 국내 100개 기업**의 AI 활용 사례를 산업별로 분류해 제공한다.

## 핵심 인사이트

### 1. 인공지능 기술 분류 체계

| 대분류 | 중분류 | 설명 |
|---|---|---|
| **학습지능** | 머신러닝 | 데이터 분석·시행착오·기존 지식 활용을 통한 학습 |
| | 추론/지식표현 | 기계 이해 형태의 지식 표현 + 새로운 사실 추론 |
| **단일지능** | 언어지능 | 텍스트·대화체 문장의 분석·이해·생성(NLP) |
| | 시각지능 | 영상의 사물 위치·내용·행동 이해(Computer Vision) |
| | 청각지능 | 음향·음성의 인식·분석·표현 |
| **복합지능** | 행동/소셜지능 | 공간 인지, 움직임 제어, 사회적 협업 |
| | 상황/감정이해 | 환경·맥락·감정을 다양한 센싱 정보로 인식 |
| | 지능형 에이전트 | 사용자를 대신해 작업을 수행하는 AI |
| | 범용 인공지능 | 인간의 모든 지적 업무를 수행할 수 있는 AI |

### 2. 해외 AI 비즈니스 사례 하이라이트

| 기업 | 분야 | 핵심 사례 |
|---|---|---|
| **테슬라** | 자율주행 | 오토파일럿 시스템 |
| **로레알** | 뷰티 | Skin Consult AI (스킨 컨설팅) |
| **JP모건체이스** | 금융 | LOXM — 딥러닝 기반 AI 주문집행 시스템 |
| **Amazon** | 클라우드 AI | Polly, Rekognition, Lex — 이미지·비디오 자동 분석 |
| **Exscientia** | 신약개발 | AI 활용 신약 DSP-1181 개발 (Centaur Chemist 플랫폼) |
| **Walt Disney** | 엔터테인먼트 | FVAE — 관객 표정을 AI로 평가해 감정 유추 |
| **BMW** | 제조 | 차체 도장 공정에 AI 적용 |
| **Lemonade** | 보험 | 챗봇 기반 보험 전 과정 간소화 |

### 3. 국내 AI 비즈니스 생태계

100개 국내 기업을 산업별로 분류하면:

- **의료/헬스**: 뷰노(의료AI 솔루션), 뉴로핏(뇌구조 측정), 노을(혈액 진단), 메디웨일(심혈관 위험평가)
- **금융**: 솔리드웨어(DAVinCI LABS), 빅벨류(부동산 시세), 에이젠글로벌(재활용 트레이딩)
- **교육**: 뤼이드(AI 토익 튜터 산타), 비주얼캠프(시선 추적 SDK), 네오사피엔스(Typecast 음성합성)
- **제조**: 라온피플(AI 비전검사), 에이모(AI 모델 플랫폼)
- **자율주행/교통**: 모라이(시뮬레이션), 모빌테크(정밀 측위), 블루시그널(교통 예측)
- **법률**: 로앤컴퍼니(로톡), 워트인텔리전스(특허 검색)

### 4. 주요 기술 프레임워크 분포

국내 100개 기업 분석 결과, 가장 많이 사용되는 프레임워크:
- **TensorFlow** — 가장 높은 점유율
- **PyTorch** — 두 번째
- **Keras** — 세 번째
- 기타: Caffe, scikit-learn, MATLAB, 자체개발 프레임워크

## 내 생각

이 책의 가치는 **카탈로그형 레퍼런스**다. 150개 기업의 사례를 산업별·기술별로 일목요연하게 정리한 자료는 "우리 산업에서 AI를 어떻게 적용하고 있는가?"라는 질문에 빠르게 답을 찾게 해준다.

다만 기술의 깊이보다 폭에 집중하다 보니, 각 사례의 성과 데이터(ROI, 정확도, 비용 절감 등)가 부족한 것이 아쉽다. 또한 AI 기술의 발전 속도를 감안하면 사례의 유효 기한이 짧을 수밖에 없다. 방향성보다는 현황 스냅샷으로 참고하는 것이 적절하다.

## 한 줄 요약

> AI 비즈니스의 출발점은 기술이 아니라, 우리 산업의 어떤 문제를 AI로 풀 수 있는가를 아는 것이다.
