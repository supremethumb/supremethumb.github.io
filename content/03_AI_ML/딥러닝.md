# 딥러닝
기계학습의 한 방법으로 동물의 신경세포 뉴런을 흉내 낸 신경망을 이용하고 학습하고 문제를 풀어냄, 심층 신경망은 입력층과 출력층 사이에 여러 개의 은닉층들로 이뤄진 인공신경망으로 복잡한 비선형 관계들을 모델링할 수 있음.[^1]

## 판단 과정
학습된 딥러닝 모델과 평가데이터가 주어졌을 경우, 평가데이터를 딥러닝 모델에 입력하여 출력 결과를 계산하는 과정으로, 출력 결괄르 계산하는 과정이 실수 값의 연산으로 구성되기 때문에 해당 결과가 도출된 이유를 사람이 이해하기 어렵다는 특징을 가짐[^3]

## 학습 과정
딥러닝 모델과 학습데이터가 주어졌을 경우, 학습 목표인 손실 값을 최소로 만들기 위하여 딥러닝 모델 내부의 가중치 변수를 조정하는 과정으로, 사람이 학습과정에서 발생하는 가중치 조정의 의미를 이해하기 어렵다는 특징을 가짐[^2]
