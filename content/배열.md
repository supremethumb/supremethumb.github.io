   - Array
- C, C++
    - 초기 값이 없는 경우: 타입명[배열수];
    - 초기 값이 있는 경우: 타입명[배열수]={초기값};
    - ex
        - int a[5] = {1,2,3};
        - 배열 수는 5개 임으로 5개의 공간이 잡힘, 따라서 1, 2, 3, 0, 0
- 자바
    - 초기 값이 없는 경우
        - 타입[]배열명 = new 타입[배열수];
        - 타입 배열명 [] = new 타입[배열수];
    - 초기 값이 있는 경우
        - 타입 [] 배열명 = {초기값};
    - 초기 값 선언이 없는 경우
        - 쓰래기 값 입력, 문자 NULL
